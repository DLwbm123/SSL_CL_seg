## 2. 可以得出的结论

1. **R0与R2-SG直接路径精确一致。** step0及每25步共25条e/D与Adam状态一致；独立审计再核对七个完整保存状态及封存预测。最终两者35.8945%。因此不能把R2-SG的额外分支本身解释为直接头增益。
2. **当前共享语义变分目标明显损害直接头。** R2-D为4.9042%，相对R0/R2-SG下降30.9902个百分点，类2/3预测消失。该初始化、目标权重与600步轨迹下，允许A梯度进入e是明确的有害变化；不能据此声称所有生成辅助都不可用，或已经定位到A内部的具体冲突项。
3. **辅助CE对生成读出有有限改善，但仍严重缺类。** R2-G 29.0602%，比R1-G 26.8106%高2.2496个百分点；两者类3均0，R2-G类2只有4.6472%。R2-G比R2-SG-G高8.7770个百分点，提示共享表示变化影响G读出，同时牺牲了直接头。这不是整体分割成功。
4. **普通监督基线本身尚未充分拟合。** R0-D仅35.8945%，类3为11.5333%，未通过训练资格。不能据此证明冻结G已达到表达上限；也不能把两图训练读数当独立泛化或“生成方法超过监督”的判据。
5. **低NLL不等于完整类别恢复。** R2-G的像素NLL低于R0-D，但类2/3几乎缺失，故继续分开报告类别功能、概率指标和背景占比，不用低NLL替代语义成功。

训练日志显示R1的KLR/N由约.880降到.153，R2约.155；这只是该目标分量的观察，不能直接把类别丢失归因于KL。R2的A梯度究竟来自类别项、KL或优化相互作用，本轮没有做分项方向诊断，结论保留。

## 3. 接口、协议与独立核验

源为P2的spatial_generator/S0600、cursor8675。原100模型参数及prior/initial冻结，原Adam未加载到新优化器；新增e/D/H使用统一seed20261020初始化后复制，只有原两canonical训练L与四翻转。G对c/R的梯度保留，SG对e的梯度断开但H仍收到梯度，Gaussian prior KL=0检查通过。

只使用image-only预测函数，不输入Y、身份或标签条件局部状态；先生成并封存预测，再调用独立评价函数读GT。主生成预测为4流×8Theta×8local，每样本先softmax再平均；报告的是逐像素边缘混合NLL，非整张空间标签的联合边缘NLL。未使用教师、TaskRel、状态条件化、输出融合、U/目标域或保留数据。

独立审计通过：四臂各600步连续physical_updates和steps；完整checkpoint/Adam/RNG覆盖；25条SG配对；12份封存预测指标在CPU复算，最大CPU/GPU差2.3842e−7；旧初始化逐项一致，源文件元数据保持，原始时钟继承。没有增加工程optimizer或按中间点补预算。见[审计](results/R_START_AUDIT.json)、[源码](r_start.py)、[冻结协议](R_START_PREREG_ZH.md)。

## 4. 工程故障与真实成本

首次在资格G前向后遇到PyTorch 2.7.1 CUDA默认mean归约NLL的严格确定性错误，0optimizer、0训练反向、0资格反向；由失败位置可确认已执行1次资格G前向。失败目录/EXIT/初始化完整保留。

修复仅将CE/NLL改为reduction=none后mean，保持数学目标与严格确定性；create-only修复目录逐项继承原初始化，不重复任何训练更新。修复guard以新start_token核验身份，以原clock_start_token计时，未重置24小时。

正式2400 optimizer/2400训练反向；生成训练3600Theta/7200批量G前向（57600图像G前向）；评价288Theta/2304批量G前向（18432图像G前向）。当前资格2次诊断反向/4次批量G前向，加首次失败1次资格G前向，所有失败成本保留。正式图像编码器19200图像前向、直接头14400图像前向；评价各96。资格另含4次编码器batch前向和2次直接头batch前向，首次失败另含1次编码器batch前向。

从第一次实际worker启动至联合结束170.9202秒；guard退休时新占用111,083,520字节，四根累计1,714,057,216字节，后续审计源码和JSON为少量额外占用并在私有交付回执记录。明显低于各原始时钟与新增空间/累计空间硬限。两个worker及guard均正常退休，不终止其他进程。

## 5. E0：通过，但只支持代数正确

8×8和16×16合成网格，各固定10次Gamma/Gaussian坐标扫掠，FP64联合参考对Schur均值、完整协方差、cross协方差及logdet的最大误差9.09495e−13；Student/Gamma解析边缘与现有标量密度一致，完整残差二阶矩检查和增广下界非降检查通过。实际约.1744秒，无医学输入、无GT/BG比较。见[E0全结果](results/STUDENT_E0.json)和[源码](student_e0.py)。

这不是原Student边缘证据的精确计算，不证明空间推断会恢复类别，也不自动启动128×128 E1。

## 6. 后继决策

本轮四臂到此收口，不改变600步终点、不重跑已完成臂。下一优先级是建立普通监督训练资格，保留R0的完整模型/Adam/RNG作为后继可追溯起点；在另立协议中区分有限优化预算与前景监督分配，而不是先加教师/TaskRel/U或扩大F。若续接同一训练，必须共享本轮原始时钟与存储成本；不得拆名重置限额。
