# 固定无标签ELBO验收的局部推断

mesh3/25产生明确位移却使共同随机数ELBO恶化。为分离步长与模型密度问题，固定全部网络与生成参数，仍只改变单次预测的局部变分状态。

robust_quarter终态推断器，生成分布终态后验/原始先验两格。原train2和预选heldout2同批。局部shift起点全零，各最多25次梯度尝试。梯度目标为原2参数×4局部样本平均ELBO（每图归一化128²，再对图求和），每次重置已有随机流50163，因此方向与候选验收使用相同8样本SAA；不再用一个随机样本的梯度验收另一噪声目标。空间x/m/ell场Riesz梯度乘128²，code原尺度；0.05原步长，固定回溯alpha=[1,1/4,1/16,1/64,1/256,1/1024,1/4096,0]。

接受条件：每图ELBO>=本步起点−1e-6，总均值严格上升>1e-5；全未过则局部状态不动，仍记梯度和候选成本。没有基于Dice、CE、标签的验收或停止。两格均跑足25次尝试，实际接受步单独记账。

每格初末输出变分均值预测及原SNIS；初末SAA-ELBO、每图改变量、逐块位移/RMS、ESS全部报告。固定另一个已有流80163上的同样8样本ELBO只作末端读出，避免只凭单一SAA改善宣称后验改善，不用于训练/验收。有限样本ELBO不等于精确积分ELBO。

最多50次局部autograd、50次接受状态步、400次候选ELBO评价（每次8样本），另50梯度ELBO评价、初末评价和配对复测实际记账；0模型optimizer/0模型参数更新。连续记录reverse/candidate/local_updates账本，保存起终局部状态与私有预测，断言完整模型张量不变。标签仅所有优化完成后计分，保留图不用于调参或选模型，全部两格正负交付。

本算法是预登记新推断对照，不修改旧结果、不自动重跑历史；失败保留partial和成本。新文件仅数据盘，检查存储/容量/探针，20GB窗口上限及UTC03:30截止不变。此后依据实际ELBO与语义变化决定下一有判别力阶段，不盲延长。
