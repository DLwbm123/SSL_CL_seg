# 冻结解码器的逐视图自由code检验

结论：绕过标签编码器确实能进一步降低重构CE，但100次局部更新未消除第二类欠拟合和缺类。不能把当前剩余误差全部归于共享编码器，也不能由局部失败证明生成架构不可能拟合。

## 设置与核验

固定上一轮fixed/code各自600步终态全部100模型参数，仅原2L四翻转8视图；从标签编码均值出发，分别优化每视图16维确定性code。普通像素平均CE，非Gaussian后验/ELBO。每臂100次尝试，手工负梯度步.05及固定回溯，逐图CE不升且批均下降才接受。未读取保留/U/目标，没有调用optimizer或应用模型参数。

实际200局部反向、200候选、410前向、200接受，0模型optimizer/应用。四连续账本、200逐图门限、202份局部code状态、初态CE复现、完整模型/RNG/源1208物理账本不变及EXIT0通过。全部步alpha=1。窗口新增空间保守累计1.302GB。

## 可支持的解释

固定模型下自由code下降说明当前编码均值没有达到这两个固定解码器可利用的局部条件拟合水平，存在摊销/优化差距；不是已找到全局最佳潜变量，也不意味着共享编码器训练必能达到该点。code臂剩余CE下降约10.5%，第二类仍弱，说明这100步自由code没有成为充分解释。

16维code经线性层/ReLU映射到16×4×4特征，再双线性上采样及卷积。后继用固定权重、相同实际特征位移尺度，对比code可达切空间与完整4×4特征空间的负CE方向，检查低维映射是否阻挡有用方向。切空间与有限参数可达性需分开解释，不把特征候选当作合法新code后验。

整个检验使用训练标签生成重构，不是图像预测，未改变识别器，也未证明SSL/CL或泛化有效。不直接将局部code写回训练或增加真实U。
