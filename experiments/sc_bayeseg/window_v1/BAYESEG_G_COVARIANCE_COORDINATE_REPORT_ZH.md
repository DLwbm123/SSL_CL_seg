# 协方差块坐标比较：直接Cholesky有所改善，仍未准入

2026-10-21。[运行前冻结](COVARIANCE_COORDINATE_PREREG_ZH.md)、[源码](validate_covariance_coordinates.py)、[逐例结果和完整轨迹](results/BAYESEG_G_COVARIANCE_COORDINATES.json)。按用户授权只做CPU合成有界修复，固定隐藏层及均值，保持同一分布起点、原KL和门槛；正式训练/医学数据/GPU/服务器写入均0。

## 1. 相同分布起点如何实现

起点固定为上一轮H终点经均值Newton-CG修复后的保存参数。均值保留该FP64数值，最大均值KL为1.83154e−21；协方差仍是H终点，完整maxKL .001927051649。

不能直接把原κ线性头权重乘以sigma后当新的线性ell21权重，因为sigma随输入变化。为避免投影误差改变起始分布，两臂统一使用冻结原输出函数加99个零初始化共享残差参数：

- 两臂尺度相同：sigma=1e−6+softplus(raw0+4hδw_scale)。
- K臂保留κ坐标：κ=κ0+hδw_k，ell21=−κ sigma_c。
- L臂直接Cholesky：ell21=−κ0 sigma_c0+hδw_ell。

h是固定隐藏层32维特征加bias；每臂3×33参数，无逐例变量。锚点由已保存模型产生，没有用精确目标赋值。初始均值固定，两个初始协方差差异最大值实测0，原KL公式与统一稳定Cholesky形式差异实测0。

这是固定锚点的坐标比较，点态Gaussian族相同，但固定特征条件函数类不保证完全相同。K臂的偏移存参也不保证与原绝对FP32权重更新逐位一致。不能称为已经替换医学网络模块。

## 3. 数值与剩余误差

微扰参数点的跨精度梯度误差K=7.88e−9、L=2.01e−8，FP64方向差分误差K=2.57e−7、L=3.13e−7，全部通过原2e−6门槛。终点跨精度参数梯度误差分别5.66e−11、9.08e−10，也通过。检查仅涵盖这些点，不保证任意训练状态。

隐藏层与均值不在优化变量中，均值KL全程固定。终点跨案例最大分项：

|坐标|均值KL|κ耦合KL|尺度KL|
|---|---:|---:|---:|
|K|1.83e−21|.000669877|.000118337|
|L|1.83e−21|.000507276|.000236646|

不同项最大值可能来自不同案例，不应直接求和。L臂为便于比较，将有效κ=−ell21/sigma_c用于相同的事后KL分解，优化时没有恢复κ输出头或做clip。两臂最差案例均tau=1,x=0，其他11例亦未过原门槛。

**结论：** 单独移除κ×sigma乘积输出坐标未能解决预算内优化失败。直接ell21只是对自由三角Gaussian坐标的改变；正尺度仍经softplus并映射到共享特征系数，所以不能据自由Cholesky坐标的凸性宣称当前神经参数目标凸或易解。现有结果仍不能唯一定位到尺度坐标、特征条件数或L-BFGS近似曲率中的哪一项。
