# 冻结解码器的非负4×4特征局部拟合

切空间方向检验发现大量下降方向位于当前code切空间外，且匹配半径下完整特征改善更大。下一步固定recon fixed/code两臂各自S0600全部100参数，从各自code_local S100映射h=ReLU(Wc+b)出发，只优化每视图16×4×4非负特征。仍原两训练L四翻转8视图，不读heldout/U/目标。

这是对表示约束的条件诊断，h不再要求位于16维code的映像内，绝非现有生成模型的Gaussian后验，也不回写旧模型或用于图像预测。后两生成卷积及其均值权重完全固定，不新增或训练模型参数。

每臂100局部尝试、合计200反向，0optimizer构建调用/0模型应用。普通CE，loss=sum各视图每像素CE，h的空间L2梯度乘4²=16、通道不额外放大，固定步长.05和原八值回溯；候选h=clamp_min(h-.05*alpha*16*grad,0)。逐图CE不升1e-6且平均降>1e-7接受。原code局部步未乘空间格数，不将两者声明为同一欧氏步长/算力对照；本阶段检验能否可行拟合，而非纯维数因果归因。
