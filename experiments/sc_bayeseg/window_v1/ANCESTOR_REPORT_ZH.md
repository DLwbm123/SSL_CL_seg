# 纯监督祖先状态核对：低泛化不是联合训练才出现

零更新审计确认：原纯监督L3终态与最初J初态的40个语义参数逐张量完全相同；原模型与拆分模型在同四图上的均值logits也完全相同。历史L3只使用原两张训练图，两张预选保留图不在历史训练batch中。

因此，最初J状态的保留图均值Dice10.92595%、CE2.46791已经存在于纯监督两图拟合阶段。不能把这种源域低泛化全归因于联合目标。后来受约束联合更新把保留图均值略提高到11.72565%，仍不能解决基础摊销泛化。该证据针对均值预测；拆分模型改变了随机语义推断依赖，不将两个模型的随机预测声称完全相同。

这与另一个结论并不冲突：联合/局部无标签目标确实可能损伤已经学会的训练语义，且当前生成条件点评分不一定偏好正确类别。现在至少有两类问题：两图确定性监督已经过拟合；生成与无标签目标不能可靠纠错。二者应分开验证。
