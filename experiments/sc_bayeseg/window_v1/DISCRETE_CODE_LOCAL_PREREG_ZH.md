# 冻结生成器：逐视图自由code条件重构诊断

原fixed/code配对600终态均未过24项拟合门限，code适配有帮助但仍有缺类。固定两臂各自全部100模型张量，仅原2L四翻转8视图，不读heldout/U/目标。各臂从自己的标签编码均值c开始，直接优化每视图独立16维确定性code；不保留Gaussian方差、不计算ELBO/KL，不把局部点code当后验或无标签预测。

每臂100次局部尝试，共200 autograd.grad，无optimizer构建/调用、0模型应用；仅c变量手工负梯度步。loss=sum(每视图像素平均CE)，步长.05，固定alpha[1,1/4,1/16,1/64,1/256,1/1024,1/4096,0]，每视图CE不升超过1e-6且平均降>1e-7才接受。最多200接受/1600候选；梯度、候选、评价前向分别记真实账，模型/RNG源账本起终不变。所有BayesLayer用均值；不给模型/Adam写回。每局部步骤保存128个code值（不公开）。固定100不择优/早停/换步长，记录0/25/50/75/100完整8view各类指标和code位移。额外前向上限1810（200梯度+1600候选+10端点评价）。

若提升，支持该固定解码器存在绕过当前编码器可利用的局部潜在方向；不等于摊销器经训练必能达到，更不是通用模型表达充分的证明。若无提升，需结合code位移/梯度/门限判断，不能认定架构容量不可能。不给保留图作code拟合，不用训练标签修正实际图像预测。成本/失败完整保留，能精确接续才恢复；四根空间20GB硬/18GB软，数据盘create-only、中性argv，UTC03:30截止。
