# 给Pro：P2资格复评与图像—标签匹配检验

2026-10-20。P2.0合格后才补齐候选，现已全部完成，EXIT0，worker及预算守护退出。**结果为“部分信号＋类别缺口”，不是稳定的完整图像匹配机制。**

## 1. 决策摘要

- **P1评分不是只在本步样本上虚假改善。** 12个旧端点逐项回放误差0；4条B分支在4个独立评价流上终态均改善，末50步亦有独立改善，因此通过P2.0。
- **位置支持成立，但类别支持不完整。** 两初始化、两张图均支持GT优于32像素平移；也均偏好删除类2和全背景，按预定MC规则是可靠负差。
- **配对主指标对初始化敏感。** init0的Gamma为+0.00004349、MC区间跨零且一个流为负，记未决；init1为+0.00015486，按规则为正。两者不能择优合并为“配对成功”。逐图match−cross均表现为图1正、图2负。
- 下一条最有依据的干预是**固定标签侧与其他参数，仅更新structure图像条件映射F**，检验类2和图像匹配缺口是否可修复。不再因A占近似负差大就先训练anatomy，也不扩大R、调KL或接真实U。

这是两训练图上的条件评分机制实验。没有无GT分割输出，没有识别器或泛化收益。用户现已授权持续自主实验，后继须另立冻结协议，不追改本轮数据、门槛或结果；报告给Pro审阅不作为逐轮授权等待点。

## 2. 来源、统计口径与公平性

固定spatial_generator/S0600完整模型cursor8675，100参数／prior／Adam不变；仅原两canonical训练L，无保留图、U、目标或新训练seed。只优化B的(mx,mm,lx,lm,b)，同像素Cholesky相关族、联合熵及局部更新规则全部沿用P1。

P2.0读取P1：B两个初始化×GT/BG×[0,100,150,200]共16状态，A四个200终态；只读不重跑。合格后新增CROSS、SHIFT、DELETE2，各两初始化从规定初态开始200次尝试。MATCH/BG只复用P1的200终态，错误候选没有从GT终态多跑200步。

init0为图像提议、b=0；init1为x均值=均值权重F(Z)、m均值=I−F(Z)、尺度取图像提议、b=0。所有新分支完整训练RNG在每25步与P1相应初始化逐项匹配。

新评价4流Theta seeds固定为220163／230163／240163／250163。Theta独立generator，局部噪声按流、Theta索引、变量种类分流，各候选／状态共享对应噪声。P2.0每流32Theta×8local，最终五候选×两初始化统一每流32Theta×16local。新终点的前8local对旧资格复评逐分项精确复现，误差0，验证了local数量没有改变Theta及对应噪声。

先在每Theta内平均local，再按128个Theta组计算配对均值、SE及近似95% MC区间。预定规则为区间下界>1e−5且4流均值均>1e−5才记正，上界<−1e−5且4流均<-1e−5才记负；其余未决。它不是跨患者置信区间、不是临床意义门槛，也没有多重检验后的总体显著性保证。没有加draw直到出现有利符号。

## 5. 相对P0/P1更新了哪些判断

1. 不能把B原先的大幅改善简单归为本步采样过拟合，独立轨迹确认了真实的期望下界改善；但固定200步还未收敛。
2. 不能只说“所有问题都在A”。不含A的B仍对删除类2和BG给出优势，类别支持缺口已被单独显露。
3. 不能只说“F没有图像信息”。两个初始化两图都支持正确位置，存在可利用的条件信号。
4. 配对未决是未决，不把init0宽区间改写为负，也不只挑init1的正值。整体应归类为部分位置证据、初始化敏感的配对、稳定类别缺口。
5. 下一次干预应针对图像条件因素，冻结anatomy／A／外观尺度／识别器，不同时修改多个因素。即使F-only修复这两训练图的匹配，也只是可修复性证据，不是独立患者分割提升。

## 7. 后继路线与给Pro的问题

按本轮预定分支和最新自主授权，选择一次有界structure-only坐标更新：保持A及其他模块、先验／噪声尺度不变，从同一完整状态更新F；主比较是原P2的图像配对、位置、类2保留和BG指标，不是标签重构Dice。使用冻结P2作控制，局部推断从相同规则初态开始并匹配新增预算；训练与读出另立协议，不追改P2，也不自动连到真实U。

仍需区分的三件事：

- 如果F-only使类2保留与匹配同时改善，支持当前条件映射有可修复空间，但还要验证无GT预测及独立患者泛化。
- 如果绝对B改善而类2偏好／匹配不改善，就不能通过继续训练F掩盖问题；应停止延长相同设置，转向单一图像生成结构或推断族假设。
- 如果主要指标在初始化／MC流间仍未决，应报告有限预算未决，不能用增加draw或挑终点制造正号。

希望Pro重点审查：P2部分信号是否足以支持一次F-only干预；主初始化的训练／评价局部变量应怎样固定才不混入额外推断优势；若F-only仍失败，什么单一建模修订最值得替代继续扩大R或A。新授权允许继续实验，但不取消上述科学停止标准。
