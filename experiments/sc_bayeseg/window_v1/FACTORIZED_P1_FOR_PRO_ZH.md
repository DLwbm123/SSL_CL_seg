# 给Pro：P0／P1完成后的图像证据与推断分解

更新：2026-10-20。P1已完成、EXIT0、worker退出；本报告没有启动后续实验。前序路线背景见[上一份审阅材料](SC_BAYESEG_LATEST_FOR_PRO_ZH.md)，此次以本报告的P0/P1结果为准。

## 1. 核心结论

**开放相关x/m推断确实大幅提高图像块下界，但没有使GT优于背景；开放c/R后也没有翻转标签先验侧的背景优势。两个初始化、两张图的完整终点评分均仍偏BG。**

在本次受限推断下，主要剩余差值位于标签先验块A，而不是图像块B。但不能直接推断“真实模型主要错在标签先验”：两块仍有不同变分间隙，初始化未给出相同终态，只有一个预固定独立评价流，没有精确证据或收敛证明。当前不应立即训练structure、扩大R、调KL或进入U；需要Pro据此选择下一项最有判别力的干预。

这次回答了“完全固定qx/qm是否留下显著可改善空间”：答案是有。没有回答“扩大后的图像后验是否已足够准确”：答案仍未知。也没有获得无GT图像预测或SSL／CL收益。

## 2. 固定条件与实际执行

唯一模型为spatial_generator_v1的S0600，模型optimizer游标8675，全部100模型参数／先验冻结。仅原两canonical标注训练图，不翻转、不读开发保留图／U／目标域、不增加训练seed。全局参数、识别器和Adam不更新。

固定权重时的生成图分解为：

- 标签侧A(Z)=E[log p(Z|c,R)]−KL(qc||pc)−KL(qR||pR)。
- 图像侧B(I,Z)=E[log p(I|x,m)+log p(x|Z)+log p(m)]+H(qxm)。

报告的是对同一个冻结qTheta的期望分块下界；单图评分不混入固定全局Theta KL。A+B的可加性不等于积分全局权重后的精确log p(I,Z)可独立分解。两块分别使用各自配对的MC流，不能把它们称为完全相同的逐draw联合样本。

A优化c和R的均值／logsd，qc与qR仍独立。B采用每像素2×2 Cholesky Gaussian：x=mx+exp(lx)e1，m=mm+b·e1+exp(lm)e2，熵为sum(lx+lm+log(2pi e))。它允许同像素负相关，但不表达完整SAR空间相关。B同时开放均值、尺度和相关项，没有另做“只增加相关性”消融，因此不能把全部收益归给相关性一项。

每块×两个初始化×GT/BG，每条分支固定200次尝试，共8条分支。每步2Theta×4local新流，候选回放同一步；固定回溯与逐图不降门限，未按GT−BG改变规则。终点评价使用预固定seed80163的32Theta×4local，与优化源RNG分离并恢复。0/200两个评价端点全部报告，不挑较好初始化或中间点。

### 两个初始化并非等总成本实验

- **init0（主读出）**：A从上一对称GT/BG各自qR500终态继续，c从相应标签编码器开始；B从原图像qx/qm开始、b=0。历史500步只复用、不重跑、不重复计费。
- **init1（敏感性诊断）**：A的c/R都从先验开始；B取x均值=均值权重F(Z)、m均值=I−F(Z)，尺度仍取图像提议、b=0。

两个假设在每种初始化内采用同一规则，但两个初始化历史成本和起点不同。init0不是只给GT使用高质量oracle状态；GT与BG各自复用相同预算的历史状态。不能以init0更好证明该初始化普遍优越。

### x/m相关性与外观补偿

四条B分支终态同像素相关系数中位数约−0.752至−0.753，5%／95%分位约−0.829／−0.630。相关后验在该优化结果中确实被利用，但没有提高相对GT排名至正值。

init0的m均值RMS约0.09304→0.09317（GT）／0.09254（BG），没有大幅增长；init1约0.33955／0.34315→0.13595／0.13642，反而下降。不能据此说“BG主要靠更大的m补偿”。m仍有较大随机方差和相关自由度，单靠均值RMS也不能排除外观吸收。x+m均值位移RMS四分支约0.030—0.031。

## 6. 不能从这些结果推出什么

1. **不能说已接近精确后验。** A仍为独立qc/qR，B没有SAR空间相关；初始状态和终态分数依赖初始化。两种初始化虽同为BG优先，但负差幅度不一致。
2. **不能说终态已收敛。** 只在0/200做固定独立评价；末25次同一步SAA平均增益A约1.8e−5至3.6e−4，B约0.199。它们不是固定评价流的单调链，不能累加成证据改善或当作收敛曲线。
3. **不报告未经保存的MC显著性。** 末端结果保存32Theta×4local均值，没有逐draw分数供独立标准误估计，也没有第二个终点评价流；小差值不宣称统计显著。不能把初始化同号当作MC稳定性证明。
4. **不能说相关性单独解决／导致了问题。** B同时优化均值、尺度和相关项，没有独立同预算的对角族对照。
5. **不能声称图像预测改善。** 没有无标签Z推断，没有更新识别器、训练U或评价新患者；所有候选均来自合法训练L的条件诊断。
