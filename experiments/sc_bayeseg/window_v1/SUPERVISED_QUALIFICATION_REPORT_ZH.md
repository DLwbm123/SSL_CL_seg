# 监督资格对照：类平均CE未优于原像素CE

2026-10-20。有效两臂各新增1000步，完整继承R-START的R0第600步模型/Adam/RNG；最终接口总步1600。有效CE原臂复用，修复只重做受影响的类平均臂。最终EXIT0、独立审计PASS、相关worker/guard全部退休。**原CE有进展，但两臂都未建立高质量训练拟合资格；类平均风险增加误检、降低Dice，不能据此修订生成似然。**

## 1. 固定终点、完整类别

类2precision/recall按八视图等权：原CE约50.43%/70.63%，类平均约24.45%/94.28%。提高召回伴随明显误检，不能只报召回上升。NLL/Brier也更差；类平均CE优化的是另一个监督风险，不保证原像素分布的校准。

## 2. 方法与归因范围

两臂只有损失的类别归约不同：原CE为完整batch逐像素平均；类平均为每类全部训练像素CE的均值再平均4类。训练类计数固定，无权重扫描、平滑或截断。源e/D、Adam600和RNG一致，网络、数据、优化器、lr、分组裁剪和更新次数一致；H冻结且不使用，G/F没有前向或更新。

当前结果不支持继续加大少数类权重作为首选路线。它也没有证明局部网络容量、上下文或Adam一定是剩余瓶颈。下一次若检验上下文，需要把它单独设为变量，不能同时改风险、数据和初始化。

## 3. 真实工程失败与修复

首次两臂共执行2000更新后，终态Adam步数断言失败。独立检查保存状态确认：

- CE起点完整模型/Adam/RNG与源一致，Adam600→1600，该臂有效且未重跑。
- 首次类平均起点模型相同，但优化器CPU step张量因加载共享而已被第一臂修改，Adam错误1600→2600，完整优化器起点不匹配。该1000步明确标为无效，不进入上表。
- 原源checkpoint仍为Adam600，没有被写回修改。修复仅对源optimizer使用deepcopy，并在加载和终态核对只读源payload仍为step600；只在新目录运行类平均原定1000步，得到正确Adam600→1600。

原失败目录、FAILURE/EXIT1、checkpoint/partial及无效1000更新保留。[无效臂全部读数与成本](results/SUPERVISED_QUALIFICATION_INVALID.json)独立公开，不能把它冒充有效重复、额外seed或挑选候选。修复没有改变科学目标、权重、终点或评价门槛。

## 4. 核验、成本与资源

[独立审计](results/SUPERVISED_QUALIFICATION_AUDIT.json)核对有效两臂全部2000步，及无效1000步的连续真实账本；22份有效完整状态、Adam600→1600、H冻结和RNG逐项检查；8份有效封存预测独立复算。源初始模型/Adam/RNG及预测精确相同。最初逐浮点相等审计发现一项CPU NLL归约差1.19209e−7，限定在既有2e−6指标复算容差内，Dice/判定不变，未重新训练；该数值检查记录保留。

实际本阶段3000optimizer/3000反向：有效CE1000、无效类平均1000、修复类平均1000。训练e/D图像前向24000，评价96图像前向（含无效32）；没有G/F调用，资格检查0optimizer/0反向。加原R-START，本链累计5400正式optimizer，失败成本没有消失。

修复worker实际约13.9905秒；其完成时自R-START首次实际启动共1038.8267秒，原始start token和24h时钟没有重置。收集时四根累计1,750,708,224字节，相对第一次R-START原基线保守新增147,734,528字节，含旧成功/失败与本轮无效结果；仍远低于既定累计和新增硬限。原worker/guard及修复worker/guard均退休，不干预其他进程。

## 5. 后继决定

本轮收口：不继续扫类权重，不补步凑24项资格，不接教师/TaskRel/U。有依据的下一问题是：在同一CE风险与相同参数数量下，增加输入空间上下文能否改善三类拟合？现有e理论最大感受野为21×21，拟比较原局部e与将4个Residual block的卷积dilation/padding固定为1/2/4/8的e（理论65×65），不把这个假设写成已证实原因。

后继须另立协议，从本轮有效CE最终完整状态（总接口步1600）为共同来源；保留Adam/RNG、不重新初始化，两个臂均原CE、相同固定续接预算，唯一变量为卷积采样上下文。不重复本轮，不改变本轮负结果，继续共享首启时钟及全部占用。模型上下文通过也只是训练资格，不能当作Bayesian生成机制贡献或患者泛化。
