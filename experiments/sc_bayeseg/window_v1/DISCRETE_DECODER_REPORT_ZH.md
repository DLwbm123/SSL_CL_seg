# 离散类别解码器零更新诊断

仅两张canonical训练图；36类别前向、10分项诊断反向、0optimizer、0参数应用。固定终态推断参数，初/终生成后验×GT/BG编码；均值权重/code与8次既有流样本。完整模型/RNG/gradNone和源604物理账本不变，未访问保留图或U。所有数值为给定标签输入的生成重构，非图像预测。

终态GT输入CE优于最优常数基线，说明不能把模型等同于完全无空间信息的类频率常数。均值预测仍全背景、采样几乎全背景，说明亚阈值概率改善不足以恢复类别决策；8个样本不能代表充分后验积分。

GT/BG code均值RMS差固定.145296；输出概率RMS差从.050855降至.016417，生成器对编码的响应减弱，但并非严格零。终态GT输入的各类NLL为[.052955,1.599031,2.038847,2.844639]，前景明显差。其各类code梯度范数[.05557,.73384,.81641,1.11397]、解码器均值参数梯度范数[.33774,8.41816,8.65248,11.08408]，没有证据表明前景梯度全部消失。

终态按像素频率平均CE的解码器梯度与各类梯度余弦为[.18369,.31141,.06435,.24177]，此处原始负平均CE一阶支持各类损失下降；不等于Adam或有限步必然各类改善。初态对应余弦[.98779,−.03678,−.41038,−.35969]，当时存在明显类别方向冲突，不能把两个状态混为一谈。

下一检验固定同一终态：确定性类别条件重构中只优化生成均值，或同时优化标签编码器，保留原Adam，固定同样600步。它去除了随机权重/code与其余生成因素，只是容量/优化及编码瓶颈的诊断，不是完整ELBO，不把损失改善称为模型或图像预测成功。若两臂都不能拟合，仍需区分优化和表达，不能直接认定4×4解码架构不可能。
