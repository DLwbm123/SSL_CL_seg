# 推断坐标×生成后验零更新诊断

本阶段发现：原J初态对自身logits模板已经给出正空间/类别匹配；终态qTheta并未一致增强此信号。GT模板四格仍负。应将“固定GT模板不通过”与“生成端完全没有结构”区分，也不能把自身模板正值当作新训练写入语义的证据。

|局部坐标|生成后验|模板|空间总评分差|类别总评分差|

|initial|terminal|GT|-0.06990707|-0.00349259|

|initial|terminal|own|3.88501024|7.14252949|

|terminal|initial|own|3.76632214|6.49938679|
|terminal|terminal|own|3.78437090|6.49502754|

差值为原模板减固定滚动/通道循环模板；正值支持原模板。每格固定对应局部x/m/c，生成参数共同采样8次，不含标签似然。自身模板保留原logit幅度，没有选择最优温度。

在初态坐标中，终态后验使own空间差增加约0.01268，但类别差降低约0.01478；终态坐标中空间增加约0.01805，类别降低约0.00436。未见一致的新增空间和类别收益。原GT负值主要来自logits生成项；shape项为小正值。自身模板正值也主要来自logits项，因此必须检查code的自编码依赖，而非直接归因于图像→结构。

源码中q(c|ell)由code_encoder直接读取ell，生成p(ell|c,Theta)回构ell。固定原c后扰动ell导致低分，可能包含这种自编码一致性，不能证明类语义已经独立识别。下一步做固定c、随每个反事实ell重新推断c、交换两图c三种读出；不训练，不用结果选code或温度。

首版已完成384评分，但own概率比值下溢产生非有限值，JSON失败。v2用log_softmax及对数差稳定计算等价模板，在新目录追加384评分；全部有限，旧GT锚点在1e-5内复现，退出0。累计768批量生成评分，0optimizer、0反向；失败、私有评分和成本完整保留。这不是训练失败恢复，也没有重跑训练。

聚合数据及分项/逐图/正比例见[COORDINATE.json](results/COORDINATE.json)。仍只用两训练图，本结论不涉及泛化、U或持续学习效果。
