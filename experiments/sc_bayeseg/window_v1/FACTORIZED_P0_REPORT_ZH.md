# P0：冻结图像通路与高斯参照诊断结果

**结论：图像通路存在部分位置／类别信号，但没有一致支持完整GT。平移与第一类删除可辨别，第二类删除和后验平均第三类删除反而更优；图像交换信号弱。建议进入有界的分块推断诊断，而非继续训练anatomy或增加R。**

## 图像交换和权重混合口径

pair为两张图matched减crossed的每像素得分之和；均值权重和后验Elog分别为：
- gaussian_per_pixel：+0.00012217／-0.00012713。
- student_fixed_proposal_B：+0.00022858／-0.00006553。

两图标签不同，但matched优势并不稳定。不能说图像通路完全无信息：固定平移32像素与删除类1的差值明确为正；也不能认为已有可靠图像辨别力：删除类2两图两口径均更优。

高斯后验预测混合在整图logp上logsumexp后除N；GT−BG两图分别为[-0.0003008803691997852, -2.5944766490204607e-06]。它与Elog不是同一评分。32draw整图混合可能由少数draw主导，不能当精确Bayes factor，完整数值见匿名JSON。

原Student图像块仍使用固定独立qx(I)qm(I)，是受限下界而非边缘图像似然。Gaussian是等方差替代诊断模型，即使完全积分也不是原Student模型的精确证据。部分正差值不能替代无标签像素预测，当前未训练识别器。

## 核验与成本

FP64 FFT对独立8×8稠密协方差参照loglik误差0、二次型误差7.11e-15。231次批量structure前向、924次原图像块密度、32组Theta draw；连续账本、模型/先验/RNG/gradNone、源604更新及前序1000反向账本不变、EXIT0通过。模型进程已退出。运行空间四根保守合计1,356,214,272字节，低于20GB。

匿名JSON含每图、每draw、所有候选、各原因素、MC标准误及正比例。标准误仅表示32draw的MC波动，不是患者总体置信区间。结果不用于修改候选、挑权重或标签调参。
