# fine100停滞：目标方向与非语义幅度分解

## 结果

从fine/S100完整状态、原下一次训练RNG出发，全部固定条件不变。原单噪声严格共同语义方向+完整非语义Adam候选，在8个固定尺度均未过；两种最小干预各自有通过格：

| 语义方向 | 非语义候选幅度β | 通过的非零语义尺度α |
|---|---:|---|
| 原单本步目标 | 1 | 无 |
| 原单本步目标 | 1/4 | 1/16、1/64 |
| 原单本步目标 | 0 | 1/16、1/64、1/256、1/1024 |
| 当前+两验收目标共同方向 | 1 | 1/16 |
| 当前+两验收目标共同方向 | 1/4 | 1/16、1/64 |
| 当前+两验收目标共同方向 | 0 | 1/16、1/64、1/256、1/1024 |

β=0只是零更新因果对照，不是新的持续训练终态；不把冻结其他参数称为联合学习成功。不同通过集合不等于长期训练表现，本轮据此另立同态配对协议验证两个因素。

## 方向解释

原单目标方向对当前/ξ1/ξ25的标准化联合导数分别−0.016588、−0.008258、−0.027695；同时对齐三目标后分别−0.016543、−0.016543、−0.026873。

所以不是“当前方向一阶上反对验收目标”，三者原本都为负；改变方向增强了较弱验收目标的下降余量，从而在已测有限尺度恢复通过。非语义幅度缩小也能独立恢复通过，说明未缩放分块更新与有限语义步骤的组合存在额外风险。

另将原Adam单位候选在100参数全空间投影到16语义+3联合的线性不增锥。投影非零，范数0.920674，原空间最大标准化导数约8.44e-15；三个目标单位方向导数分别−97.2741、−114.0630、−85.5635。按相同r0全参数一起缩放，α=1/64、1/256通过实际门限。该投影存在切向语义约束，不能只凭一阶证据保证安全；本阶段未将其加入后续四臂，避免同时混入第三因素。
