# 冻结生成器的code切空间与4×4特征空间检验

两臂自由code100仍未充分拟合，检查16维code映射是否阻挡有用类别方向。仅原两训练L四翻转8视图，模型来自recon fixed/code各自S0600，局部code固定为code_local各自S100，不读保留/U/目标。全部100模型冻结，无optimizer、无局部迭代、无模型/局部状态写回。

h=ReLU(Wc+b)reshape(16,4,4)，固定原上采样和后两卷积。显式重建h精确复现原anatomy输出。每臂对背景/三前景各自按类平均CE及总像素CE求h梯度5次，共10次反向。每视图J=diag(preact>0)W，FP64 SVD、相对最大奇异值1e-10确定列空间，检查投影残差/幂等性，报告rank和总CE梯度在列空间内外的范数比例。rank仅此ReLU活跃区域，不是全局容量证明。

负总CE梯度构造full_h与投影至range(J)的code_tangent_h两方向。两方向逐视图均规范为相同h的RMS半径：该臂先前code_local的c0→c100真实h差RMS；full_h在h=0坐标禁止负方向，code切空间方向在这些零Jacobian行置零；为保持ReLU后非负性，两方向共用的最终半径再取不越零最大半径的一半与上述实际半径之小者，分别报告限制前后半径。零方向/零半径明确记录，不造新尺度。固定alpha1,1/4,1/16,1/64全部评价，不择优；共两臂×两方向×四尺度=16批量特征候选，另两臂各起点h和原code复现前向=4，以及两臂梯度图前向=2，总22前向、10反向、16候选，0optimizer/模型应用/局部接受步。
