# R-START-v1：冻结 G 的 image-only 共同语义读出

2026-10-20，用户在审阅 Pro 最新四臂建议后明确指令“立即开始实验”。该指令解除此前“不启动”的限制；本协议在第一次实际计算之前登记。它不修改历史实验。

## 科学问题与解释边界

检验图像侧推断器能否使用现有标签生成器 G，以及直接监督辅助能否改善生成读出、生成损失是否影响共享表示。G:(c,R)→Z；F:Z→x。本轮预测不经过 F 或 B，不将结果称为图像生成似然纠正未知标签、完整 ASVI、半监督或持续学习收益。

唯一源为 P2 所用 spatial_generator/S0600，全模型 cursor8675、population=(2L,0U)。不选 structure-only 的新端点。全部原100模型张量及 prior/initial buffer 固定，原 Adam 不加载进新优化器、不更新；运行时记录私有 checkpoint 定位与已有来源回执、文件元数据，载入后及端点核对源模型状态。源文件只读，不为本轮复制大型旧产物。

## 数据与结构

只读取原 PRIVATE_SELECTION 的两张 canonical Siemens 训练 L。沿用128×128图像双线性插值、标签最近邻，四种水平/垂直翻转，共8视图，每步完整 batch=8，顺序为(view0图0/1，view1图0/1，…)。不读取保留图像/标签、隐藏test、真实U或目标域；不增加训练seed扫描。两图结果只表示机制/训练可行性。

新增同一次随机初始化的接口：e 为已有 inference_net(1,16,width16,4个Residual block)；D 为1×1卷积16→4；Hc 为特征全图均值→Linear16→32→ReLU→Linear32→32，分成16维均值和logsd原量；HR 为完整空间特征的非重叠8×8均值→1×1卷积16→32，得到16通道16×16网格的均值和logsd原量。两者logsd均采用既有光滑边界 −4+3tanh(raw/3)。第一版q(c|I)q(R|I)均为对角Gaussian，prior均标准Gaussian；不宣称随机变量相关。

初始化seed=20261020，仅初始化一次保存并复制四臂；它是新增模块随机性，不能写成零新增随机性。初始化来源、训练噪声、评价噪声分离；e/D无dropout、BatchNorm或随机操作。不会通过全局池化消除R的空间输入。

## 目标与比较臂

令N=128²，C=mean_batch CE(D(e(I)),Y)，A=mean_batch{E[−log pG(Y|c,R)]+KLc+KLR}/N。类别项先对像素求和再除N（实现为像素平均），局部KL只计一次；G固定，不加入global KL常数。G参数冻结不等于no_grad前向，必须保留对c/R的梯度。

|臂|可训练模块|目标|
|---|---|---|
|R0|e,D|C|
|R1|e,Hc,HR|A|
|R2|e,D,Hc,HR|A+C，权重1|
|R2-SG|e,D,Hc,HR|A+C，但H输入为stop_gradient(e(I))|

每臂独立一个Adam：lr3e−4、betas(.9,.999)、eps1e−8、weight_decay0、foreach=False、固定学习率、FP32、无AMP、无TF32、严格确定性。e、D、H分别独立clip L2≤1，Hc/HR合为H组；不跨组裁剪。每臂恰600次实际optimizer.step，合计2400次，训练反向2400次；不作额外golden optimizer更新。必要资格仅2次诊断反向、0optimizer，成本单列。

训练每步2个G参数后验样本×每Theta2个c/R样本。仅抽取G的三层Gaussian权重；固定随机流相同step跨臂配对，Theta seed=720163+step、local seed=820163+step。R0不调用G。R0与R2-SG的e/D参数及Adam状态在step0和每25步逐项精确核对，共25次；最终直接预测指标也必须相同。若失配立即停止并保留现场，不解释成科学差异。

## image-only接口与固定评价

predict只接收接口、冻结G、图像和采样配置，不接收Y、身份、切片索引或标签条件局部状态，不从预测函数访问dataset。资格核对G对c/R和e的有限非零梯度、SG无e梯度但H有梯度、prior的Gaussian KL为0、固定流在外部评价标签上下文改变时预测不变。资格失败0训练更新停止。

固定记录0/200/600，唯一主要终点600，不按200步表现改终点、选臂、调权重或追加预算。每100步保存完整接口/Adam/RNG/成本；0/200/600另保存私有预测。预测先完成并封存，再由单独评价函数读取GT。生成读出每次使用4流seeds=[620163,630163,640163,650163]，每流8Theta×8local，先每样本softmax再平均概率。四流各自报告，并等权平均作主读出；不平均logits，不融合两头，不择优。

直接表：R0-D、R2-D、R2-SG-D；生成表：R1-G、R2-G、R2-SG-G。完整八视图逐图逐类Dice、前景macro Dice、class2 precision/recall、预测面积比例、像素边缘混合NLL、Brier及四流波动。分母为0的precision/recall为null；不以0或1替换NA。训练的E[−log p]与预测的逐像素−log E[p]分开，后者不冒称整张空间联合标签的边缘NLL。

训练可行性门槛为8视图×3前景类各Dice≥.8；未通过仅表明该配置在600步内未建立资格，不是模型全局不可行。两图训练超过R0不是方法有效性的必要/充分证明；任何患者泛化和生成知识增量须另立评价。

## E0：独立合成小网格核对

在R完成后独立输出E0，不作为R前置关卡、不自动进入E1。只用8×8与16×16合成Gaussian图像/u、周期SAR α=.9、Gamma shape2/rate(.1²,.2²)、m prior precision4。FP64稠密联合参考对Schur均值、完整协方差、cross协方差、logdet误差<1e−9；完整残差二阶矩误差<1e−10；标量Student/Gamma消元解析式与现有密度误差<1e−12。每网格固定10扫掠（≤50），检查增广CAVI目标不降；不读医学图像、不评分GT/BG。独立2h硬上限（提前中断留余量）、新增<2GB，实际极小；不把条件Gaussian精确或增广下界当Student边缘精确证据。E0失败保留结果，不重跑已完成R。
