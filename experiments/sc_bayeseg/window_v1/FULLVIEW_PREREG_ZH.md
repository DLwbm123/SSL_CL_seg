# 同四视图的全均值梯度：监督可行性控制

循环flip4完成1200步但训练四采样Dice63.10%，资格失败，原协议不转joint、不换plain或中间checkpoint。下一阶段检验相同视图目标的梯度估计，而非扩增广或改损失。

从同一coupled/robust_quarter/S50完整状态cursor3175重新分叉，保留全部Adam/scheduler/RNG，确定性mean CE、lr3e-4、clip1、FP32。40语义张量训练、60非语义模型和Adam冻结。每步把同两L的none/h/v/both四视图合为batch8，对全部像素CE求均值。这是原循环四视图目标的完整均值梯度，不含新患者、seed、旋转/强度/裁剪、类别权重或联合项。

固定1200正式步+首末各2次golden共4工程，实际optimizer上限1204。每步前RNG与已保存原配对轨迹比较1200次（mean CE没有局部采样，Theta.draw消费与batch大小无关）。首末完整model/Adam/scheduler/RNG/损失golden对必过。变换和逆变换复用已完成资格回执，不重跑旧训练。每100保存完整checkpoint、所有实际调用连续记账；故障保留partial不自动重跑。

只在0/300/600/900/1200评canonical两train+两heldout，另评两train的全部四视图，均值+既有50163四采样。每步训练不看heldout；评价保存恢复RNG，不以其早停、调参或选择checkpoint。最终报告全部轨迹与循环臂。300步（2400图像）对比循环1200步同图像暴露；1200步对比循环1200步同优化次数但4倍图像暴露。两者均非同时匹配全部计算因素，明示差异。
