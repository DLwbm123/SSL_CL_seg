# code切空间与4×4特征空间方向检验

原两训练图四视图，冻结fixed/code两臂全部权重，在其自由code100终态比较。10反向/22前向/16特征候选，0optimizer、0模型或局部更新。三连续账本、h/code精确复现、FP64 SVD投影、模型/RNG/源1208物理和200局部账本不变、EXIT0均通过。无保留/U/目标。

## 主要证据

每视图16维code到256维ReLU后4×4特征的Jacobian列空间，只保留总CE梯度范数的fixed约11.8%—20.0%、code约15.3%—21.5%；这是范数比例，不是保留能量比例。大量有用局部梯度不在当前code映射切空间中。ReLU活跃区域的局部投影不代表整个非线性模型全局容量。

在逐视图相同有效特征RMS半径下：

|臂|起点CE|完整特征负梯度alpha1|code切空间投影alpha1|
|---|---:|---:|---:|
|fixed|.0841682|.0818998|.0835557|
|code|.0528912|.0516188|.0526045|

完整特征方向CE下降约为切空间候选的3.70/4.44倍，且两臂四类平均NLL均下降。四个预定alpha全部公开，没有择优。候选不是训练或合法Gaussian后验：两方向都直接替换内部h，有限切空间候选也未保证存在相同真实code。

## 控制和限制

起始半径来自先前c0→c100真实特征位移；为保证ReLU后特征非负，共同半径被两方向的越零界进一步缩小。有效半径最小约2e-5，部分视图很保守，不能声称已充分探索；大幅改善潜力仍未知。完整方向在零h处禁止负位移，不以负隐藏特征制造优势。

结果支持当前16维映射限制了可利用的局部下降方向；不单独证明16维总体信息不足，也不排除优化/解码器本身限制。下一步仅做冻结解码器、非负4×4自由特征的局部条件拟合，检验额外方向能否持续恢复第二类，不把它直接纳入原概率模型。所有标签条件重构均非图像预测，尚无SSL/CL或泛化成功证据。
