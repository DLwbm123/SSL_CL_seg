# Structure只读分解：均值、方差与类2响应

2026-10-20。0optimizer/0反向/0局部更新，只交换已完成F干预的均值/方差端点并读取类2删除响应；本轮不是重新训练或无GT图像预测。四格固定P2旧局部q，00=旧mean旧sd，10=新mean旧sd，01=旧mean新sd，11=新mean新sd。

## 决策摘要

- **不是“方差变化导致类别损伤”。** 新mean/旧sd的端点交换，对两个初始化全部四项相对指标均有负变化；旧mean/新sd对GT−BG、GT−DELETE2反有小幅正变化。方差并没有解释掉均值端点的损伤。
- **KL下降来自均值回到prior附近，而非variance KL下降。** F mean KL/(2N)由.01947936降到.01307844，下降.00640092；variance KL由.00002785升至.00004742，增加.00001957。不能把原“92%来自KL”误读成“92%由方差收缩引起”。
- **目标与类别支持仍不一致。** 仅交换新mean时，GT B变化−.00100737（MC未决），但坐标负目标因KL下降而改善−.00539355；只交换新sd时，GT B改善+.00155228（MC正）。四格不能替代独立训练轨迹，但明确否定了优先责怪方差的简单解释。
- **类2响应存在但减弱。** 两图类2区域D_F RMS分别.18333→.17224、.19966→.16929，支持范围检查通过；F输出不是完全无标签响应。两图在radius3腐蚀后类2内部均为空，全部类2像素属于该定义下边界，不能用“大块同类内部缺上下文”直接解释本类结果。
- **暂不盲启动mean-only训练。** 下一步优先只读分解训练条件项与均值KL的梯度，并检查实际Adam候选对类2/背景对比的一阶方向。若KL或数据项与类别支持冲突，应先明确冲突位置；本轮不改变KL、不加排名损失、不换架构或加入U。
