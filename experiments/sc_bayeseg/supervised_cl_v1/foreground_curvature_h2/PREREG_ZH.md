# H2：前景平衡预测 Fisher 精度的无回放三中心实验

**状态：前瞻冻结协议。** 本协议、`curvature.py`、`run.py`、`evaluate.py`、`summarize.py` 先提交，再读取任何 H2 真实训练病例或启动正式优化。H1 的[负结果](../hierarchical_bayes_h1/results/DECISION_ZH.md)已独立封存，不回改其模型、门或矩阵。H2 是针对前景保持的独立机制实验，不是给 H1 搜索 Q、λ0、损失权重、阈值或 checkpoint。

## 观察、假设与唯一机制差异

H1 无过程噪声 F0 在 I2CVB 后比成像噪声 F_A 更能保留旧域，但 RUNMC/BMC 仍仅 66.477%/57.624% Dice；旧域 precision 为 98.524%/93.706%，recall 仅 50.760%/44.732%。**待检验假设**：原在线 Gaussian 的像素平均 CE 预测 Fisher 将曲率质量主要放在背景区域，对保持前景相关参数不够有效；等质量地分配给模型预测的前景与背景可能保护旧域前景召回，同时保留新中心学习。上述是开发 val 提出的机制假设，不是已证实因果。

两条过滤器均沿用 H1 的条件成像／多尺度解剖模型、源曲率初始化、每批广义风险、对角均值／精度更新、λ0、无过程噪声 F0、识别网络 AdamW、batch4、6000 步及 MC16 部署读出。唯一候选变化是预测 Fisher 的像素权重：令当前训练批的部署 logit 为 `z_i`、`p_i=sigmoid(z_i)`，原 standard 的 `w_i=1/N_pixel`；balanced 固定为

`w_i = 0.5 p_i / max(sum_j p_j,1) + 0.5 (1-p_i) / max(sum_j(1-p_j),1)`。

两臂都用同一两探针 Rademacher GGN 代理，对 logit VJP 的系数为 `sqrt(p_i(1-p_i) w_i)`；仅从当前模型对**当前中心 train 图像**的预测计算，不用旧标签、旧影像或旧模型。源 RUNMC 仍为当前中心时，对同一训练患者集分别计算两份源曲率精度；离开源域后只留各臂唯一当前模型均值与对角精度，不保留旧训练数组／教师。balanced 与 standard 的预测风险、模型架构、随机流及正式更新数相同；额外曲率与推断成本单列。U-FT 仅按固定 BasicUNet 标准配置提供公平的新域参照，不优化它。

## 冻结样本、顺序和预算

沿用已审计的 prostate seed0 `all_train` 目录：RUNMC 18、BMC 18、I2CVB 11 名训练患者；顺序 RUNMC→BMC→I2CVB。每次优化进程只载入**当前中心** train，换域前释放旧数组；既往域 val 由独立只读进程按 0/1500/3000/6000 固定步评估，前缀 val 为 4/4/3 名已反复用于开发的患者；test 完全封存。患者级 Dice、precision、recall、惩罚 HD95、p10、最差患者、零重叠和到达后遗忘完整保留，先患者内、再中心内、再中心等权汇总；不得按 val 选训练步或阈值。

新固定种子 **20261028**，在 H2 训练病例读取前确定。U/C 两个源模型骨干初态逐张量相同，源各 8000 步；C 源状态精确分成 standard/balanced 两臂，BMC 和 I2CVB 各臂各 6000 步：`2×8000+3×2×6000=52000` 次正式物理更新，8 阶段。两份源曲率各 18×8=144 次调用、每次两探针；另有 1 次丢弃的真实 BMC 工程更新。等步数不等实际算力，如实报告。

## 预定积极信号门

所有条件同时满足才进入后续六域研究，任何一项失败都关闭**本固定候选**：

1. U-FT、standard、balanced 的所有当前域终点 train Dice ≥80%。
2. BMC 与 I2CVB 的 balanced 新域 val Dice 均 ≥`max(U-FT,standard)−1 pp`，对应 train Dice ≥`max(80%,standard−2 pp)`。
3. I2CVB 终点 balanced 的 RUNMC/BMC Dice 各 ≥70%；旧两域平均到达后遗忘 ≤10 pp，任一旧患者下降 ≤15 pp。
4. 三域等权 balanced Dice ≥U-FT+3 pp 且 ≥standard+2 pp；最终旧患者相对 U-FT、standard 各自的最差配对差均 ≥−5 pp。
5. 三域等权惩罚 HD95 ≤`1.10×min(U-FT,standard)`；所有固定旧域读数不新增本站首次学完时没有的零重叠患者。

旧域 recall 差及其 precision 代价、源与新中心的曲率分布另列机制诊断，不用它们事后替换门。即使过门，单种子和复用的 11 名 val 仅供开发筛查；独立种子、六域与 test 必须另立冻结确认协议。失败不通过调 Fisher 权重、精度、损失或 checkpoint 补救。
