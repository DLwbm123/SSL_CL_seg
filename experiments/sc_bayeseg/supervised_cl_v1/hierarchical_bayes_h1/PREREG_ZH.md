# H1：无旧数据、无旧教师的条件层级与在线权重 Gaussian

**状态：三中心机制包的前瞻冻结协议。** 本文件及 `model.py`、`online.py`、`run.py`、`evaluate.py`、`summarize.py` 必须在任何 H1 训练患者读取或正式优化前提交；既有 B/U、P1、C1 结果及独立运行中的 N1 协议均不回改。方案依据[现有六中心匿名证据](../results/CONSOLIDATED_SUMMARY_ZH.md)和 [BONG 原论文](https://papers.nips.cc/paper_files/paper/2024/hash/ecffd829f90b0a4b6aa017b6df15904f-Abstract-Conference.html)，不宣称原论文精确复现或精确 Bayesian 推断。

## 研究问题与访问边界

首批只研究 RUNMC→BMC→I2CVB：在直接决定分割的成像／解剖通路中，唯一当前权重均值与对角精度能否保存旧域知识，同时将有限过程噪声优先给成像通路，使旧患者不再于第三域坍塌且新域仍能学习？

使用原 prostate seed0 的全部授权 train 标签：RUNMC 18、BMC 18、I2CVB 11 名患者。每阶段优化进程仅载入**当前中心 train**；离开中心即释放病例数组，不重读旧 train，不保存旧图像、标签、特征、预测、旧模型或教师。已见中心 val 仅由单独只读评测进程访问；前三中心分别 4、4、3 名，均为项目反复用于开发的患者。test 完全封存。各实验臂是独立的当前模型；从同一已完成源状态或同一当前 BMC 状态分叉只为配对，不互相提供预测或权重目标。阶段快照仅供独立评测、审计和故障恢复；正常后续训练只延续内存中的当前模型与精度，不把旧快照当训练输入。

## 直接参与部署的条件模型

- 成像先验网络为 `12→32→12` MLP，实际参数 812。12 个输入统计依次为图像均值、标准差，分位点 0.1/0.2/0.3/0.5/0.7/0.8/0.9，以及固定 `cos(πx)`、`cos(πy)`、二者乘积的平均投影。输出六维原始成像变量的均值与 log-SD；初始均值 0、SD 0.1，log-SD 限于 `[−7,0]`。六维通过 `tanh` 映射：α、κ 限于 ±log2，δ 限于 ±0.25，三个低频 β 限于 ±0.1。变换及解析逆为 `I=exp(α+Bβ) sinh(exp(κ) asinh(C))+δ`，不裁剪、不重采样。
- 对规范化图像 C 使用同一 MONAI BasicUNet 骨干，通道 `(32,32,64,128,256,32)`。两类 logits 之差经两级正交 Haar 化为 c `(1,64,64)`、u `(3,64,64)`、v `(3,128,128)`；逆变换完整重建 256² 场。条件 prior 均值依次为 `Hc(logit)`、`Hu(logit)+Fu(c/4)`、`Hv(logit)+Fv(up(c/4),up(u/2))`。Fu 为 `1→16→3`、Fv 为 `4→16→3` 的两层 3×3 Conv/ReLU，末层零初始化；三层 prior SD 初始 .2/.1/.05，log-SD 限于 `[−7,1]`。分割概率是逆 Haar 场的 sigmoid。所有部署路径参数包括成像先验、骨干、细化器和 prior 方差，合计合成 P0 所见 1,980,903 个，均纳入当前 Gaussian 权重状态。
- 训练识别网络 φ 只在**当前 train**使用标签：成像 q 输入上述 12 个图像统计及标签面积、x/y 质心、边缘比例四个统计，MLP `16→32→12`；另有 1→32 图像特征干线，以及 c/u/v 的 `34/37/40→16→2/6/6` 残差头。u 头额外见采样 c 与 prior 概率，v 头额外见采样 c/u 与 prior 概率。残差头初始 0，q 初始等于条件 prior。部署不能调用 φ 或标签。
- 局部 q 的负条件 ELBO 为一个标签条件祖先采样的 Bernoulli NLL，加成像/三级形状条件 Gaussian KL 之和除以 65,536 像素。总训练风险固定为 `0.5×局部负ELBO + 0.5×部署prior单样本CE + 部署prior单样本soft-Dice`。这属于广义 Bayesian 风险；Dice 与混合目标使其不是完整模型的精确似然。部署每批固定 8 对相反基噪声、共 16 个 prior 祖先样本，平均概率后阈值 0.5；权重只读当前均值，不声称完整权重 posterior predictive。

## 唯一当前权重后验及优化

预测参数分成 θ_A（812 个成像先验 MLP 参数）和 θ_S（其余部署参数）。维护唯一当前 `q(θ)=∏N(μ_j,λ_j⁻¹)`；φ 是同一当前模型的确定性训练模块，不属于部署权重分布。训练损失对 μ 求 g；用部署标签 CE 的两个固定 Rademacher VJP 探针估计非负对角 GGN 代理 h，探针系数 `sqrt(p(1-p)/(B×65536))`。这是混合风险的曲率代理，不是其精确 Hessian。g 全参数全局范数裁剪 5，并记录触发比例；θ 的 μ 不再由 AdamW 更新，φ 按原 AdamW 当前域更新。

每个新中心开始只注入一次相对过程方差 Q，然后每批以 `α=65536×N_train/6000` 执行：`λ_new=(λ_old⁻¹+Q)⁻¹+αh`（后续批 Q=0），`μ_new=μ_old−αg/λ_new`。源域 C 先以原 AdamW 完成 8000 步；仍在 RUNMC 当前域时，每患者按 seed+患者哈希抽 4 个前景池、4 个全切片池位置（必要时有放回），固定增强和两探针，患者等权求 `h_source`，置 `λ_source=λ0+65536×18×h_source`。Conv/Linear 权重 `λ0=fan_in/2`，其余参数 `λ0=1`。源曲率 18×8=144 次，另记探针成本。精度 float32、有限且严格为正；不暗加上限、衰减、后验旧均值 KL、权重 MC 或验证驱动的补救。

四个过滤器共享相同源 `(μ,λ)`：F0 无 Q；F_all 对全部预测参数用 `Q_j=(812/Pθ) λ_j⁻¹`；主候选 F_A 只对 θ_A 用 `Q_j=λ_j⁻¹`；F_perm 只对由 seed、参数名和坐标确定性选出的 812 个非成像位置用同样相对 Q。后三臂总相对方差预算都是 812；同一位置集合跨域保持。θ_S 在所有臂仍参与梯度。F_erase 在 F_A **刚学完 BMC** 时从其当前模型分叉，μ和 φ 相同，仅将当前 λ 重置为 λ0，再以 F_A 的 Q 规则学习 I2CVB；它只检验累计精度的操作作用，不能称完全擦除历史。

合成标量 Gaussian 更新对 1/10/100/6000 等证据拆分须与解析后验一致。初步合成 P0 曾发现：若遗漏上述源曲率初始化、直接从裸 λ0 开始，大尺度广义更新可能迅速发散；该错误起点不属于正式协议。补齐源初始化后同一合成设置 100 步有限且损失下降。正式结论仍以实际完成源训练后的真实精度、真实当前批 P0 和完整患者表现为准，不把合成拟合称为医学证据。

## 固定实验矩阵与实际计算

种子 **20261026**，顺序 RUNMC→BMC→I2CVB，batch4 全来自当前域、患者等权、前景切片概率 .5、原几何/光度增强。U-FT 是原 BasicUNet 顺序 AdamW 微调；C-FT 是上述条件模型顺序 AdamW 微调；F0/F_all/F_A/F_perm 共用 C 源状态但各自保持唯一当前 μ/λ；F_erase 仅进行 BMC→I2CVB 6000 步。U 与 C 的骨干初态逐张量相同。源 U 8000＋源 C 8000；BMC 六臂各 6000；I2CVB 七臂各 6000，合计 **94,000 次正式物理更新、15 个阶段**，另有一次真实 BMC 丢弃的 P0 工程更新。等步数不等 FLOPs；源曲率、探针、16 样本评测和工程检查都单列成本。不复训 ER、PPR、缓存容量或 Joint。

每个新域在更新 0、1500、3000、6000 固定评估所有已见域 val；源仅在 8000 终点评价。每域 train 拟合只在它仍为当前域的终点评价。患者级 Dice、precision、recall、惩罚 HD95、p10、最差患者、空预测和零重叠完整保留；主汇总先患者内、再中心内患者等权、再中心等权。旧患者相对该臂首次学完该域的变化与臂间配对差分列；所有阶段内读数保留，不用终点恢复掩盖中途坍塌。固定终点，不按 val 选训练步、checkpoint、seed、λ0、Q、损失权重或 MC 数。

## 预定三中心继续门

所有条件必须同时满足，属于前瞻工程筛查，不是临床非劣或独立统计确认：

1. U、C-FT、F_A 每个当前域的终点 train Dice 均≥80%；其他过滤器训练不足仍完整报告。
2. BMC 与 I2CVB 的 F_A 终点 val Dice 各≥`max(U,C-FT)−1 pp`，对应 train Dice≥`C-FT−2 pp`且≥80%。
3. I2CVB 终点 F_A 的 RUNMC、BMC Dice 各≥70%；旧两域平均到达后遗忘≤10 pp；任一旧患者到达后下降≤15 pp。
4. 三域等权 F_A 分别高 U、C-FT 至少 3 pp，分别高 F0/F_all/F_perm 至少 2 pp；高 F_erase 至少 3 pp，且新 I2CVB Dice≥F_erase−1 pp。
5. I2CVB 终点旧患者相对 U 和 C-FT 的最差配对差各≥−5 pp；三域等权惩罚 HD95≤`1.10×min(U,C-FT)`。
6. F_A 所有固定旧域读数不新增本站首次学完时没有的零重叠患者。

任一门失败则关闭此固定候选，保留所有结果；不调 κ、λ0、证据量、噪声坐标、风险权重、优化器或 MC 读出救分。全部通过才可从同一当前模型状态、同一首次时钟和目录继续后三中心 UCL→BIDMC→HK 六条链，各域 6000 步，最多再 108,000 次；首种子总上限 202,000。六域候选门也预先固定：最终 F_A 六域等权 Dice 分别高 U/C-FT 至少 2 pp、分别高 F0/F_all/F_perm 至少 1 pp；每个新中心终点 Dice 对 `max(U,C-FT)` 不低超过 1 pp 且 train≥80%；每个阶段终点旧域等权到达后遗忘≤10 pp、任一旧患者下降≤15 pp；最终各旧中心 Dice≥70%、相对 U/C-FT 旧患者最差配对差≥−5 pp；最终等权惩罚 HD95 对 U/C-FT 均≤1.10 倍；所有固定读数不新增旧域零重叠。续行代码和门必须在续行前实现并审计，不能从三域结果临时改门。即使六域过门，一个种子且复用既有 val 仍非独立确认；新增种子、替代顺序和一次 test 开封另立冻结确认协议。
