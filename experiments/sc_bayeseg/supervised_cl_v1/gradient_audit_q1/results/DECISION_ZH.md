# Q1 梯度诊断：固定候选门未通过

Q1 的[预注册协议](../PREREG_ZH.md)与[源码](../audit.py)在读取 Q1 样本／梯度前提交于 `f374c29a`。真实 NAS 挂载、创建写读探针、可读的既有终点模型与缓存、GPU 余量及中性进程命令行均通过准入。两个模型的完整梯度检查通过。独立实验完成 64 个配对训练批次、**0 次优化更新**，退出码 0；从原始启动时钟到完成约 86.8 秒，新增目录不足 0.1 MB，未达到 23 小时／50 GB 限额。旧域只使用首批保留的 32 张训练切片；当前域只读取 HK train，未读取 val 或 test。

生成项与旧域任务梯度的余弦在 **79.7%** 批次为负，但生成项梯度范数仅为旧域任务梯度的中位数 **0.069 倍**，加入生成项后的旧域任务对齐余弦中位数变化为 **−0.001**。预先定义的候选门同时要求负余弦比例至少 50%、范数比中位数至少 0.10、对齐余弦变化中位数不高于 −0.05；后两项失败。U/B 的新旧任务梯度余弦中位数分别为 0.044/0.073，说明一般的跨域任务方向也并不高度一致。[匿名聚合](PUBLIC_SUMMARY.json)保留完整统计。

因此，本诊断**没有支持**“在最终重放检查点，生成项以足够大的原始骨干梯度直接压制旧域任务”这条具体解释。它只评估固定末端检查点的局部梯度，不能排除训练早期、AdamW 动量、数据覆盖或表示结构等其他机制；也不能从梯度方向推断患者分割的因果改善。不据此更改首批结果、阈值或同一模型的训练配置。
