# 2026-10-25 用户方法范围更正

用户明确指出：其持续学习方法在学习新中心时**不回放此前中心的数据，也不保留此前阶段的模型**。后续主线协议须以这两条为硬约束：旧中心训练影像、标签或缓存不能重新用于参数更新；方法运行时不能保留或调用旧模型副本、冻结教师。持续更新的当前模型可以跨阶段传递。历史检查点如为审计而留存，不得成为方法输入。旧域验证结果仍可用于按冻结协议评估遗忘，不作为训练输入或事后调参依据。

此前的冻结协议、运行记录和数值结果保持原样；这份说明更正它们相对于用户方法的归类，而不追认其为用户方法的效果：

| 已完成或在跑的路线 | 训练时的旧域访问 | 当前归类 |
| --- | --- | --- |
| 首批 B 顺序微调 | 不回放旧数据，后续训练不调用旧阶段模型 | 符合两条访问约束的 BayeSeg 启发式架构基线；尚无单独的抗遗忘机制 |
| 首批 B 的 ER、P1 的同源 ER | 使用 32 张旧域带标签切片 | 放宽数据访问约束的经验参照 |
| P1 的 PPR | 使用旧域切片，另保留上一阶段冻结教师 | 同时放宽两条约束的经验参照；不能称为用户方法的正结果 |
| C1 的 Prefix/Coverage 和离线联合训练 | 使用旧域切片或同时访问全部中心 | U-Net 诊断与全数据参照，均非用户方法 |

用户允许将 P1 等路线作为“upperbound”参照来理解额外访问可能带来的效果。这里的 *upperbound* 指放宽约束的经验参考，**不保证其 Dice 在数值上高于**无回放方法。跨独立运行的数值也不能直接当成配对优势。P1 的已冻结候选门仍按原协议判定为失败，不能因重新归类而更改。

已启动的 C1 按原冻结协议完成、审计和匿名交付，不因本次归类更正中途改训练。其后任何声称是用户方法的实验，须先写明无旧数据回放、无旧模型／教师的实施方式，按研究目的冻结假设、访问边界、对照、预算、患者尾部和新域安全门；不能把 ER 或 PPR 再命名为主线机制。
