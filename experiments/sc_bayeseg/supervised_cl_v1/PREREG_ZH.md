# 六中心全训练标签持续学习：BayeSeg 层级与 U-Net 配对协议

**冻结点**：本协议和代码提交后，才启动首次正式优化更新。实际时钟、NAS 基线、GPU 准入和清单指纹另记启动报告；结果不回写本协议。

## 问题与数据边界

用户明确要求全部原 `split=train` 患者的真值标签用于新的全监督持续学习，并保留 BayeSeg 形状／外观生成层级，与 U-Net 比较。冻结 prostate seed0 患者划分，训练病例 69 名：RUNMC 18、BMC 18、I2CVB 11、UCL 8、BIDMC 7、HK 7。原训练清单里部分病例曾标为 `train_unlabeled`；本轮只在独立私有清单中重新赋予训练标签路径，不修改原 HDF5、清单、旧 LCR-Seg V0.1 或既往结果。六中心 val 共 17 名，仅探索性评估；test 完全封存。既往项目已多次使用部分 val，不能称本轮独立外部确认。

顺序固定为 **RUNMC → BMC → I2CVB → UCL → BIDMC → HK**：先沿用项目已有 RUNMC→BMC 起点，其余按训练病例数降序排列，7 名患者的并列中心按字母序。顺序、患者集合、预处理、随机种子和评价域均不因观察结果变更。一个固定训练种子 `20261025`，仅作探索性首批；患者、切片、体素不混作独立样本。

## 配对模型与训练

- 两者使用 MONAI 1.3 的同一 2D BasicUNet，特征通道 `(32,32,64,128,256,32)`，输入冻结预处理的原生 256×256 单通道切片，输出二类整前列腺分割。相同种子下骨干初值逐张量相同，均从零训练，不加载旧 HBSI 权重。
- **U**：标准 U-Net，损失为确定性实现的交叉熵 + 前景软 Dice。
- **B**：相同 U-Net 的分割 logit 差作为 `z` 后验均值，另有图像条件形状 `q(S|I)`、外观 `q(A|I)`、`q(z|I)`、形状生成均值 `F(softmax(z))`；训练完整的 `p(I|S,A)`、外观先验、形状空间先验和分割潜量空间先验组成的每像素变分项。总损失为与 U 完全相同的分割损失 + `0.01 ×` 变分项。主读出固定为分割 logit 均值的概率；不以 MC 读出选较好结果。B 是独立的 BayeSeg 启发式层级实现，不称官方复现、精确后验或已证实的形状语义。P0 必须确认完整目标有限、所有参数有梯度、生成项到骨干的梯度非零。
- 两者统一 batch 4、患者等权抽样：先均匀取训练中心，再均匀取患者，再以 0.5 概率从该患者前景切片或全部切片取一张。训练增强统一为随机旋转 ±15°、缩放 0.9–1.1、平移 ±0.05 宽度、双轴翻转、gamma 0.8–1.2、增益 0.9–1.1、偏置 ±0.05；标签只做最近邻几何变换。AdamW 学习率由 `3e-4` 每阶段余弦降至 `1e-5`，权重衰减 `1e-5`，梯度范数上限 5；各阶段重新建立优化器但延续本路线的模型参数。B 的额外参数、训练/推理时间、存储如实报告。

每个模型族各跑以下路线，U/B 的顺序、训练病例、每阶段更新、当前域样本流、增强、评测和重放容量完全相同：

| 路线 | 训练访问 | 更新数 |
| --- | --- | ---: |
| 顺序微调 | 每阶段只见当前中心的训练病例；旧中心训练影像不可读 | 首域 8000，其余五域各 6000 |
| 固定总容量重放 | 当前中心训练病例 + **总共仅 32 张**旧中心二维影像/标签 | 与微调共享首域模型，其余五域各 6000 |
| 离线联合训练 | 六中心全部训练病例同时可见，仅作离线参照 | 38000，与单条顺序路线总更新相同 |

重放缓存真实保存影像和标签，活跃且持久保存的原始样本总容量始终 32 张、原始数组 6,291,456 字节；更新缓存时用临时文件原子替换，不保留更早阶段的图像缓存，只留匿名配额审计。不用旧原始数据集代替缓存。阶段二旧域配额 `[32]`，阶段三 `[16,16]`，阶段四 `[11,11,10]`，阶段五 `[8,8,8,8]`，阶段六 `[7,7,6,6,6]`。每旧中心按固定种子只从 4 名训练患者选片，尽量均匀覆盖有前景切片；缓存缩减只保留既存样本，选择不使用 val。重放每批 2 张当前域、2 张缓存；微调每批 4 张当前域，当前域的前两张和增强随机流配对。联合训练按六域均匀采样。每模型族的总物理优化更新为 `8000 + 2×(5×6000) + 38000 = 106000`，两族合计 212000；P0 的前后向不算更新。

## 固定评价和决策

每阶段仅在已见域所有 val 患者评价，同时读出当前域训练患者拟合；联合训练读出六域训练/val。预测先完整生成，再与相应 GT 计分。按三维患者体计算前景 Dice、使用处理后 spacing 的惩罚 HD95、零重叠和空预测；保存患者级私有结果，公开仅患者等权、站点等权聚合、p10、最差患者、下降人数和成本。旧域遗忘以同一患者在该域首次训练后与后续阶段配对；未见域性能不称遗忘。终点检查点固定，不用 val 选最佳步骤或超参数。

两族的当前域训练 Dice 若未达到患者均值 80%，记为拟合不足，先排查数据/模型/预算，不把其 val 差距解释成方法胜负。若拟合达标，平均旧域 Dice 下降至少 5 个百分点或任一患者下降至少 10 个百分点是值得后续核查的遗忘信号。B 相对 U 的**最终重放路线**只有在六域等权 val Dice 均值至少高 2 个百分点、最后到达的 HK 域不低于 U 超过 1 个百分点、任何已见旧域患者最差配对下降不超过 5 个百分点、六域等权惩罚 HD95 均值不超过 U 的 1.10 倍时，才记为本单种子的候选积极信号。其余结果照实报告；不因失败改换读出、阈值、顺序、预算或挑选站点。即使通过，已见 val 和单种子仍不足以证明可重复或独立泛化；test 留待另立冻结确认协议。

## 运行与交付硬边界

U 和 B 分别是独立实验，create-only NAS 目录名分别为 `supervised_cl6_u_20261025_86` 和 `supervised_cl6_b_20261025_87`；完整服务器路径只记录在私有启动配置。各自首次运行至退出严格小于 24 小时：内部 23 小时安全截止，外部 23 小时 15 分钟独立硬超时并留子进程终止余量。各自新增全部模型、缓存、日志、临时文件等严格小于 50,000,000,000 字节；运行目录到 49,000,000,000 字节前停止写入并保存恢复状态，预估各自峰值低于 3 GB。启动前核实真实 NFS、空间、创建写读探针和所选 GPU 显存。运行进程完整可见 argv 均须中性；不干扰已有进程。只读使用冻结 HDF5；私有患者标识、GT、预测、模型和重放样本只存 NAS。完成后按项目公开交付规则只发布源代码、冻结协议、匿名聚合、失败与成本；所有 GitHub 操作走有效代理。
