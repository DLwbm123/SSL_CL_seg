# H4 完成后的只读核查（不改变冻结判定）

分享的[外部分析](https://chatgpt.com/share/6adeb8e8-2f6c-83ea-9cc7-d01d61295384)指出两项值得复核的限制。本文件在 H4 训练和冻结汇总结束后，仅从私有 NAS 的既有验证读数与 `BMC_CURRENT_STATE_WITH_BASIS.pt` 计算，不启动训练、不重新评测，也不改写原始 `ANALYSIS.json` 或门槛。

## 零重叠患者身份

原汇总的 `no_new_zero_overlap` 比较各中心零重叠**人数**，没有比较患者集合，因此可能漏掉“一人恢复、另一人变零”的情况。补充核查以到达时读数为基准：RUNMC 用 `source_C` 第 8000 步，BMC 用 `lowrank_BMC` 第 6000 步；逐一对照 `lowrank_BMC`、`lowrank_I2CVB` 的 0/1500/3000/6000 步旧中心验证记录。零重叠定义与原汇总相同：`TP == 0 && GT > 0`。

逐例身份集合与到达读数完全一致；12 个“阶段 × 步数 × 旧中心”单元各有 4 名验证患者，均为到达时 0 人、当前 0 人，因此新增 0 人、恢复 0 人。本次计数式门槛碰巧给出正确结果；实现缺口仍存在，不能推广为其他实验的逐例核查。

## 后验几何与因果边界

BMC 后已保存精度为 `D + U Uᵀ`，`U` 为 1,980,903 × 8。只读计算 `Uᵀ D⁻¹ U` 的八个特征值，从大到小约为 74,701、37,898、26,405、23,356、18,995、13,819、10,791、9,241。以特征值大于 1 为描述性阈值，八个方向均非数值上可忽略。`U` 平方范数按参数组分配：backbone 95.780%、appearance prior 3.126%、两个 shape refine 合计 1.095%；这是参数坐标中的能量份额，不能直接解释成各组对预测或遗忘的贡献。

H4 相对对角臂的 4.882 pp 终点优势仍只说明**整个 H4 配置**在这一种子、这批开发验证病例上的配对差异。H4 同时将源及新中心 Fisher 增量的一半留在对角精度、另一半用于低秩项，并在 BMC 结束后添加新基。因此本实验未隔离跨参数相关性的因果效应；也没有保存足以重建逐步等对角精度路径的历史梯度。不能把几何核查当作机制证实，或用同批验证结果选择 rank/分额。

冻结门槛结论保持不变：旧域绝对保护与新域学习失败，H4 不进入六域确认。H5 是在收到分享前已冻结和启动的独立外观轨道干预，其结果仍需按原协议判定。
