# SC-BayeSeg 原K→T完整验证报告：生成校准有效，但联合解冻仍破坏语义

## 结论

本轮按原方案完整执行，修复后的两阶段完整状态golden均通过，退出码0，无失败回执，worker已退出。新增实际优化1204次，加此前失败的2次工程更新，**累计恰为1206次**，未超预算，没有再次重跑。

核心结论分为两部分：

1. **K确实改善了生成条件拟合，并使固定推断器下正确空间布局的兼容性边际转正。** 不能再笼统说当前小生成器完全无法获得结构相关信息。
2. **K的600步预校准仍不足以保护后续完整联合优化。** T第100/300步三类前景Dice均为0；第600步第一类部分恢复，但另外两类仍为0，前景平均Dice仅6.8955%，相对96.2809%起点下降89.3854个百分点。

本轮否定的是“原配置下仅先校准Θ600步，便足以安全解冻”这一具体假设；不证明所有分块优化无效，也不证明整个概率模型无可行解。未加入U、目标域、新分块、超参搜索或训练延长。

## 3. K：生成条件获得实际适配，主预测不变是冻结检查

K阶段主输出来自被冻结的推断器，所有固定点前景平均Dice均为96.2809%，六项最小Dice为92.8690%。这证明冻结正确，**不构成生成校准改善分割的效果证据**。

使用相同8次随机数的分项读数如下。除KL外均为nat/像素的MC均值；完整目标含KL/(2×128²)。

| 项 | L3/K起点 | K终态/T起点 | T终态 |
|---|---:|---:|---:|
| shape条件NLL | 3.882936 | 0.938751 | −0.558251 |
| logits条件NLL | 28.070352 | 15.998697 | 2.921928 |
| image NLL | 12.278588 | 12.278588 | −0.477872 |
| code NLL | 0.884882 | 0.884882 | 0.001427 |
| appearance NLL | 0.365988 | 0.365988 | 0.262966 |
| label CE | 0.006558 | 0.006558 | 0.202218 |
| 局部log q贡献 | 17.792991 | 17.792990 | 0.721357 |
| 全局KL，未归一化 | 0 | 5929.042 | 2898.610 |
| 完整负ELBO | 63.282294 | 48.447392 | 3.162232 |

K的两个生成条件项合计下降约15.01584 nat/像素，归一化KL增加约0.18094，完整目标净下降约14.83490。其余因子按依赖关系保持不变。log q通过sum(terms)−bound在FP32中回收，显示约9.54×10⁻⁷的舍入差异；独立审计对这项采用2×10⁻⁶容差，并不将其解读为冻结推断分布变化。

因此，K不是“校准无效”：生成后验在固定局部解释下确实降低了可优化的条件代价。但图像、code、外观、标签和局部变分分布并未因此适配。

沿用原φ0的均值局部解释x0/m0/c0；只替换qΘ，不用标签似然，不做局部校正或SNIS。q0与每阶段后验各8次配对参数抽样，GT与三个空间平移及两个前景身份循环候选；空间平移精确保留每类像素数量。每阶段384图像级density调用，均无优化。

## 6. 实现、模型与优化应如何区分

**实现层面。** 前次RNG隔离错误已修复；本次两阶段完整golden、冻结、原prior、Adam时钟、K→T状态传递和真实成本审计均通过。没有观察到冻结泄漏、优化器历史清零、重复先验更新或账本漏记。本轮通过这些具体检查，不能宣称所有实现及推断接口均无错误。

**优化层面。** 在相同PGM及ELBO下，K能拟合生成条件并改善固定坐标空间偏好，说明生成后验并非完全学不动；但原定的K600→T600仍找到了大幅降低联合代价、同时损坏语义的路径。600步预校准不够，不等于必须增加K步数，更不能事后延长或挑最好checkpoint。

**模型/局部变分解释层面。** K没有改变图像残差、code先验失配及局部方差。解冻后x和c发生大幅尺度变化，与“分类表示和图像生成变量的要求尚不相容”的解释一致。CE阶段仅训练x→ell链，appearance/code没有接受CE梯度；联合切换还同时启动了此前未适配的辅助推断分支。这些现象尚未被本轮分项因果对照区分，不能确定图像项、code项、熵/方差或Adam历史中的哪一项是主因。

从两张训练图的CE可拟合，不能推导完整生成假设兼容；反过来，本轮联合退化也不足以证明所有语义良好的联合解不存在。尤其不能用本轮结果支持SSL增益、旧域保持、可靠不确定性或无需历史图像的持续记忆主张。
