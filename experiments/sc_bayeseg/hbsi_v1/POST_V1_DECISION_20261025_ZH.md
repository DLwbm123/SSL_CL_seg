# V1 后方法主线证据决策

**证据截点：2026-10-25，V1 固定外部站点评价完成。当前没有达到完整 SSL/CL 训练准入的 HBSI 候选。** 本文整理已冻结结果，不新增患者评分、训练更新或科学门槛；各实验的原判定仍以各自协议和报告为准。

## 能支持什么

| 路线 | 同配置可解释的观察 | 冻结判定与限制 |
|---|---|---|
| 原结构概率 W/R64 | R64 的 BMC 适应终点 Dice 46.46%，比同预算标准 U-Net 的 62.11% 低 15.65 pp；BMC 开发 4/4 患者均低。 | v53 九门失败五项；原模型长程 CL 资格未建立。不能将冷迁移优势或较低平均 HD95 当成新域适应成功。 |
| 完整分辨率 A1 | 源 RUNMC 和目标 BMC 分别比标准 U-Net 低 6.19 和 4.75 pp；BMC 开发 3/4 患者低于 U。 | A1 四门联合失败；不是对官方 BayeSeg 的等价复现。 |
| C1 源端生成反馈 | 两臂同 U-Net 预测、完整形状/外观图像生成层级，区别为生成梯度是否进入 U-Net。 | C1 源端 Joint 未通过预定安全门，其原目标分支硬停止；后来的 R1/R2 是另立协议，不能追认 C1。 |
| R1 目标端切换反馈 | BMC 开发 Dice 相对保持 Cut 增加 3.08 pp。 | RUNMC 旧域平均下降 2.24 pp、最差配对患者下降 10.53 pp；旧域安全和目标患者一致性门失败。 |

| T0/U1 固定最大三维组件探针 | 部分 BMC 开发患者的断开假阳性被移除；RUNMC 开发旧域安全探针通过。 | 规则源自反复使用的开发患者，训练患者已有误删真阳性例子；不能据此更改 R2 原判定。 |
| V1 额外四站点、全部 9 名验证患者 | 固定组件后 Joint−Cut 的站点等权 Dice 为 −0.44 pp；BIDMC/HK/UCL 为正，I2CVB 为 −29.13 pp。 | 外部空间安全和积极门均失败。I2CVB 3/3 患者的组件 Dice 为 0，最大组件删掉全部原有真阳性。不能删除该站点或按其结果改组件、阈值或选择 checkpoint。 |

这些患者级开发和额外站点结果不是独立重复的训练种子。R2 的正 Dice、T0/U1 的局部空间线索与 V1 的明确反例必须同时保留；任何跨实验数字都不能无视源模型、标签曝光、目标、预算和患者集合的差异。

## 对下一轮的约束

1. 当前 W/R64、A1、C1 原目标分支、R1、S1、R2 与固定最大组件候选均按各自失败协议关闭。不能用再次评分同四名 RUNMC/BMC 开发患者或 V1 九名患者，为这些固定候选挑参数后声称验证成功。
2. 目前没有一个已检验的候选同时满足新域积极收益、患者级旧域安全、目标边界安全和跨站点最低安全。完整长程 SSL/CL 训练不从这些短程结果直接启动；无标签 U 的增益也未由 R2 建立。
3. 后继若有**新**的、从生成机制或实际数据生成过程推出的主线假设，先冻结处理的患者集合、唯一机制干预、配对对照、标签曝光与算力、旧域患者下降数/最差配对差、目标 Dice/HD95、绝对参照、预算和失败动作。现有验证患者可用于明确标为探索性的诊断，不能作为最终独立证据；新的确认性结论需要独立患者资源及访问授权。
4. 不从 V1 的 I2CVB 失败倒推一项专门修补该站点的后处理。若提出空间或外观机制，须先在训练数据或无需标签的独立物理证据上说明其为何适用于全部站点，并保留所有负例。

本次仅作证据综合，没有新实验、无新评分，未读取 test 或 U 隐藏标签。原始数值、患者匿名分布、费用和预注册门详见 [v53](spatial_latent_v53/REPORT_ZH.md)、[A1](fullfield_bayeseg_a1/REPORT_ZH.md)、[C1](feedback_c1/REPORT_ZH.md)、[R1](staged_target_feedback_r1/REPORT_ZH.md)、[S1](patient_gradient_guard_s1/REPORT_ZH.md)、[R2](source_rehearsal_r2/REPORT_ZH.md)、[T0](r2_component_audit_t0/REPORT_ZH.md)、[U1](r2_old_component_u1/REPORT_ZH.md) 和 [V1](external_component_v1/REPORT_ZH.md)。
