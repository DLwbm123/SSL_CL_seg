# M0：Bayes形状/外观生成器的源域交换可用性审计

在任何M0数据读取前冻结。本轮不训练、不选择checkpoint，不沿用L1失败配置做调参。L1已完成：标签锚定qS使源安全通过，但Joint生成反馈使BMC分割比Cut和旧U更差。下一候选主线是用`p(I|S,A)`生成保留源标签几何、改变外观的训练图，再考虑无标签目标外观；**必须先证明源域外观交换至少保住标签**。本审计只用RUNMC四名L训练患者80片与L1封存终点，不使用BMC开发标签、BMC U或test，不访问隐藏标签。

固定两臂L1 Cut及Joint第1600步。对每名RUNMC L患者的每片，先由该臂qS均值经形状解码器生成形状图，qA均值为外观图。构造自身均值重建`R_i=shape(qS_i)+qA_i`，再构造跨患者交换`X_i=shape(qS_i)+qA_j`，其中伙伴是固定循环下一名患者，切片索引取`floor(k*n_j/n_i)`，相对轴向位置对齐且不依赖标签或预测。无采样、缩放、裁剪、阈值或强度修补。用原封存U-Net同一概率读出分别预测原图、自身重建与交换图，把概率恢复原尺寸并算逐患者三维Dice、TP/FP/FN、惩罚HD95；另记自身重建MSE和生成图超出训练强度[−1,1]的像素比例。评分顺序Cut原/自身/交换，再Joint同序。身份、图像、标签及预测仅NAS，公开只匿名索引和聚合。

零更新工程门：L1 COMPLETE/EXIT0、两臂第1600步checkpoint可读、U逐张量等于v45 U1600、RUNMC L恰4患者80片、跨患者伙伴身份不同、qS/qA/形状解码有限；任何失败即止。科学**合成准入门**预先固定，须对Cut和Joint分别全过：自身重建MSE≤0.02、交换图超出[−1,1]的像素≤1%；自身重建相对原图U的患者等权Dice下降≤5pp且每患者下降≤10pp；跨患者交换相对原图U的患者等权Dice下降≤5pp且每患者下降≤10pp；无交换后整患者空预测。主决策以Cut为准，Joint仅机制对照。若Cut任一门失败，M0关闭，不启动源标签/目标外观合成训练；若Cut全过，也只是后继独立协议的工程准入，不把U对合成图的成功当作真实标签保真的证明。不得在看到结果后更换伙伴、加裁剪、重训生成器、放宽门或回选checkpoint。形状/外观空间场并未被证实解耦，结果保留这一限制。
