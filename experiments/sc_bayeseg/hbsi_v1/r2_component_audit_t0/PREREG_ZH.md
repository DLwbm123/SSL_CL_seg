# T0：R2 边界误差的三维连通性诊断

在任何 T0 私有预测/标签重新读取前冻结。R2在BMC开发四患者的Dice各自上升，但惩罚HD95均值由21.292升至27.377mm，超过冻结1.10倍门；BMC完整L训练HD95却由6.265降至5.415mm。R2原科学判定失败且固定策略关闭。本轮只回答一个描述性机制问题：开发HD95恶化主要是否来自远离主体的**断开小组件**？不得用本轮后处理结果改判R2，亦不选择部署阈值或模型。

固定输入：R2的ReplayCut/ReplayJoint各自BMC split0的4名完整L训练和4名开发患者的第800步私有128²概率；只读同患者原存储影像的尺寸/spacing属性、已见L或开发标签和封存原评分。共2臂×2分组×4患者=16个三维病例，0模型前向、0反向、0更新，不读隐藏U标签或test。对原概率恢复到原始尺寸后按argmax得到二元掩膜，以三维6邻接定义连通组件；固定保留最大预测前景连通体，体积相同取 `scipy.ndimage.label` 扫描的首个组件。该变换**完全不用标签**；标签仅用于事后描述被删FP/TP与Dice/惩罚HD95。记录原掩膜组件数、最大组件占比、移除体素、其中FP与TP、基线和最大组件后Dice/HD95。最大组件后处理是假设探针，不是正式预测器，尤其不追改R2主终点。GT也记录组件数供解释。

工程准入：16例原掩膜在同一评分函数下重新算出的Dice及惩罚HD95与R2封存患者指标误差≤1e−9，否则诊断停机、不报告改变后的指标。描述规则：若ReplayJoint开发第3和第4名HD95恶化均能由固定最大组件保留消除到≤其ReplayCut原HD95×1.10，且这两名各自被删FP≥100体素、FP≥10×max(1,被删TP)，可将断开FP作为后继空间先验候选；若不满足，则仅说明此简单组件机制不足，转向主体过扩张/患者强度差异等其他解释，不据此自动启动训练。即使满足，也不证明因果或独立泛化；开发患者已多轮用于路线决策。
