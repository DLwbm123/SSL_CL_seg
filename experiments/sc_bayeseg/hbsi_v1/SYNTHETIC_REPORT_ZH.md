# 合成资格结果

结论：解析与实现单测通过；神经两域演示完成80次外层更新，但判定为 **OPTIMIZATION_FAIL / INFERENCE_UNQUALIFIED**。没有正式医学结果。

## 解析资格

线性高斯模型使用 Theta~N(0,1)、a~N(0,0.7²)、噪声0.2，两个固定域观测分别为[0.2,0.5,0.4]与[1.3,1.1]。独立全数据精度矩阵参考与顺序条件核重建的均值最大误差3.33e-15、协方差1.94e-16。固定旧边缘、重复旧证据、重置先验三个负对照误差分别约0.3689、0.07339、0.17188，均可辨识。

低维证据加权预测：每域65536样本，4个固定重复，主域混合概率的最大绝对误差0.002918，预登记容差0.015；错误均匀预测误差0.03128，oracle 选择误差0.5301。此结果只资格化低维积分实现，不意味着高维图像推断合格。
