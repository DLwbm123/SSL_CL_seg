# R2：源标签重放下的目标生成反馈

在任何 R2 数据读取、预检或正式更新前冻结。R1 从相同 C1 Cut 源1600状态出发，仅在目标阶段接通生成反馈：BMC 开发均值相对 Cut +3.077pp，但仅2/4目标患者获益，RUNMC旧域−2.243pp且一人−10.525pp；R1 原冻结判定失败。S1 的四源患者静态风险梯度锥在765/800步生效，终点旧域/新域门仍失败。本轮提出不同的持续学习假设：**实际源图及标签的同步训练约束**可随参数状态变化，可能避免静态线性锚的失效，使目标生成反馈在保护旧域患者时仍提供新域收益。此假设明确付出源数据重放成本，不声称无重放方法。

两臂从完全相同的封存 C1 Cut_source1600 全模型状态恢复；U与v45 U1600逐张量相同。两臂在BMC split0 L的4患者134片上各做800目标更新，同时每步取RUNMC split0 L的4患者80片中一张源图标签；源和目标独立固定数据流分别为163000、263000。每步监督项固定为 `0.5*RUNMC_task + 0.5*BMC_task`，再加 `0.01*BMC_full_hierarchical_variational`。源片不进入生成项；目标生成项保留完整 `q(S|I),q(A|I),q(Z|I),p(I|S,A)` 与形状/分割 Student-t 空间先验。两臂batch均为源1＋目标1、128²、float64、无增强、fresh Adam3e−4；主预测均为标准双logit U-Net。

- **ReplayCut**：生成项至 U-Net 的路径截断；完整生成模块仍按目标生成项训练。它是同源/目标标签曝光与同更新数的纯判别U对照。
- **ReplayJoint**：仅开放目标生成项到 U-Net 的路径；其余数据、损失、抽样、初始化、优化器一致。两臂的差仅为该梯度路由。不同于R1无重放目标链，不追改其判定。
