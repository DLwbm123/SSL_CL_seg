# H1：直接语义监督下的 BayeSeg 形状与外观潜变量配对检验

在H1任何新正式参数更新或开发读出之前冻结。现有C1/C2/E1/F1/G1各按原协议失败，尤其F1的残差头对形状后验的分割反馈只带来有限冷域变化，G1无标签生成拟合改善却使源和冷域每名患者Dice均下降。本轮新假设：**若形状后验确有比外观后验更可迁移的解剖信息，使用只依赖单一潜变量的分割头，并直接监督这个头，应让形状臂优于同容量外观臂；标准U-Net作为冻结的安全基座。** 这检验潜变量承载语义的能力，不把变量名称当成已验证的解耦，也不改写旧实验结论。

## 固定入口与唯一干预

两臂都从只读C1 `Cut_source` 第1600步完整 BayeSeg 模型及相同零输出新头初态进入。C1的`q(S|I)`、`q(A|I)`、`p(I|S,A)`、`p(S|Z)`、局部分割场、空间/Gamma边缘化Student-t先验与完整图像变分目标全部保留并继续训练。标准U-Net双logit参数及运行状态冻结且须与v45 U1600逐项相同。

新增头为单通道`tanh(潜变量后验均值)`→3×3卷积16通道→ReLU→1×1双logit卷积，末层零初始化；两臂容量、随机初态、数据流和生成训练均相同。主预测双logits固定为`U_logits + 0.5*tanh(head_logits)`，零更新时严格等于标准U。训练标签项固定为`risk(主预测,标签) + risk(head_logits,标签)`；后一个直接监督防止分割头只学习依赖U logits。两个risk均为项目v45相同的CE加非空真值切片soft Dice，生成项权重仍是0.01。

- **Shape**：头仅读`q(S|I)`均值；标签梯度经头进入形状后验，外观后验只接收生成梯度。
- **Appearance**：头仅读`q(A|I)`均值；标签梯度经头进入外观后验，形状后验只接收生成梯度。

形状与外观后验原容量并不相等，因而Shape−Appearance是**完整配置对照**，不能只归因特征内容；新增分割头容量和训练成本匹配。固定主预测不使用后验采样；采样、外观可辨识性及独立患者留给后继独立协议。RUNMC split0 L4患者80张切片，均为128×128 float64、batch1、无增强；每臂1600次Adam3e−4正式更新，抽样种子183000、局部噪声`74000000+step`，共3200新增更新。不使用BMC标签训练、U隐藏标签或test。零输出初始时标签到潜变量梯度可能为零，P0用可恢复的固定非零末层扰动证明两臂各自路径，随后恢复初态。

## 工程门、评价与停止线

P0在真实源L批上0正式Adam验证：C1封存EXIT0、两臂全部初态逐项相同、U与v45逐张量相同且在训练模式下不更新；主输出严格等于U、两项标签损失与完整变分目标有限；可恢复探针下Shape标签到qS非零而到qA零、Appearance反之；两臂qS/qA均有有限生成梯度，探针后状态逐项恢复。优化器仅含生成层级和新头。任何工程门失败即停，不读开发结果修复。

两臂在RUNMC四名开发患者、BMC四名冷迁移开发患者和RUNMC全部四名L训练患者做固定终点评价，记录匿名逐患者Dice、TP/FP/FN、惩罚HD95、NLL/Brier、空预测及完整成本；评分顺序Appearance源/冷/源训练，后Shape源/冷/源训练。每臂保存1/400/800/1200/1600步当时状态所选潜变量的标签与实际0.01系数后生成梯度范数及余弦、每步标签/生成/重建读数，所有中间checkpoint仅供恢复，不回选。

**源安全门**：Shape相对Appearance及只读U的RUNMC开发等权Dice均值分别≥−1pp、逐患者分别≥−5pp；完整L训练均值分别≥−5pp；惩罚HD95≤两者各1.10倍；无整患者空预测；完整生成目标及后验尺度有限。

**形状特异冷域积极门**须源门全过且同时满足：Shape在BMC的等权Dice高于`max(Appearance,旧U)+2pp`，相对两者各至少3/4患者非负且每名下降不超过5pp；惩罚HD95≤两者各1.10倍；无整患者空预测。形状优于外观仅表示此固定配置的开发信号，不证明解剖/外观解耦；若外观更好也不得重命名为形状成功。这些反复观察的4名患者只是资源门，不是独立检验。失败则关闭H1固定配置，不调整头、0.5系数、辅助项、步数、随机种子或checkpoint；通过也仅允许另立协议做独立患者、多种子、反向域及长期CL验证。
