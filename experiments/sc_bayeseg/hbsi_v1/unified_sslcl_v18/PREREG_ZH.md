# v18 统一概率 SSLCL：冻结目标与有界路线

授权：2026-10-23 用户要求按第二次 Pro 方向直接推进。新协议独立于旧 HBSI qualification；旧失败、MCMC 暂停和原运行预算不变。

目标依次为：同模型未标注信息贡献、跨域迁移与遗忘；解释性与不确定性作为诊断，不以单轮 Dice 证明五项目标均成立。主线保留 θ 的全局分布、条件域记忆 r(a|θ)、图像条件自回归局部后验 rφ(z|x,θ,a) 和结构生成模型。没有 EMA teacher 或 EWC。

## 概率目标及预测

令 E_i=E[log p(x_i,z_i|θ,a)−log rφ(z_i|x_i,θ,a)]，Y_i=E log p(y_i|z_i,θ)。优化

J=[KL(q_t||π_t)+E_q KL(r_t(a|θ)||p(a))−Σ_L Y_i−0.01(Σ_L E_i+u Σ_U E_i)]/(N_L H W)。

这是明确的广义贝叶斯变分目标：图像/局部先验的 ELBO 整体温度为 0.01，标签项温度为 1；不是原始未经温度处理联合模型的精确后验，也不是新增 Dice/一致性损失。0.01 是本次预先固定的机制选择，不搜索验证集最优值。两臂监督项、KL、L 数据流、初始化和更新次数完全一致；唯一差异 u∈{0,1}。所有随机变量在训练时采样，梯度进入均值和尺度，局部后验始终只看图像，K=0。训练 MC 为 2×2。

预测为 E_{q_t(θ) r_d(a|θ) rφ(z|x,θ,a)}p(y|z,θ)，8×4 样本、3 个推断随机种子。均匀权重是对该变分分布的积分，不是旧 K0 的重要性加权，也不宣称对真实 p(θ,a,z|x,D) 无偏。域已知；选择对应存储域记忆。域后验不额外根据当前图像更新，这是近似限制。φ 没有被 θ 的 KL 保护，持续学习结果必须包含其遗忘影响。

## 固定实验顺序

冻结 seed0 患者划分，RUNMC→BMC；训练种子 20261023/24/25。128×128、现有带坐标的生成/识别网络，float64，Adam 3e-4，无增强，无暖启动，无旧数据回放。

每种子先训练同模型 L、L+U 各1600步；第一种子两臂结果先产生作为有界单域比较，随后直接进入两域阶段，不设 Dice 晋级门槛。每个源状态复制到第二域，交叉 u∈{0,1} 与历史先验 M∈{0,1}，各800步。M=1 使用 q_A 为先验，M=0 恢复固定初始先验；参数初始化、源域记忆和φ仍从相同源状态继承。U=0/1 在两个阶段一致。共6个源训练、12个目标训练，19200步；不使用测试集。

每个源阶段评估 A/B 验证集，目标阶段评估 A/B。报告患者宏平均 Dice、NLL、Brier、HD95、空预测、训练种子离散程度、推断重复波动；遗忘 Dice_A_after−Dice_A_before、目标迁移 Dice_B_after−Dice_B_before。源阶段 B 使用 A 域记忆，称为未适应迁移；目标阶段 B 使用新 B 记忆。同时报告 U 主效应、M 主效应及交互，不把概率校准或因果解释当作已证实。

预算：独立原始时钟12小时硬停止，新增实际存储10GB硬界前9GB停止写入；预计≤2GB。每步复用已有可恢复训练事务，保留每400步快照；单阶段3600秒。运行失败保留证据，不重置计时。启动前检查真实批次所有分布梯度、U标签访问边界、两臂L一致性和成本。运行结束后根据结果修正主线，不回到无限单域诊断。唯一现有30分钟监测原位更新。
