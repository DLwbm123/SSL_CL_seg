# 精确归约与转移核说明

原固定Theta只使c0与R的第一通道进入生成器。双线性插值保持常数，因此v=vec(R0)+.1c0*1，Pi_fg=sigmoid(6*tanh(upsample(v)))。F的实际固定权重又使S均值为tanh(2Pi_fg-1)。这两步均由原源码验证，不改变生成函数。K=I+.01*11'，唯一对称平方根L=I+(sqrt(1.16)-1)/16*11'，采样w~N01、v=Lw。使用对称白化避免任意特征向量排序影响块定义；w中的2x2块经过L后包含全局分量，不冒称严格空间局部更新。

精确恢复：c0|v均值=.1sum(v)/1.16，方差=1/1.16；R0=v-.1c0，c1/R1独立标准高斯。恢复噪声使用独立随机流，既不读取真latent，也不影响转移核。每保留步恢复后重新计算原生成器的完整logjoint，原变量继续进入全部资格诊断。

整块提议u'=u cos(angle)+nu sin(angle)映射为v'=v cos(angle)+Mnu sin(angle)，Mnu~N(0,K)。所以接受判断相同，精确归约本身不应被当成预测混合机制。P0同时验证投影椭圆路径及生成/密度等价。

A每sweep四次全16维更新；B每sweep四块各一次；每5sweep两臂都额外一次全16维更新。椭圆方向为所更新w块的标准高斯，其余块固定；因w先验独立，条件先验保持正确。所有结构更新在固定omega下使用积分S/b的图像似然；之后恢复联合S/b，再更新omega，继承v3有效的collapsed顺序。没有使用标签或后验点估计替代积分。

原32条链只读复析。v、c0条件残差及c1/R1、S、b、omega分组诊断；固定和最大分歧位置以及delta范数为解释性指标，不替代全256概率/全原变量资格。相关系数是链轨迹描述，不能单独证明omega锁死或后验多模态。

NumPy诊断交叉实现使用NormalDist逆CDF、平均秩、直接时域自协方差与逐坐标Geyer序列；它不调用被检查的torch rank/FFT/ESS函数。公式与门槛相同，仅实现路径独立；不是第三方认证。数学参考来自此前阅读的Murray等2010椭圆切片和Vehtari等2021诊断论文。

费用计数明确范围：collapsed_density_evaluations包含当前点阈值计算及所有收缩候选；analytic_mean_evaluations含每次密度调用和每sweep末均值重算；每链转移有1500次C Cholesky、density+1500次三角求解、1000次原logjoint、6300次结构转移。构造Reference每链另有一次先验矩阵inverse和一次先验Cholesky，单独列入资源汇总。链seconds含迭代及样本堆叠，不含构造器、保存与链后诊断；stage账本计入这些费用，ESS/链秒须连同完整stage秒数报告，不能冒称端到端吞吐。

不估计边际证据，不涉及未知Theta/a积分或CL。教师门即使通过，也不自动授权训练；本轮科学学习更新始终0。
