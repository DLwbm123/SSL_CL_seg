# 新路线 B0：层次模型 × 监督风险缺角实验

冻结于 B0 的任何正式更新、开发结果或训练患者读出之前。A1 四门失败、固定配置关闭；B0 是独立方法主线机制试验，目标是识别 A1 与标准 U-Net 之间监督风险定义差异的作用。旧 W32/R64、A1 和 v45 U-Net 全部封存；不重训、不重评分其开发终点，不用 B0 结果改写原判定。

## 四格与因果范围

| 家族 | 平衡风险 Bal | 标准风险 Std |
|---|---|---|
| 完整分辨率层次模型 H | 已封存 A1 H-Bal：类别平衡 CE＋所有切片前景 Dice＋0.01 变分项 | **新增 H-Std**：仅将监督风险换成逐像素 CE＋仅非空片前景 Dice；其余同 A1 |
| 标准 U-Net U | **新增 U-Bal**：仅将 v45 U-Net 的标准监督风险换成 A1 平衡风险，无变分项 | 已封存 v45 U-Std |

H-Std 直接加载 A1 的零更新预检初始模型状态，权重逐项相同；A1 的源/目标局部噪声和数据采样公式逐项复用。U-Bal 使用 v45 `unet()` 原始确定性初始化函数、同代码快照和环境、相同数据流；历史 U-Std 未保存初始权重文件或初始哈希，因此只能称**程序性初始化匹配**，不能声称已经核对过历史两臂初始张量逐项相等。若这一限制影响解释，须另立有预算的配对 U-Std 复训，不能悄悄补入本轮。B0 在同一模型家族内比较风险作用；跨家族差异仍包含架构、变分目标、推断和成本，不归因某个单独 Bayesian 元件。H-Std 一次改变 CE 权重与空片 Dice 约定，不能把效果全部归给 CE。

## P0 有界零更新准入

核实两旧根 EXIT0 与正式步数、当前源代码/预处理/manifest 及运行环境、固定 L 切片数、同一步源/目标 batch、初始状态和 0 Adam 真实反向。H-Std 与 H-Bal 在同一初始状态和局部随机流上应有完全相同的后验/变分项，损失之差仅是监督风险之差。U-Bal 用 v45 标准 U-Net 构造，固定同一初始函数和输入；两新增臂均验证概率归一、有限非零梯度与检查点往返。P0 不读取开发标签做选择，不跑 MC/梯度网格；运行后只读固定完整终点。全训练患者的空/非空 FP/FN 和后验尺度等有明确异常时，再作为单独无更新诊断，不以 P0 扩大搜索。

## 正式训练、评价和冻结读出

两新增臂各从头 RUNMC 源1600次 Adam 更新，再继承自身源权重、新 Adam 完成 BMC 目标800次。split0，RUNMC 4名 L 患者80张训练切片，BMC 4名 L 患者134张训练切片；训练种子20261023，步索引采样流163000/263000，batch1，无增强，float64，128×128输入，Adam 3e−4。H-Std 单步一次局部重参数化采样，评价固定4次局部抽样平均；U-Bal 确定性输出。全部患者按现有256原空间三维指标评价，源和目标终点各有 RUNMC/BMC 两格，目标完成后另读出全部 BMC L 训练患者。每臂源和目标唯一终点；不按中途 checkpoint、阈值、种子或开发患者挑模型。目标训练只访问 BMC L，旧域图像只评价；U 隐藏标签与 test 不访问。

主要量：在四格分别报告 `H-Std−H-Bal`、`U-Std−U-Bal` 及二者差；患者等权 Dice、匿名逐患者差、precision/recall/TP/FP/FN、预测体积比、空预测、HD95、NLL/Brier。BMC 训练患者空片 FP 与非空片 FN 用冻结预测规则汇总。所有源/目标与训练结果封存后才联合分析，不拿部分输出选择第二臂或分支。

## 新基座资源继续门与动作

仅 H-Std 进入下列新门（相对 v45 封存 U-Std）：源 RUNMC Dice 差≥−1pp；目标 BMC 差≥−2pp；目标 RUNMC 差≥−2pp；自身 RUNMC 源→目标均值变化≥−0.5pp、任何患者变化≥−5pp；BMC 目标至少3/4患者相对 U-Std差≥−5pp，任何患者差≥−10pp；完整训练及两域开发患者无整患者空预测或全背景坍缩。全部通过仅允许独立预注册 `H-Std-NoVariationalLoss`，检验变分目标的作用；它仍保留随机推断，不能被称为“无 Bayesian 模型”。若 H-Std 失败，先交付 B0 全部结果，再单独冻结 q(Z|S,I) 结构与同结构无变分项对照；本轮不自动以 B0 剩余预算启动。无论结果如何，不追加 CE 权重、阈值、尺度、推断次数、训练长度或中途 checkpoint 网格。新门是看过 A1 后的开发资源规则，不是统计非劣或独立确认。
