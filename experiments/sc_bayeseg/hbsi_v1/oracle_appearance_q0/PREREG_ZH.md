# Q0：标签形状固定时的类条件外观可交换性审计

在读取 Q0 的任何图像、标签或评分前冻结。M0 显示旧生成器的全分辨率 `q(A|I)` 跨患者交换使固定 U-Net 的源训练 Dice 平均下降 20.645 pp；N1 把外观场限制为 4×4 后仍未得到可用交换。它们没有回答一个较窄的问题：若形状由真实标签固定，仅交换每类的全局外观均值，原图的空间纹理是否可保留并使分割读出稳定。Q0 是后续类条件形状/外观图像生成器的**乐观上界审计**，不是训练模型或目标域效果。

仅使用 RUNMC split0 的四名 L 训练患者共 80 片。把每张原图双线性缩至 128×128、标签最近邻缩至同尺寸；对每名患者的全部像素，按真实背景/前景标签分别求单个灰度均值 `mu_bg, mu_fg`。四患者按清单顺序循环配对下一名；绝不按结果换伙伴。固定构造三种输入：原图 `I`；仅有真实形状和自身两类均值的 `C=mu_bg*(1-Y)+mu_fg*Y`；保留原图残差而换伙伴两类均值的 `D=I+(mu_bg_partner-mu_bg_own)*(1-Y)+(mu_fg_partner-mu_fg_own)*Y`。`C` 是极简类条件发射模型的重建能力诊断；`D` 是类均值外观变化在**真值形状已知**时的最有利情况，残差仍来自原患者，不能称为完整外观潜变量交换。无裁剪、随机噪声、阈值选择、优化器更新或模型训练。

用 L1 Cut 封存第 1600 步中的标准 U-Net，对三种图逐片一次性预测，将概率恢复原尺寸，按已有三维患者指标计算 Dice、TP/FP/FN、惩罚 HD95 和空预测。记录 `C` 对 `I` 的像素 MSE、`D` 越出原归一化强度区间 [−1,1] 的比例，以及匿名逐患者源训练结果。所有真实标签只用于这项源训练乐观审计；BMC、隐藏 U 标签和 test 均不读取。
