# 训练集定位：识别分布语义退化，非生成器只能输出背景

固定初始化/L400/LU400三个checkpoint的全局与域均值，检查四名L全部80切片；0优化器更新、0MCMC、0验证/test访问。8个配对proposal样本的概率均值仅作训练网格诊断，不替代原正式重要性加权预测。

L400在K0下，前景位置平均概率0.01391、背景0.01524；LU400分别0.01305/0.01472。两者全部无硬前景，患者宏Dice=0。训练数据本身的前景占比为0.01765。K3 image-only仍全背景；加入训练标签的K3仅将前景位置概率小幅提升到L的0.01604、LU的0.01594，仍不能定位前景。不能把这一低步数诊断当作局部优化已收敛。

固定生成器、16组标准先验c/R样本的平均前景概率，初始化/L400/LU400分别为0.51448/0.48472/0.47519；硬前景占比分别0.59349/0.53746/0.51561。因此不是生成器已经对所有潜变量都只能生成背景；当前训练得到的图像条件识别分布缺少语义定位，强度生成学习与标签语义之间可能存在落差。不能仅凭这些诊断确定全部根因。

下一轮检验数据驱动语义初始化：先用L的CE+前景Dice训练G和识别分布，再转回原完整L+U ELBO；与相同总更新数的直接ELBO对照，明确初始化目标改变，不宣称新增项是原贝叶斯似然。原密度、最终完整ELBO、先验和预测器保持，不能将暖启动后验当先验重复计入同一训练证据。该新假设不需要MCMC参照。
