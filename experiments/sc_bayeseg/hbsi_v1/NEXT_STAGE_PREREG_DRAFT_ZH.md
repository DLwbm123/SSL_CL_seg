# 下一阶段预注册草案（不构成启动授权）

当前阻塞是合成实例的前景塌缩和重要性权重退化。先修复并资格化这条方法主线，不重做或调强B11，不因解析单测通过就上真实持续学习。

1. 固定生成模型的推断资格：将局部S/b项、固定Theta/a的Delta方差与外层证据方差分开；比较K=0与预登记有限K，检查条件Gaussian初始化及SAR相关性失配。候选变化仅限有完整归一化密度的proposal，不改变生成模型的sigma/Student尺度来掩盖问题。每项改动另立协议、保留本轮失败、重复密度/超梯度/IS对照。
2. 合成单域资格：固定新预算和独立合成评价种子，要求类别完整性、image-only NLL/Dice、前景占比及重复MC稳定性同时通过；推断local/global ESS分别设门槛。本轮80步不能重命名为新实验后继续计数。通过前不开真实多域。
3. 真实单域资格：先复用一个已审计灰度任务；冻结源训练划分、训练预算、患者/phase评价空间、spacing、Dice/HD95/empty/NLL/Brier及逐患者分布。真实数值门槛须在源训练前写入批准协议；本草案不拿当前合成数值替代医学准入标准。未通过源域资格不开CL。
4. 两域机制对照：独立域后验、条件域后验、条件记忆加半摊销、仅L与L+U。匹配真实数据、global/domain/local MC、局部反向次数和总体算力；保留匹配的确定性生成模型、标准SSL方法及B11既有结果，不追改其失败判定。
5. 之后才考虑独立源多seed、多域顺序与封存test；先冻结最终协议再开test。不得用验证集反复选患者级K、路由或后处理；默认主预测无域ID。
