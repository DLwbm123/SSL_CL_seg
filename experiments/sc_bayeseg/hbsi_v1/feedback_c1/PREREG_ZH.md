# C1：判别均值路径与层次生成反馈

冻结于任何 C1 正式参数更新及新开发读出之前。B0/B1 的失败判定不改写。C1 是独立方法主线假设：标准 U-Net 双 logit 分割路径提供可核验的判别锚，完整形状—外观—分割场变分生成目标只在 C-Joint 臂反馈到该锚；C-Cut 臂保留并训练同样的后验/生成分支，却截断所有生成项到 U-Net 的梯度。新方法的可归因量是 **Joint−Cut 整条训练流程的效应**，不是 C1−B1 或目标阶段单独贡献。

## 固定模型与两臂

U-Net 与 v45 `unet()` 一致，原两个背景/前景 logits 同时定义 Std 监督风险和主要分割预测。局部分割后验为 `q(Z|I)=Normal(logit_fg−logit_bg, sigma_Z²)`；sigma 由 U-Net 末级 decoder feature 上的独立1×1卷积输出，经A1固定 `−4+3*tanh(raw/3)` 映射，卷积零初始化。形状/外观后验、图像拟合、`S|Z` 关系、空间自回归与Gamma精度**解析边缘化**后的 Student-t 项按 A1 固定定义；不新增显式精度后验或声称学习精度图。完整变分目标系数0.01。监督项只作用在原双logits确定性均值路径；MC4后验预测是预定次要读出，不与主要预测择优。

Cut 的变分分支同时截断 logit 差、scale头输入的共享decoder feature及任何其他通往 U-Net 的路径；Joint不截断。共同初始U-Net只构造一次并复制给两臂，辅助参数也从同一状态复制，局部噪声与数据采样使用独立固定流。无全局梯度裁剪、EMA、weight decay或共享优化器状态。此目标是判别风险＋层次变分生成目标的联合训练，**不是**原监督ELBO的等价改写；主要 softmax 不等于MC后验预测均值。
