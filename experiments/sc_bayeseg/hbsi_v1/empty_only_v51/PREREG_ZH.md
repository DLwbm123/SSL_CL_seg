# v51 仅空切片抑制：分离 v50 正例项

冻结于任何 v51 模型输出之前。v50 在完整 BMC 训练患者上把空片平均 FP 从 956.57 降到 400.16，但四名患者 recall 均降，BMC 开发 Dice −3.8787pp、旧 RUNMC Dice −21.5106pp，七门失败五项。v50 的切片存在 BCE 同时包含正片 `-log(max p_fg)` 和空片 `-log(1-max p_fg)`；不能从这一臂判断两项各自的影响。本实验只删除正片项，保留空片项，检验这种空片局部改善能否与非空病灶召回共存。它不是系数搜索，也不预期单一项必然成功。

## 一处改变和同入口比较

C3 从与 v46 C0、v49 C1、v50 C2 完全相同的 W_target `ACTIVE_INITIAL` 出发。仅在有标签空切片增加 `-log(1-max_pixels p_fg)`，有前景切片增加零；系数固定为 1。原类平衡 CE、前景 Dice（含空真值定义）、图像评分/局部 prior-minus-q、ranking anchor、global/domain KL、q/phi/eta、旧记忆/Sb、128 输入/256 三维读出、采样与 Adam 均不变。无新参数、阈值、权重、增强、U 目标或测试标签。此项是判别风险，不称 ELBO 或校准的存在概率。

BMC 原 4 名 trainL 患者 134 片、batch1、data_seed263000、800 更新；源模型和 Adam/RNG 入口与 C0 一致。控制 C0 的 BMC 完整训练读出和两域开发格、标准 U-Net/v49/v50 封存结果只读，不重训或重评分。新臂 C3 训练后读出同一 134 片的三维预测（8 global×4 local×3 推断）；训练定义按相同数据流和空/小/中/大面积层逐字段匹配 v49。然后仅评估 RUNMC/BMC 两个固定 800 终点开发格。旧域图像仅作隔离评价。公开匿名患者级和分层合计，不公开私有逐片标签、影像、权重、概率或路径。

生产预检在真实**空片** batch 上精确匹配 v23 原目标与独立 C0 控制的 loss/全部梯度和 RNG；C3 与控制的差只等于空片罚。小 fixture 覆盖非空零罚、空片罚随最大前景概率增大、有限反向。预检 3 模型目标前向/3 反向、1 fixture 反向、0 Adam。预检后来源 payload、prior、旧记忆、未使用头及训练 RNG 不变。正式训练最多 800 backward/Adam，无额外重训。

## 冻结继续门与解释

相对 C0 沿用七项固定门：BMC 患者等权 Dice ≥+2pp、至少 3/4 患者改善；precision ≥+5pp；recall 下降 ≤2pp；RUNMC Dice 额外下降 ≤0.5pp；两域无新增患者空预测；两域 HD95 均值恶化 ≤10%。七项全过才是单 seed、四名反复开发患者的后继确认信号，不等于赶上 U-Net、旧域安全、SSL 或泛化证明。另列 C3−C2 以隔离 v50 正片项的表观差异，但不以此改变主门；也列 C3−自身源和 C3−U 的绝对差距。训练完整患者与开发患者分别报告 TP/FP/FN、precision/recall、体积比、FG/BG 条件误差和空片 FP。患者等权，MC 推断不是训练 seed，切片不是独立患者。

若训练空片 FP 降而开发净收益或召回门失败，关闭本空片罚配置；不搜索系数、阈值、中间 checkpoint、seed，且不与失败 v49 像素 CE 堆叠。若七门过，另立从头统一目标源/目标确认，之后再研究 U 增量；不能把 800 目标步替代历史 1600 源步。保留既有 v18/v20 等冻结停止要求与所有失败证据。
