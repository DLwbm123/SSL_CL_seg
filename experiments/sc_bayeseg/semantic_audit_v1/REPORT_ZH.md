# SC-BayeSeg R/J终态零更新语义诊断报告

## 结论

用户授权的前两项诊断已完成，**optimizer更新0次，未构造优化器，未执行第三项code适配**。使用已有split_v1的R/J终态和原两张可见训练L，未修改checkpoint，退出码0。

主要发现：

1. **终态损伤主要已进入语义均值。** R均值配J方差仍有96.14%平均Dice；J均值配R方差仅80.55%。终态大方差不是原正确均值失效的充分条件，恢复小方差也不能挽救J均值。
2. **第二类主要被背景吞没。** JJ的490个GT2像素中，242个判背景、40个判第一类；确定性均值链也有251个判背景。R正margin→J负margin的254个像素中，222个的J胜出类别是背景。
3. **独立输出坐标存在竞争，但当前R状态不支持直接认定“熵经共享特征破坏均值”。** label项的负mu梯度提高第二类平均margin，shape/logits/code项分别降低它，完整目标在输出坐标上接近抵消、净值微正。Gaussian自身logq对mu偏导为0；它经共享特征确实影响均值，但本次四抽样平均的局部负梯度方向反而提高第二类平均margin。
4. **均值/方差参数化存在明显尺度与饱和问题。** R中约58.86%的raw-logsd→logsd导数小于1e-6；但这些观察尚不能说明实际Adam更新及整个J轨迹的因果方向。

因此，应保留“共享参数化/有限步长/Adam行为、code近似误差、结构因子作用尚未区分”的结论，不能把本次结果包装成支持预设的熵破坏假设。没有据此追加训练。

## 2. 均值×方差四格

定义RR/RJ/JR/JJ：首字母是mu来源，第二字母是logsd来源。logsd使用原平滑参数化s=-4+3tanh(raw/3)。四格使用相同4次epsilon_ell，并重现seed50163原proposal对x/m/ell/c的随机数消耗顺序。

RR/JJ的历史主Dice和CE均成功复现。没有进行密度评分，因此没有将某个混合Gaussian的样本错误配上原logq。

| 均值×logsd | 平均Dice | 类1Dice | 类2Dice | 类3Dice | CE |
|---|---:|---:|---:|---:|---:|
| RR | 96.3373% | 98.3246% | 93.3272% | 97.3603% | 0.006504 |
| RJ | 96.1373% | 98.2614% | 92.7871% | 97.3634% | 0.006573 |
| JR | 80.5504% | 96.3518% | 55.8987% | 89.4007% | 0.051818 |
| JJ | 80.3109% | 95.7582% | 56.4420% | 88.7327% | 0.053512 |

固定R均值只换成J方差，平均Dice下降约0.2001个百分点，远小于完整J损伤；固定J均值换回R方差，只恢复约0.2395个百分点，第二类甚至略低于JJ。后一微小差异不应扩大为“大方差有益”的结论，它是在有限四抽样、固定两个均值场下的读数。

确定性R/J均值链分别为96.2640%/80.5537%。这些结果支持：**最终错误主要由均值场变化承载，而不是测试时采样扰动造成**。它们没有回答训练过程中方差更新是否曾促成均值变化。

## 4. 分项梯度定义与核对

只在R终态，4个MC随机流95163..95166，作为诊断抽样而非新增训练seed。采用原完整负ELBO的共同每像素归一化。分项为六个NLL（label/image/shape/logits/code/appearance）、四个正logq以及total。

令g_mu=dL/dmu，g_s=dL/ds。对语义参数eta计算：

直接梯度g_eta = J_mu^T g_mu + J_s^T g_s。

参数组：原shape语义前端、logit共享trunk、最终均值头、最终raw-sd头。logsd输出坐标s和raw-sd头不是相同坐标，后者还乘上平滑tanh导数。

先对4次梯度求平均，再计算主要范数/夹角/方向；JSON保留输出梯度每次范数范围。VJP分解最大相对残差约1.61e-6；输出分项和也核对通过。image、appearance、logq_x、logq_m对语义mu/s及语义参数均为0，符合拆分后的依赖关系。

以下方向均为**局部、未经Adam和clip的负梯度方向**。没有真实参数扰动，单步方向系数也不是实际损失或margin变化量。

## 6. 共享参数：存在耦合，但当前读数不支持预设的破坏方向

### 6.1 映射到参数后，方向可能与独立坐标读数不同

将各组四次平均参数梯度拼接，其与label参数梯度的cosine如下：

| 因子 | 全语义参数cos(label) |
|---|---:|
| shape | −0.7956 |
| logits | +0.8660 |
| code | +0.8605 |
| logq_ell | +0.4560 |
| logq_c | +0.5440 |
| total | +0.8447 |

输出坐标上logits几乎与label正交，映射后却大幅同向；网络Jacobian会改变几何，不能将输出梯度结论直接当作参数更新结论。在本次R状态，完整语义参数的未预条件负梯度一阶上降低label损失、提高GT2平均margin。

### 6.2 单独看logq_ell的方差路径

| 参数组 | 梯度范数 | cos(label参数梯度) | GT2平均margin方向 |
|---|---:|---:|---|
| shape语义前端 | 131.298 | +0.9211 | 提高 |
| logit共享trunk | 142.378 | +0.2099 | 提高 |
| 均值输出头 | 0 | 不适用 | 无直接变化 |
| raw-sd输出头 | 184.830 | −0.8169 | 无直接变化 |

logq_ell没有mu直接梯度，却可通过共享特征间接影响均值；**这证实了耦合存在，但这里共享特征方向并未降低GT2平均margin**。raw-sd头方向与label的方差参数梯度冲突，但它本身不直接改变确定性mu。

因此，不能把“共享”自动等同于“共享造成了本轮均值损坏”。本次对R起点的诊断反而不支持这种单一解释。不同因子仍可能在其他像素、后续状态或经过Adam预条件后产生不同结果。

所有分组和mu/logsd两条VJP读数见[PARAMETER_GRADIENTS.csv](results/PARAMETER_GRADIENTS.csv)。

## 7. 方差饱和、因果边界及当前判断

R终态的ell logsd中位数为−7，5/25/50%分位数均为−7；raw→s导数中位数为0，约58.8552%的位置导数小于1e-6。这说明大范围输出已接近平滑变换的饱和区，独立s坐标的明显梯度未必能有效传到相应raw头；某些共享特征或未饱和位置又可能放大整体参数梯度。

但本次没有扩大方差范围、冻结方差、拆新网络或优化局部Gaussian。饱和是观察，不是已验证的改进处方。

本轮可以较清楚地回答：

- 终态损伤是否主要由测试方差造成？**不是。** 四格明确指向均值场已经改变。
- 第二类主要错到哪里？**主要背景，其次第一类。** 不是只有一个全图平均数的下降。
- R起点独立mu坐标是否毫无冲突？**不是。** label与shape/logits/code存在margin方向竞争。
- 熵是否已被证明通过共享特征损坏均值？**没有。** 当前四抽样平均的共享方向反而改善平均margin。
- 是否已经判定生成结构先验不合理？**没有。** code近似误差与真实边缘结构偏好仍未分离，第三项未执行。

还需保留一个关键解释：即使起点的原始负梯度与label同向，真实训练也可能因Adam历史和坐标预条件、有限步长、非线性尺度变化、随机抽样及后续状态而损害语义。本次既没有调用optimizer，也没有重建实际Adam位移，因此不能由当前局部方向证明实际训练应当安全，更不能将600步轨迹归因于某一个项。
