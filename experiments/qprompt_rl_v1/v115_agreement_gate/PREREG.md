# V115 — class agreement before memory pseudo-label transfer

Frozen before new model work. V114 failed its broad Adam-state criterion and all three deterministic policies still had negative absolute continuation. The human literature discussion asks for actions with substantive evidence-selection meaning. Inspection of the actual transfer loss shows that memory class confidence >.7 and memory flip consistency admit transfer even when EMA and memory predict different classes. V115 tests one structural admission rule before considering a learned selector. This is not an RL experiment or a new threshold search.

## Hypothesis and one intervention

Restrict the existing memory-transfer gate to pixels where argmax(memory)==argmax(EMA). Keep the confidence threshold .7, existing memory flip agreement, EMA admission mask, normalized class weights, alpha, loss denominator and coefficient unchanged. On rejected pixels the transfer target is the original EMA target; on agreeing pixels loss and gradients must exactly match the old loss. Use a uniform detached memory distribution only internally at rejected pixels to disable the old confidence gate, reusing the exact existing loss implementation. Do not alter stored memory outputs, models, features or probe semantics. Since C=3 and 1/C<.7, this is exactly a gate conjunction. All pseudo-target inputs remain detached. Report classwise counts of valid, admitted, previously eligible, rejected and active transferred pixels. No additional forward, data read or label query is introduced by the gate.

This can suppress harmful teacher conflicts but can also suppress correct memory corrections of an erroneous EMA. Class agreement is not ground-truth correctness. Positive results establish only a deterministic selection signal; they do not prove an RL advantage, causal label accuracy, long-term credit assignment or independence.
