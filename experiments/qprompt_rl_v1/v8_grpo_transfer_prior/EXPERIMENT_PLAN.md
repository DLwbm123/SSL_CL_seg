────────────────────────────────
三、新控制对象：全池 U 上的知识迁移，而非图像子集
────────────────────────────────

所有正式方法使用全池 U 的原生遍历方式。

定义：
q_E：当前学生 EMA 的弱增强预测。
q_M：任务入口已学模型的冻结预测。
p：当前学生在对齐训练视图上的预测。

q_M 在当前任务中完全冻结，包括参数和相关 buffer。
q_E 按原生 EMA 更新。
两者都不得接收学生损失梯度。

只引入一个小规模离散动作空间，共 9 个动作：

a = (alpha, b)

alpha ∈ {0, 0.25, 0.5}

结构权重模板，顺序为 background / rim / cup：
b0 = (1.0, 1.0, 1.0)
b1 = (0.5, 1.25, 1.25)
b2 = (0.5, 1.0, 1.5)

这些数值是预登记的筛查设置，不是已优化配方。
本轮不搜索其他 alpha、权重、温度或阈值。

1. 记忆可靠性门控

仅使用当前 U 构造 g_M：
- q_M 最大概率 > 原生阈值 0.7；
- 原图与水平翻转后逆对齐预测的 argmax 一致；
- 位于原生 valid 区域。

门控完全 detach。
不能读取图像标签，也不能用旧域性能校准门控。

混合完整的三分类概率向量：

q_a = (1 - alpha*g_M)*q_E + alpha*g_M*q_M

不得分别对 rim/cup 概率通道随意插值后不归一化。
不得把单个 KL 通道贡献当作一个非负 KL。

2. 固定有效监督区域

本轮所有动作使用相同的准入规则：

m = valid AND [max(q_E) > 0.7]

不让动作同时改变阈值和有效像素集合。
记忆参与监督不意味着额外准入低置信像素。

3. 结构预算归一化

按 detach 后的 argmax(q_E) 分配 b 的结构权重。

仅在 m 内归一化，使：
sum_p m_p*w_p = sum_p m_p

保留原生 valid 像素分母，而不是改成有效像素均值：

L_U(a) =
sum_p m_p*w_p*KL(q_a,p) / max(sum_p valid_p,1)

学生损失：
L = L_supervised_native + 0.5*L_U(a)

没有有效像素时返回可求导的零值，不放大少数像素。
记录归一化前后权重、有效监督量和真实梯度范数。

alpha=0 且 b=b0 为 NATIVE 动作。
该动作必须直接调用原生 U loss 路径，验证数值及更新等价。

memory_available=false 时：
- 只开放 alpha=0 的三个动作；
- 其他动作 mask；
- 不把重复的等价动作留在采样空间。

本轮不控制学习率、A/B 学习率比例、正交强度、总 lambda_U 或 EMA 衰减。

每个情境保留自己的当前学生状态，不能跨情境混用 Adam/EMA。

每组：

2. 从行为策略采样 4 个动作。
3. 每个分支从完全相同入口训练 100 步。
4. 计算奖励。
5. 更新控制器。
6. 主情境状态按预登记的 branch 0 延续。

不能保留奖励最好的分支。
不得把其他固定动作作为 on-policy 样本混入策略梯度。

奖励：

D_new：查询患者等权、rim/cup 等权 macro soft Dice。

G_i =
0.25*(D_new_25 - D_new_entry)
+ 0.75*(D_new_100 - D_new_entry)

F_i =
max(0,
D_old_memory_reference - D_old_100 - 0.005)

r_i = G_i - F_i

全部 Dice 使用 [0,1]，0.005 对应 0.5 pp。

保持参考是该虚拟任务的冻结记忆模型；
不能每个 group 重置参考，从而掩盖累计退化。

这些“旧/新”查询均属于第一域阶段内的模拟情境。
它们不是已经离开的真实旧域数据。
模拟保持收益不能直接写成真实持续学习保持保证。

GRPO 设置：
- group size = 4；
- clip epsilon = 0.2；
- 4 个 full-group 更新 epoch；
- 每个 epoch 一个完整 group optimizer step；
- Adam lr = 1e-3；
- grad clip = 1；
- entropy coefficient = 0.01；
- temperature = 1。

不要照搬旧实现中“每个样本分别 Adam.step”的 16 步顺序更新。

优势：
A_i = (r_i - mean(r)) / max(std(r), sigma_floor)

sigma_floor 根据阶段 A 的配对重复噪声按预登记公式确定：
max(1e-4, median(|r_stream1-r_stream2|)/sqrt(2))。

该量是重复波动尺度，不包装成精确统计标准误。
组内 std 小于该尺度时，记录低可辨识组并跳过 actor 更新。
不重采样补齐“有效 group”，不延长总训练。

每个 epoch 后记录精确离散策略 KL 到行为策略。
平均 KL 超过 0.02 时终止本组后续 epoch；
不通过回滚 optimizer 隐藏已经发生的更新和成本。

记录：
原始奖励、奖励分量、组内 std、优势、
动作概率、entropy、KL、梯度范数、
clip 比例、动作激活差异和实际更新次数。

禁止看到高熵后自动减小熵系数。
禁止看到接近均匀后自动降温。

第一域开发读出：
4 个预登记情境；
NATIVE、FIXED_BEST、UNIFORM_ACTION、PRE_FROZEN_601、PRE_FROZEN_602；
每个 200 步；
共 4,000 次学生更新。

开发情境使用 Q_dev 患者和预登记的不同成像条件。
额外入口准备最多 400 步。
Q_dev 不参与 actor 更新。

保留两份训练末端策略，不按目标域结果挑种子或 checkpoint。

若两份策略在第一域开发效用上均不优于 UNIFORM_ACTION，
且没有任何预登记的学习—保持改善：
状态 STOP_PRIOR_NOT_TRANSFERABLE_IN_D1_SCREEN。
停止，不自动增加第一域训练量。

每个域、每个种子运行以下 7 组：

1. NATIVE_ALL_U

2. FIXED_BEST

3. UNIFORM_ACTION

4. YOKED_SHUFFLE

5. PRE_FROZEN
加载第一域对应种子的策略，目标域不更新 actor。

6. ONLINE_SCRATCH
相同网络、相同状态、相同动作空间；
从零初始化控制器，在目标域有限在线训练。

7. PRE_ONLINE
加载第一域策略，在目标域使用与 ONLINE_SCRATCH
完全相同的在线预算和更新规则。

      - 0.1*max(0, K_currentU_after - K_currentU_entry)
