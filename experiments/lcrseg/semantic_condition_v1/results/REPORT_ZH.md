# 空间语义条件残差：Siemens→Philips 首轮结果

**结论：本实现未通过预设的 SSL／历史分割保持联合收益门槛。** aligned_ssl 的新域验证 Dice 为76.9336%，低于 aligned_lonly 的77.0676%，也低于同期 DenseFixMatch 的82.4014%。相对空间打乱 SSL，语义对应在新域仅+0.1921 pp，旧域−0.0260 pp。工程正常不等于方法有效；这轮不支持将该实现作为已验证的TMI方法贡献。

本轮是SCOPE核心思想的独立卷积适配研究，与CARE-Seg独立；不是作者EEG实验的原样复现。所有数字来自固定验证集，不是独立test。只有Siemens→Philips一次转移、seed163、每组3500次实际更新，不能拼接旧实验声称获得完整多域持续学习链。

## 完成与成本

五组均EXIT0；各3500条连续实际调用记录、固定最终EMA及可读有限checkpoint。model／EMA／优化器浮点状态有限；四个条件组最终原U-Net、原生3×3头和历史P及其EMA与初始状态精确一致。初始原模型函数误差均为0，当前L及适用组U的模块梯度非零。控制器及工作进程已全部退出。

总成本 **17,692次 = 17,500正式 + 192工程**，无未确认预留。工程包含Dense32（复用通过记录）、v1 aligned_lonly失败32、四个v2组各32；恢复重放照计，工程权重全部丢弃。首次CuBLAS环境错误发生于0更新。预算20,000，余2308未使用，不自动用于延长或调参。源43600次历史更新单列；原型准备仅原10L／230切片一次遍历、0优化器。审计不增加患者前向或优化器调用。

v1输出为s·tanh(a)，入口导数也缩至s=0.1；两例CE虽下降但未过预定绝对下降1e-4门槛。正式评估前冻结v2为s·tanh(a/s)，保留相同±0.1边界、函数族、3328参数、零入口与SGD设置，入口斜率恢复1。没有放宽工程门槛。该变更及失败成本完整保留；不得称为未修改配方复现。

P由真实源L标签绑定类别，当前L与FixMatch的U伪标签共同训练同一残差，是合法的类别语义路径；但本轮没有观察到目标验证集上的U增益。上表只是接受量，不是伪标签准确率，不能用它证明错误伪标签导致失败，亦不能访问U隐藏GT来补解释。

工程两例上空间移位后条件argmax仍有94.8941%一致，原条件的背景概率质量95.9974%；概率平均绝对差0.0359857。该操纵在背景占比较高的样本上较弱，不能把接近的对照结果解释为“语义条件一般无作用”。该统计只来自工程两例，不能泛化为整个训练／验证集的比例；不事后重新选择移位。

语义SSL相对Dense保住旧域约3.56 pp，却损失新域约5.47 pp；空间打乱组也保住旧域。因此证据不足以把历史保持归因于类别语义对应，而非冻结网络、低容量或有界输出。语义SSL相对L-only的新域−0.1340 pp，以及旧域U交互−0.0392 pp，均不支持同一机制带来联合收益。

本轮保留负结果，结束本实现的冻结首轮，不使用剩余预算继续同配方、换seed、加域、加模块或恢复旧方法。后续若有新研究设计，应先解决当前目标训练／适应能力及强语义对照问题，并重新冻结范围；不能把未验证的原因包装成已完成的创新。半小时研究检查按用户要求保留。
