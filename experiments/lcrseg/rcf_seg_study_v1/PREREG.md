# RCF → TransUNet / M&Ms：冻结迁移协议

日期：2026-10-18。用户已明确授权 TransUNet 源模型训练、完整 RCF 迁移、专家隔离、历史特征原型和无任务 ID 路由，以及匹配对照。此协议独立于已经失败的 CARE V1，不修改其结果或门槛。

## 来源与复现边界

- RCF：ICLR 2027 submission 15032，https://openreview.net/forum?id=6EnlHthjhS 。依据当前可得完整 PDF §3、附录 C.3/C.4/C.8；公开页面与 PDF 未找到作者代码链接，可靠性模块是按论文重实现。
- TransUNet：官方 https://github.com/Beckschen/TransUNet ，固定提交 `02ef0010b36eb8328b5e689eadaf613602edf9b8`。`upstream/` 三个源码文件原样保留，许可证 Apache-2.0 随附。加载官方 README 指定的 Google ViT ImageNet-21K `R50+ViT-B_16.npz`；只读加载编码器，解码器随机初始化。
- DSE-SSF：https://openreview.net/forum?id=8iPy2VA94x ，已下载并阅读全文。其无任务 ID 路由缺少具体算法，动态图像素迁移需额外设计，未选择为本次实现。未实施或运行 DSE-SSF。
- 本次是分类类增量方法到同类别域增量分割的迁移，不是原论文分类分数复现。

## 数据、存储、时间顺序

使用现有不可变 M&Ms canonical320 HDF5 和 seed0 划分。只允许 `evaluation_eligible=true` 的记录。沿用各域可见训练标签，不打开 train_unlabeled 的隐藏标签；不使用测试标签。唯一模型训练种子163。

域序为 Siemens → Philips → GE → Canon。源模型和每个域的路由只读本域训练图像，包含可见标签样本的图像与 U；构建路由不打开标签。源域路由在源阶段退出前构建，后续只保留摘要。后续阶段不回放历史图像、像素特征或标签；验证阶段仅报告已见域，不选择 checkpoint、不调整超参数。

源域训练也只使用现有可见 L；不把源 U 的隐藏标签变成全监督标签。所有模型、临时数组、缓存、checkpoint、私有明细和日志均保存在 pro5000 数据盘新建运行目录；环境依赖单独安装到新运行辅助目录，不改已有环境。

## 架构

R50-ViT-B/16 TransUNet，n_skip=3，四类。HDF5 保持不变；网络内部将单通道输入双线性缩放224×224并复制三通道，输出 logits 双线性回到原384×384，原分辨率标签监督。图像预处理沿用已冻结 HDF5，不另作 ImageNet 均值标准差转换。

Siemens 源阶段训练完整 TransUNet，包括随机初始化的解码器。之后冻结所有源参数、LayerNorm、解码器和 BatchNorm running statistics。每个新域从同一冻结源网络增加 Transformer 最后六层 Q/V LoRA：rank8，alpha16，dropout0.05，up投影零初始化。历史 LoRA 永久冻结。共享解码器与 head 不更新。训练梯度可通过冻结解码器回传到当前 LoRA。

原 RCF 始终冻结 ImageNet 特征；本迁移使用经过 Siemens 训练后冻结的编码器，这是适配医学分割源模型的明确差异。无逐域新增解码器，无额外空间损失，无 CARE 模块。

## RCF 的保留机制与必要改动

1. 预测二维第一轴：两弱视图平均概率的最大值乘以 `1-JS/log(2)`，再 logit。选择温度2；学生 hard CE 温度1。
2. 第二轴：冻结编码器语义原型相似度，预测类减最佳其他类。原型仅用当前全部可见 L，三视图：原图、水平翻转、垂直翻转并逆对齐；每像素特征归一化后跨视图平均，再按类平均归一化。标签最近邻到14×14 token中心；两弱视图 token 相似度平均后插值回原图，仅用作语义证据。
3. 训练缓存使用完整384×384的预测目标、后验和选择掩码，保留像素坐标身份；不将伪标签缩到32×32后回传。注册的两个弱视图为原图与水平翻转，这是对原随机两弱视图的确定性几何替代。
4. 为限制密集像素 GMM 拟合成本，每次访问当前每个唯一 U 切片一次，每切片确定性等距抽最多2048个像素估计 MAD/GMM。抽样不依赖标签、置信度或解剖类别；这是相对原文“全部图像样本”的像素近似。拟合后对全部唯一 U 像素计算后验、EMA和阈值。
5. MAD系数1.4826，尺度下限0.05；二维两分量full covariance GMM，最多25 EM，容差1e-4，收缩0.2，jitter1e-4。三种低/高分位初始化0.10、0.25、0.35，选最高似然；clean为两标准化均值之和较大分量。不用标签给GMM分量命名。初始化细节、退化阈值与jitter为论文未完全指定处的固定工程选择。
6. 像素后验EMA0.7；eta0.90（沿用原文5%/25%标签设置，当前约20%患者可见标签）。最大平均后验≥eta的排序前缀产生阈值，阈值增加立即生效，减少使用0.7旧+0.3新。无有效前缀则拒绝全部；分数并列沿用 `>=`，不声称有限样本真实风险保证。
7. 无有效GMM复用之前有效状态；从未有效则该epoch仅监督。后验不按伪标签改变重置，与原RCF一致。
8. U hard CE以选中有效像素数归一化，空选择返回可微零。源CE+Dice，增量监督CE，U权重1，无源域蒸馏或额外损失。
9. label-free路由：冻结源编码器归一化token特征空间平均，再归一化得到每切片向量。各已见域十个cosine K-means core，每core距离0.70–0.95分位的样本产生最多三个boundary中心。25次迭代、1e-4容差、无标签farthest-point初始化。Top-3原型相似度均值最大域选择专家。源域专家标记`source`；部署不读取站点名。逐切片路由，非真实厂商oracle。

## 预算、匹配对照、评估

- 源训练12000步（80个预算epoch，每epoch150次更新），AdamW1e-4、weight_decay1e-4、poly0.9衰减。该源预算是预先固定的分割适配选择，不是RCF原源模型训练预算。
- 各新域1500步：300步仅监督warm-up + 1200步半监督（10×150，对应原文2+8epoch）。AdamW5e-4、weight_decay1e-4、固定学习率。
- 分支 `confidence` 与 `rcf`：完全相同源checkpoint、各域LoRA初始化seed、患者→phase→slice采样、几何/强度增强、batch2 L + batch2 U、全部可见L、当前1500步预算、每150步刷新伪标签、冻结语义路由结构、推理协议。confidence同样使用两视图/温度2/整epoch缓存hard目标，但以固定0.95代替RCF可靠性选择。不是另一条EMA教师baseline。
- RCF原分类batch16+48与RandAugment改为已有医学分割batch2+2、共享翻转几何和strong亮度/对比度/噪声，无cutout。采样按患者、phase、slice，不按图像均匀。
- 正式更新总额21000：源12000 + 两分支×三目标域×1500。工程源34步（exact-resume2 + 两例32步下降检查），每目标分支2步，共46步；全部工程更新恢复到预检查状态，不进入正式轨迹。无自动重试、增加seed、延长训练或扫参数。
- 固定终态模型为主，每域结束验证所有已见域，按phase→patient→class macro Dice。报告各阶段各域Dice、最终均值、各域获得能力后到最终的遗忘，以及路由切片计数。源模型、置信度与RCF共享数据评价协议；旧U-Net/CARE结果仅为历史背景，不能作为骨干匹配比较。
- 每阶段记录optimizer物理更新数、资格检查、冻结参数与buffer不变检查、训练日志、终态checkpoint与推理router。无定时监测；后台启动后做一次检查，后续按用户询问查询。完整实验结束确认后，公开发布源代码、协议、汇总结果及报告，排除数据、权重与患者明细。

## 局限

单种子验证性迁移，非独立测试结论；源模型小标签预算与token空间语义质量可能限制结果。专家隔离只保证给定专家的函数保留，路由错误仍可能导致实际遗忘。固定解码器可能限制新域适应，这属于本轮方案，不根据验证结果追加可训练解码器。未获得作者代码，所有原文未指定实现选择均不冒充官方实现。
