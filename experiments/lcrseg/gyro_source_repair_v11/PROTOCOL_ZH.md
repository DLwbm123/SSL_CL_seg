# GYRO v1.1 源接入修订：校准后重置动量、三组源验证

日期：2026-10-19。用户已明确授权实施本协议，**总 cap 404 次实际优化器调用**（含工程、失败、丢弃和恢复重放）。仅 GPU3；与 BayeSeg、CARE-Seg 的方法、代码、状态独立。没有目标域训练授权。本协议更新并公开推送之后才启动优化器调用。

## 固定方法与阶段

复用原生单通道四类 U-Net、原 3×3 head/插值、原预处理、seed163、Siemens 原 10L/38U/23 人验证划分。GYRO 使用既有 bottleneck GAP→128/512/128 projector（BN/ReLU）、V2 弱强增强、K10 固定阶段 simplex、均值不再归一化、最近参照 stop-gradient 和归一化负核范数。没有读出绑定、伪类别参照、KD 或新模块。数学与原 GYRO 的区别仍是先前披露的医学/资源适配，不声称作者代码或原 benchmark 原样复现。

1. **共同 projector 校准**：原 43,600 步最终 EMA（验证 80.3674066377%）保持只读；其固定特征上训练同一个新 projector，β=0、谱权重1、SGD Nesterov、LR0.03，一次源图像遍历共69步。16图/步、双视图，末批补齐；不读取 U GT，校准不更新原生 U-Net。
2. **阶段边界**：保留校准后的 projector 权重和全部 BN 状态，保留原生网络原始权重；三组从完全相同状态出发。**重建优化器，native 和 projector 动量均为空**，不载入校准动量，不载入原43,600步学生动量。边界明确检查，并在 checkpoint 中记录。
3. 三组分别执行 **69 次正式更新**，正式分割学生完整主干/decoder/head 全部原允许参数训练，只有既有 sigma.weight、grad_update 固定。采样顺序及当前 L2 完全配对，几何图像使用源第二遍的同一固定图像顺序。

| 组 | native LR | projector LR | 损失 |
|---|---:|---:|---|
| CE_high | 0.03 | 0.03（无梯度，不更新） | L2 CE |
| CE_low | 0.001 | 0.03（无梯度，不更新） | L2 CE |
| GYRO_low | 0.001 | 0.03 | L2 CE + 0.01 GYRO（β=1/3） |

各组 LR 在69步内固定，原 weight decay 与 Nesterov momentum0.9、全局裁剪1不变；显式按参数组设置 LR，不被共享引擎的统一赋值覆盖。原源图像几何流由1,102张训练切片组成；CE仅原10L，U隐藏GT和test封存。两例工程权重不进入任何正式阶段。

## 工程与预算

共四个阶段/组各最多32次工程，全部丢弃；共同校准69 + 三组69×3 = 276正式，工程最多128，合计404。所有 optimizer.step（含projector-only、失败调用和恢复重放）预留后记执行；未确认预留保守占用。任何失败都不额外增加cap或该阶段的调用数。前轮GYRO170/剩10160以及更早18652/剩1348完全另列，不挪用或混算。

工程检查包括入口分割输出不变、校准native精确不变、joint全原允许参数可训练、校准权重/BN保留且双动量清空、L/U实际梯度、完整分组（enc1/2/3/bottleneck/decoder/projector）golden-batch、checkpoint和非空动量恢复、两例目标学习。固定两例目标在32次内绝对下降≥1e-4；其中30次常规、1次恢复重放、1次真实完整目标更新合计32。校准两例目标是无锚谱目标，joint两例目标为CE；真实完整联合目标另验一次。工程不证明科学收益。

## 诊断与停止

- GYRO_low每步记录完整编码器（含bottleneck）加权谱/CE梯度比 `r=0.01*||gG||/max(||gCE||,1e-12)`；若 r>0.25，在优化器调用前保留状态并停止，不自动降权、投影梯度或改变网络。该比值不是带动量/衰减有限步长的功能保证。
- 分开记录 native/projector 实际参数位移、clip前后范数、各组LR、CE/谱梯度及夹角、projector输入/输出范数/BN统计、图像几何曝光量。固定训练L query 的前后CE、类Dice作诊断，不用验证选学习率或λ。
- 目标为固定最后**学生**在原23人/46个ED/ES体上的结果；另报0.999 EMA作为诊断，不能改选EMA通过。原10L/20体训练与验证分开，各类及ED/ES、原模型和CE_low的患者配对改善/下降人数与中位数均报告。
- **GYRO_low 最终学生相对原80.3674066377%下降超过1.0pp，或相对 CE_low 下降超过0.5pp，判定源接入失败并停止**。后者方向固定为GYRO_low减CE_low，必须≥−0.5pp。CE_high是诊断组，不因为其科学结果较差而跳过另外两组；任何工程失败仍保留现场停止，不盲目重试。
- NaN/Inf、错误访问、坏恢复、意外冻结/更新、存储或显存不足均停止并报告，不换seed、β/K/V、数据、损失或延长。不因有余额自动调参。
- 即使源门槛通过，也仅证明接入具备可用性，**不自动进入目标域、不生成历史回放库、不追加任何新实验**，不声称已证明SSL/CL联合收益或TMI创新。
