# Siemens 硬伪标签候选：固定终点负结果

相对既有 SSL，23/23 位验证患者均下降，平均 −51.5390pp；相对 L-only 平均 −58.0131pp。训练集也大幅下降，不能仅用验证集泛化差解释。

对部署异常做了针对性检查：最终训练 checkpoint 的 native 张量与 sealed 模型完全相同，部署 transform 为单位阵，模型没有 BatchNorm running-stat buffers。因此没有发现封装时权重替换或运行统计差异；这不等于排除所有训练机制问题。未追加验证推理。

本轮主要改变仅 U 目标：相同已接纳像素上，类别等权硬伪标签 CE 加现存前景 Dice。保持 lambda_U=0.25、置信度/PAS、LCTX、数据、初始化、优化器和固定训练终点。少量错误前景获得较大权重可能造成自强化，但当前证据不能确证机制。

预算：L-only 43,601 + 本轮 43,600 = 87,201 次，剩余 43,599。最后一轮只检验一个预先固定的保守 U 目标，不扩大预算。无独立 test、U 真值、额外种子、最优 checkpoint 选择。GPU/backend 差异仍限制归因；论文分数不能作为同协议结论。
