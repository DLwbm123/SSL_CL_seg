## 1. 改变核心问题

半监督持续学习中的U没有永久真标签。若把当前伪标签一次性累积进`B_U=Σφ_i q_i^T`，之后丢弃样本，模型变化时就无法正确重算历史U的贡献。保留旧U的错误解释可能被误当成“保持知识”。新方案要区分：

- **不可修改的监督证据**：历史L真实标签的相关统计；
- **允许重新解释的未标注证据**：历史U在固定特征坐标中的分布摘要，不绑定进入记忆时的类别判断。

它的统一性在于：同一个未标注状态在当前域用于SSL学习，在后续域用于重新估计历史U对解析解的影响；不再分别外挂一个SSL一致性模块和一个CL保护模块。

## 2. 为什么只存一、二阶矩不够

令一维原始特征集合为`X={-2,-2,1,3}`、`Z={-3,-1,2,2}`，映射`φ(x)=[1,x]`。

二者都有`Σφφ^T=[[4,0],[0,18]]`。但当新分类器把`x>1.5`判为正类时，正类交叉矩`Σφq`分别为`[1,3]^T`与`[2,4]^T`。所以不存在只根据相同Gram矩阵就能为任意未来分类器重算正确`B_U`的通用函数。

精确整数检查见[UNLABELED_STATE_COUNTEREXAMPLE.json](UNLABELED_STATE_COUNTEREXAMPLE.json)。这是状态信息不足的反例，不是新的数学定理或医学实验。均值/协方差不足以支持任意重新标注，也不能据此反推所有历史方法都有此问题：ILR-ELM用图平滑，不是把全部U一次硬标注。

## 3. 一个可写清楚的候选算法

### 固定表示与记忆对象

先固定现有Siemens U-Net编码器、全部skip/decoder，以及后续使用的响应映射φ。可复用上一版核对到的最后16通道/3×3局部上下文构造响应基，但不声称该固定基有新颖性。首版仅学习四类解析头W，不能称为全网表征学习。

保存：

1. `G_L=Σ_L w φφ^T`与`C_L=Σ_L w φy^T`，历史真标签统计精确保留；
2. `G_U=Σ_U w φφ^T`，历史U的二阶矩精确保留，不含伪标签；
3. U分布摘要`{n_j, μ_j, v_j}`：每个摘要的总权重、响应均值、簇内平方半径均值。所有统计在同一固定φ坐标中；n是权重而不一定为整数患者数。

摘要是**特征分布近似记忆**，不是原图，也不是纯A/B充分统计。计算中会查询摘要中心，因此不宣称“完全无回放”、隐私保证或可以精确重新标注每个旧像素；只能重新解释簇级责任分配。若摘要只有单个成员也不能把它宣传为充分聚合的匿名统计，真实数据协议须明确私有存储边界。

### 同一潜变量目标

令簇j的四类责任概率为q_j。对簇内真实响应向量φ_i（推导用，部署后不保存），考虑：

`F(W,Q) = tr(W^T G_L W)-2tr(W^T C_L)+η||W||²`

`          + λ Σ_j Σ_(i∈j) w_i Σ_c q_jc ||φ_i^T W-e_c||²`

`          + λτ Σ_j n_j Σ_c q_jc log q_jc`。

q_j非负、和为1，e_c为四类one-hot，τ>0。所有簇的U都参与，不设置信阈值，不增加冲突状态或结构修复。L/U/域权重在未来协议中预先按患者与合法数据曝光归一化，不能让背景像素数任意淹没L。

**Q步**（给定W）：

`q_j = softmax(2 μ_j^T W / τ)`。

这是因为展开平方项后，与类别c相关的部分只有`-2 μ_j^T W e_c`。注意这里是加权“各类平方误差的期望”，不是`||φW-q||²`；后者的Q更新不同，不能混用公式。

**W步**（给定Q）：

`M = G_L + λG_U + ηI`

`W = solve(M, C_L + λ Σ_j n_j μ_j q_j^T)`。

每个阶段可复用M的分解，在有限次Q/W交替中重新解释**所有保留的历史U摘要与当前U**。不继续累加旧版固定`B_U`，否则双重记账；真标签C_L永不被模型重标。

对于固定的数据权重与簇划分，这两步都是各自子问题的准确解，可下降同一个目标。但整体目标非凸，**不是一次闭式求得全局最优**，也不保证不同域顺序收敛到相同局部解。“解析”指分块更新，不可宣传成ACIL式无条件联合等价。

### 为什么保留精确G_U有意义

簇内q共享时，完整U二阶矩控制平方项曲率：

`Σ_(i∈j) w_i φ_iφ_i^T = n_j(μ_jμ_j^T + Cov_j)`。

只用`n_j μ_jμ_j^T`会丢掉簇内变化。方案保存全局精确G_U，W步因此保留全部已见U的二阶曲率；摘要只近似责任分配，并不把全部U都当成重复的中心点。

这能将“压缩造成的类别责任限制”与“丢弃特征方差”分开评估。它是候选机制的一项实质要求，但是否已有等价实现仍须核查，不能直接命名为新贡献。

## 4. 有限记忆如何处理，误差在哪里

摘要新增/合并只使用当前合法U与已保存聚合量，记忆预算J固定。合并时n、μ、v可以按加权矩精确更新；G_U不因合并改变。合并后不能凭空恢复旧簇内的原始点，也不能承诺之后可随意拆分历史簇。

对给定W，让`q_W(φ)=softmax(2φ^T W/τ)`。其Lipschitz常数可取`L_q≤||W||₂/τ`。以中心责任近似逐点责任时：

`||B_U,point(W)-B_U,summary(W)||_F`

`≤ L_q Σ_j n_j [v_j + ||μ_j|| sqrt(v_j)] = ε_B(W)`。

这个界来自δ=φ-μ的零均值与`||q(φ)-q(μ)||≤L_q||δ||`。对**同一个给定W对应的下一次解析W步**，保留同一精确M时：

`||W_next,point-W_next,summary||_F ≤ λ ||M^-1||₂ ε_B(W)`。

这只控制单个条件更新，不等于控制整个非凸交替轨迹、未来Dice或旧域误差。τ很小、W范数大、摘要簇散布大时，该界会变差；这些是必须报告的失败条件。固定簇内交替的下降性质，也不能跨越改变簇划分的合并操作直接沿用。

若达到预算后压缩误差过大，记录失败/保留现场；不能自动增加J、改温度、换seed或扩大训练。不能依赖隐藏U真标签选择合并，也不能用验证患者参与构建摘要。

## 5. U-Net接入及与CARE的独立性

原生U-Net提供固定局部表示，解析头直接输出分割类别。最终16通道、分类卷积3×3与插值几何已在前一份设计核对。新头通常需要独立源阶段解析校准，不能继续冒称新序列入口必然等于原80.3674%；源端点与所有后续对照须重新统一、单独报告。

推理只需要φ(x)与W，不查患者支持集、不需要域ID或U摘要库。U摘要仅在合法训练阶段参与头部更新；test封存。

本方案研究的是**未标注证据的记忆表示与可修订解析更新**。没有可靠性网络、阈值筛选、冲突识别、低置信区域修复或CARE模块；Q是目标函数中的潜变量，不是另一个伪标签质量判别器。也不恢复此前跨患者支持关系读出。

## 6. 与已有方法的区别和仍未通过的新颖性检查

- 相对ACIL：未标注目标会随W变化，不能仅保存一次固定标签的交叉矩；使用精确G_U与可查询的分布摘要，而非只用监督相关矩阵。
- 相对ILR-ELM/PRMROSE：U通过潜在类别责任进入解析目标，不只是图Laplacian平滑；摘要会被当前头重新解释。但“原型＋半监督在线解析”已有先例，仍须逐式比较。
- 相对Optimistic LSC/RSSL：交替估计软标签/解析头已经存在，不作创新；该实现保留完整X_u，我们提出的是有限历史摘要上的簇共享目标及曲率/责任压缩误差区分。
- 相对STSD：不求广义迁移子空间/OT，也不更新encoder；不拿其margin条件当本方法保持保证。
- 相对在线量化图SSL：不能把“聚合中心保留旧U”本身算新；需要核查它是否已经覆盖相同的可修订责任和解析状态闭合。若等价，这个候选也应淘汰。

潜在TMI贡献只能落在：**有限历史记忆下，保留尚未确定的U语义，使后续监督能修订历史解释；同时对解析曲率损失与责任压缩误差给出可验证控制。** 目前这是值得核查的问题与具体原型，还没有证实新颖性和临床收益，不直接称为TMI算法。
