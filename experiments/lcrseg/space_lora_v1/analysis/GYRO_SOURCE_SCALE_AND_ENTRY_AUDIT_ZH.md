# GYRO 源准备退化：梯度尺度、学习率与成熟模型接入核查

日期：2026-10-19。范围：实际执行源码、已有 preflight/telemetry/成本/评估及官方正文/补充。**只读既有小型记录与静态分析；没有重读权重做重复审计，没有患者前向、反传、SVD 或优化器调用，没有新实验。** GYRO 保留，不更换方法、不引入模块，与 CARE-Seg 独立。本文件按用户本轮明确要求单独推送；不包含其他私有研究文档或运行信息。

## 1. 结论先行

尚不能在没有匹配消融的情况下把 −19.6040 pp 全部归因给某一个因素，但已经定位到具体、可修正的接入风险：

1. **谱梯度不是与 CE 同量级。** γ=1 首批 enc1–enc3 的谱梯度范数为 CE 的 10.67585 倍；把核范数数值缩到约 [−1,0] 并不能校准网络参数梯度。
2. **成熟源网络的学习率被重启放大。** 原 FixMatch 最后一次更新约 0.00585364，源准备重新用 0.03，约 5.12502 倍，138 步内几乎不衰减。
3. **冷启动 projector 立即牵动已经收敛的编码器。** 不是从头学表征，却把新随机 MLP/BN 的全权重谱信号直接施加到成熟编码器；没有先校准新增接口。
4. **源目标和评估时间平均均发生切换。** 原来是 CE+FixMatch 的 EMA；准备阶段变成 CE+全局图像谱学习，移除了原像素级 U 分支，并以固定最后学生评估（所谓源 EMA 每步直接复制学生）。这些都不是原实验的低风险续跑。

以上是实际执行/设计事实，不是已经分解好的四项因果效应。最小修正应针对初始化及扰动尺度，先只验证源网络不受损；不据此淘汰原 GYRO，也不直接进入后续域。

| 第 100 步 CE/谱项 | 0.048332032 / −0.715152383 | 与首批不是同一 L 输入，且 β 已从 0 变 1/3；不能当成固定样本 CE 曲线或同一谱目标的下降证明 |

测量缺口必须更正：原 preflight 的“encoder”分组**没有包含 bottleneck**。上面的比值是 enc1–enc3 子集，不能声称整套编码器、全部网络或所有 138 步都保持 10.68 倍。没有记录两项梯度夹角、逐层更新或全过程范数，不能认定它们反向冲突，或精确还原每一步的贡献。

### 全局裁剪为何没有解决这个问题

实际代码是先反传 `CE + G`，再把所有可训练参数梯度统一裁剪到范数 1，最后执行带动量、Nesterov 及 weight decay 的 SGD。裁剪按同一个标量缩放合成梯度，**不把谱项/CE 的相对权重调回一致**。

仅由记录的互不重叠参数块，即可对首批合成梯度给下界：

\[
\|g_L+g_G\|\ge
\sqrt{(1.675656488-0.156957692)^2+0.191102785^2+0.650304445^2}
=1.66309>1.
\]

因此首步裁剪必然激活，不依赖未知的梯度夹角；缺失的 bottleneck 只会增加完整范数。空动量下首步 Nesterov 的无衰减近似位移为 `0.03*(1+0.9)*1 = 0.057`，与记录 0.057001898 接近。weight decay 在 PyTorch SGD 内加入，故不是精确相等关系。该核对说明实际大步长与当前实现相容，**不是“有裁剪便是小幅微调”**。

### 源损失替换不是纯增加 U

原源模型已经通过高置信度像素伪标签学会分割；本次源阶段没有保留原 FixMatch U 像素 CE，只保留 L2 CE，并在另外 16 张图像上加全局谱项。样本数相近不等于监督语义和梯度同量级。这里先如实记录这一变更，不自动加回损失或另加教师/KD，避免把原因核查变成新模块堆叠。

COSTS/telemetry 中 `U_reads=0`、`U_pixels=0` 是复用引擎的伪标签流计数，不代表没有使用无标签图：实际源几何输入来自 `ImagePool` 的 10L+38U、1,102 张图，直接走图像流。它们不能拿来证明 U 未接入；将来需要单独记录 geometry/L/U 图像暴露量。

## 3. 哪些代码问题已核对、哪些证据不存在

- 负核范数符号、每视图 L2 normalization、均值 c 不再归一化、同阶段最近参照 stop-gradient 和固定 frame，未发现与定义相反的实现；最小化负核范数即最大化核范数。没有证据表明此次是符号写反。
- 原生分割入口输出误差 0，原 checkpoint 参数与入口相等；原 head/插值保留，没有替换输出接口。原 U-Net 不是在 step0 就坏了。
- 谱梯度通向 enc1–bottleneck，decoder/head 只有 CE；不是误把 head 冻结。原 sigma.weight、grad_update 是既有非训练参数。
- GYRO 新 BN 只在 projector；原 U-Net 是 GroupNorm。不能未经证据把下降归为主干 BN running statistics 污染。
- 源准备确实用最后学生，源 EMA 是复制，不是 .999 的时间平均；这符合旧版冻结协议，并非加载错 checkpoint。但不能通过改报缓慢 EMA 来掩盖学生已经受损。对比原最终 EMA 起点是合法的功能保持检查，不是完整相同训练轨迹比较。
- frame 在构造时已经生成，但首 69 步 β=0，未进入损失。没有第 69 步阶段末 checkpoint/评估，不能说 20 pp 一定由后 69 步锚定造成；首轮无锚谱梯度同样可能扰动编码器。
- 官方原流程面向从头自监督表征学习，使用 Adam、V=40、阶段后拟合 probe；不是给成熟医学 decoder 直接追加 γ=1 的 SGD 微调配方。原正文也讨论无 replay/单阶段锚定不自动带来准确率收益。未到 replay 阶段的本次停止不检验其历史保持机制。

静态上，`normalize(v)` 的 Jacobian 含 `1/||v||`，MLP/BN 与 encoder 的 Jacobian 再参与链式法则；因此有界的谱目标值不提供参数梯度上界。没有保存首批投影向量范数和 BN 统计轨迹，不能进一步断言具体发生了哪种内部放大。

## 4. 推荐 v1.1：初始化校准 + 保守联合接入

这是一份**待授权修正方案**，不改已完成运行，不实施代码或重新训练。保留同一原 U-Net、原生头、projector 维数、GYRO 公式、K=10、β=1/3、V=2、图像增强、源划分及采样。无新网络/损失、无 KD、无可靠性/冲突模块。所有正式分割学生参数仍全部可训练；不把冻结主干当成历史保持机制。

### A. 先校准新增 projector，不用随机接口改写成熟分割器

- 原 80.3674% 源模型作为**既有只读参考**，只提取 bottleneck 特征；用其 detached 特征训练同一个新 projector，原无锚 GYRO/MMCR 目标，固定一遍 69 步，φ 学习率 0.03。
- 这些仍是 **69 次真实 projector 优化器调用**，不能当作零成本前向；原图和划分不变，不读 U GT。
- 此时尚未执行分割学生更新，原 U-Net 参数与输出按构造保持不变。不是把后续训练学生冻结，也不声称这 69 步已让 U 学到新的器官语义。
- 之后从原源权重创建完整可训练学生，装入已校准 φ，再固定源 frame。原 GYRO 第一轮是联合从头学习，这里是成熟网络的接口初始化适配，必须明确披露，不冒充原作者逐步原样实现。

### B. 只把已校准的谱信号以小尺度接回完整 U-Net

固定第二阶段 69 步：

\[
\mathcal L=\mathcal L_{CE}+0.01\,\mathcal L_G,
\qquad \eta_{UNet}=10^{-3},\quad \eta_\phi=0.03.
\]

- 编码器（含 bottleneck）、decoder、原 head 全部保留原允许参数的训练路径；不设低秩/有界更新，不把谱梯度永久 detach。
- SGD/Nesterov/weight decay/全局裁剪 1 保持；分组 LR 明确覆盖所有 native 参数，不能再被共享引擎的逐步统一 LR 赋值覆盖。69 步用固定上述 LR，不对成熟网络重启 0.03。
- 原 EMA 权重不对应旧学生 optimizer 的精确状态，故 native 动量重新初始化是有意选择；不直接加载旧 43,600 步学生动量冒充 EMA 续跑。φ 的校准动量按固定映射携带，跨阶段恢复要检查。
- 0.01 不是已证最优值；它把**已知首批 enc1–enc3 比例**从 10.67585 降到约 0.10676，只是有证据的保守起点。校准后及完整编码器的真实比例要重新记录，不能沿用旧首批推定。
- 不同时改 β/K/V、不加回额外 U 损失或追加其他模块；先问这三个接入修正是否保住源功能。

上述 0.001 学习率仅用于这次**源模型接入校准**，不是把后续新域长期压到低学习率。目标域本轮不实施；届时仍需单独冻结同入口、完整主干可训练的可塑性对照，不能把源保持配方直接当作新域最优配方。

### C. 不用 EMA 或“根本没学”绕过门槛

所有源门槛继续要求**固定最终学生**相对原 80.3674% 不下降超过 1 pp，并检查 LV/MYO/RV；另外记录 .999 EMA，但 EMA 不能替代学生通过。原 10L 训练与 23 人验证均单列，不能只看 CE 或背景像素准确率。

联合期间额外记录（仅在之后获授权的运行中）：

1. 每个 encoder block、bottleneck、decoder/head、projector 的 CE/谱梯度范数，合成前/后 clip 范数及两项 cosine。
2. 含动量/weight decay 的实际 native 与 φ 参数更新范数，逐组实际 LR；不能继续用混合参数位移当 native 位移。
3. 开始、阶段边界、结束的 projector 输入/输出范数及 BN 统计、几何图像暴露量；这些只作诊断，不作类别收益证明。
4. 固定训练 L query 上的前后 CE/类级预测，以及固定末步完整训练/验证 Dice。query 是训练病例，不用验证标签逐步选 λ。

若完整 encoder 上加权谱/CE 梯度比超过 0.25（CE 非近零时），或 CE 近零而谱不小，保存现场并停止该源接入；不在线自动搜 λ、投影梯度或修改目标。这个比值门槛只是原始梯度诊断，**不保证带动量 SGD、weight decay 或有限步长下 CE/Dice 单调**。若源 Dice 门槛不满足，仍不启目标阶段。

## 5. 最小可判别验证，而不是直接再跑五目标组

未来若授权，仅先在源域做同一入口的三组，均从 A 的共同初始化出发、相同 L2 流/源图像/69 步/随机状态/裁剪；不给目标训练发放自动启动许可：

| 组 | 原生网络 LR | 目标 | 回答的问题 |
|---|---:|---|---|
| CE_high | 0.03 | CE only | 在同样短程再微调中，仅高 LR 和 CE 是否也伤害源网络 |
| CE_low | 0.001 | CE only | 与 CE_high 比，隔离 LR 在 CE 再微调中的作用 |
| GYRO_low | 0.001 | CE + 0.01 GYRO | 与 CE_low 比，隔离校准后的谱项是否仍有明显额外代价 |

不是在三个结果间挑最好配方：预先指定 **GYRO_low 是唯一修正候选**，其他是诊断对照。若它相对原模型下降 >1 pp 或明显差于 CE_low，停止；即便只保住源性能，也还没有证明 U 语义收益或历史保持，不能直接宣称方法成功。

该三组不能单独分解旧 19.6 pp 中的冷启动、λ、β、EMA 和交互贡献；它们提供较小但可解释的下一步证据。若对照也掉点，先看源 CE 再微调；若只有 GYRO_low 掉点，说明接入仍有问题，而非再盲目延长。

建议上限只是供后续审查：共同 projector 69 + 三组各 69 = 276 正式调用；若四个阶段/组各最多 32 工程，则总计最多 **404 次实际调用**，含所有失败和恢复重放。旧轮、GYRO 当前余额均不在本轮静态分析中消耗；没有启动请求或许可推断。
