# 统一SSL与持续学习的具体方案：固定语义坐标中的残差读出与历史能量

2026-10-18。用户要求继续分析、与CARE-Seg独立、先不启动实验。本文为可审查的方法原型，不是获准运行的实验协议；没有修改训练代码、启动作业、查询服务器或读取新患者数据。方程是本轮拟议设计，不是Vectorizer/STSD原论文方程，不声称已取得性能收益或TMI级创新。

## 选择：让Vectorizer退出主方案

Vectorizer可保留为SSL机制参考，但不再作为本路线统一模块的首选：保存U无法约束系数/encoder/decoder漂移；强制所有U-Net跳接经过全局类别向量又是大幅重构。64/512的配置差异另有审查，不能靠挑一个配置解决历史状态的函数意义。

ICLR27候选中，STSD的“固定语义参考+跨视图分歧”更接近本问题，作为概念参考；但其时序视图/源校准/平衡OT不能直接搬来。FluxLoRA保留为以后需要表征塑性时的候选，当前区域梯度与历史梯度坐标仍未解决。这里不把新方程称为STSD或FluxLoRA复现，也不强迫把SPACE保留进最终方法。

**本方案选择一个明确的代价：首版冻结原U-Net全部特征及原分割头，只学习统一残差读出。** 这样能真正固定历史状态的坐标；只能改善该固定表示上的分割读出，不能解决本体特征不可分、空间细节缺失等问题。若因此新域学不动，应淘汰该方案，而非未经论证解冻encoder或再叠保护模块。

## 1. 接入真实U-Net的位置

实际源模型来自`siemens_ssl_reproduction_v1/methods.py::Segmenter`。它调用`NativeLRParent.features`，经过enc1/enc2/enc3、bottleneck及decoder的三层skip合并，得到最后16通道特征h；再调用`native_readout`。原生头实际为`decoder.conv_logit.mu`的3×3分类卷积，不是仓库另一份示例U-Net中的1×1头，不能拿错实现。

建议计算路径：

`x → 冻结原生encoder/全部skip/decoder → h → 冻结原生头 → p0`

`                                      ↘ 固定响应基ψ → ψR ↗ 相加 → 概率单纯形投影 → 最终q`

- 原头按现有`stochastic=False`推理；原模型所有参数与状态保持eval/无梯度。没有新encoder、投影MLP、关系支持患者、第二分割分支或第三teacher。
- 从h的3×3局部补丁构成z，维度16×3×3=144，以匹配实际分割头可用的局部上下文。补丁padding及输出插值严格复用原几何，不能重裁ROI或改变图像归一化。
- 固定映射ψ(z)采用源训练集合形成的聚合中心RBF响应，归一化为非负且和为1。一个拟议单配置是m=128；源特征标准化、中心及带宽在边界确定后固定。中心不是带身份的原患者像素/图像，仍属于私有模型产物，不公开，也不宣称具备差分隐私。
- ψ在原生特征网格计算；如需输出插值，沿用`native_readout`的输出尺寸和`align_corners=True`，先把ψ插值到同一输出网格。训练标签和强弱对应均在该网格对齐。禁止默认假定“特征坐标=原图像素坐标”。
- 按像素块流式累积，避免同时存全部U的128通道响应图；固定全维矩阵，不截断历史状态的低秩谱。

令ψ为m维列向量，R为m×4残差系数：

`r_R(x,p) = p0(x,p) + ψ(x,p)^T R`

`q_R(x,p) = Π_Δ4(r_R(x,p))`，Π为欧氏概率单纯形投影。

R=0时，q=p0，和既有源输出完全相同；基准入口有可检查的恒等性。使用概率残差而非任意logit目标，避免凭空指定one-hot logit幅值。四列严格绑定原清单的背景/LV/MYO/RV索引，不能按聚类结果交换。

为什么保留skip不构成Vectorizer式旁路：本方案没有声称所有分割必须经过压缩类别瓶颈。skip与原头是显式冻结的基线，**所有可学习变化只能经过ψR**；该变化在推理时直接进入最终分割。未标注项约束的也是该输出，不是可被分割网络忽略的重建支路。此模块确实只有读出塑性，不伪装成全网表征学习。

## 2. 一个学习问题同时使用L与U

L项用四类one-hot y监督原概率的残差：

`E_L(R) = Σ_(x,p in L) w_L ||ψ^T R - (y-p0)||²`。

U只使用合法的同一图像弱/强视图。在共同几何网格上，对应像素应有相同类别；记

`a = ψ_w - ψ_s`，`d0 = p0_w - p0_s`。

`E_U(R) = Σ_(u,p in U) w_U ||a^T R + d0||²`。

学习目标为`η||R||² + E_L + λ E_U`。拟议λ=1、η=10^-3，均在观察新结果前冻结，不在本轮运行或搜索。

- U的作用是学习**使最终语义响应对合法视图变化稳定的修正**；L决定正确类别方向。它不需要教师硬伪标签，不按置信度筛选或修复低置信区域，也不把当前同域EMA当作不动的历史锚。
- 强弱几何应共享且可逆对齐。原强增强的Cutout被直接遮挡位置不纳入配对项，依据已知增强掩码，而非预测可靠性；其余光度变换需接受语义保持假设。这个遮挡处理及目标函数都不同于原FixMatch，必须显式写进将来的新协议，不能改写既有冻结实验。
- 这是Brier型**投影前平方代理目标**，不是原CE FixMatch，不能声称保留原目标函数。对one-hot标签，投影不会增大到标签的欧氏距离；但代理误差、校准、交叉熵及Dice不是同一指标。
- L/U各自按患者、ED/ES、有效采样像素归一化，使一域L和U的总贡献不由像素数量无限放大。U不做依赖隐藏GT的类别平衡；稀有结构仍可能被背景淹没，须保留为风险。
- 固定基可能令a近零，或令修正空间无法抵消d0；此时U不会提供有效学习。也可能将不应保持的强增强误差固化。这些均是可证伪失败条件。

## 3. 历史状态保存什么，为什么有函数意义

把每个监督项统一写成`w||v^T R-t||²`：

- L：`v=ψ, t=y-p0`；
- U：`v=a, t=-d0`。

只累积：

`A = Σ w vv^T`，`B = Σ w vt^T`。

于是除与R无关的常数外，整个域的学习目标就是

`E_domain(R) = tr(R^T A R) - 2 tr(R^T B)`。

**历史语义状态是(A,B)，不是类别向量U，也不只是协方差A。** A保存哪些语义响应方向受过去L/U约束，B保存这些方向应往哪里修正；仅保存A会丢失正确响应目标。若需要绝对能量，另存标量`c=Σw||t||²`；比较同一历史状态下的能量增量不需要c。

过去域退出后，删除本轮临时样本/响应缓存，只保留固定ψ定义、A/B（可把L与U分开保存以便审计）及R。无旧图像、逐患者节点或可回访的支持集。合成聚合中心也不作为公开数据发布。

当前域进入时：

`M_t = ηI + A_history + A_current`

`R_t = solve(M_t, B_history + B_current)`。

退出时一次性累加当前A/B，不能每个迭代重算时重复记入历史。在线批次只累计新的预声明视图观测；若重看同一图像，它是额外加权观测，曝光须记账。ηI在全序列只加入一次，不能每域重新加入以改变正则强度。域权重按同一归一化规则相加，无自动遗忘因子。

L学习、U一致性和历史保持都通过同一个残差函数、同一个能量与同一个解算器实现；没有另接一个保护teacher/LoRA约束，也没有把历史只当成额外伪标签生成器。

m128时，完整A约128KiB（FP64），B约4KiB；固定144维中心约72KiB（FP32），另有源标准化/带宽及R。若L/U分存需额外相应状态。冻结原U-Net本身仍是模型存储成本，不能省略。矩阵状态不是患者级记录，但也不能据“不存图像”宣称隐私安全。

## 4. 可证明与不可证明的边界

在p0、ψ、视图样本及其权重全部固定、完整A/B保留、线性系统准确求解时：

1. 顺序累积与一次性联合求解**同一个加权平方代理目标**完全等价；域加法顺序不改变解。它不是与全网CE训练、原始像素数据均匀混采或最优分割结果等价。
2. 若旧解`R_old=M_old^-1 B_old`，新解变动ΔR，则旧能量增加量恰为

   `E_old(R_old+ΔR)-E_old(R_old) = tr(ΔR^T M_old ΔR)`。

   此处E_old包含一次η岭项。过去语义风险的变化可在无旧图像时计算，而不是从向量漂移猜测。
3. 由于单纯形投影非扩张，对任意旧像素的固定响应ψ，可推出

   `||q_new-q_old||₂ ≤ sqrt(ψ^T M_old^-1 ψ) * sqrt(tr(ΔR^T M_old ΔR))`。

   这是条件性的函数变化上界。若旧预测margin大于该上界的两倍，可保留其argmax；不等于保留真实标签正确性，更不等于Dice不降。部署时不据此做置信度门控，本轮仅用作理论/诊断。

能量可精确保留，旧能量仍可能升高：联合优化在旧/新需求冲突时会折中。本轮纯Python Fraction代数例子已经同时验证“顺序=联合”“旧能量增量=二次型”，并给出旧能量正增长的例子。见[SEMANTIC_ENERGY_ALGEBRA.json](SEMANTIC_ENERGY_ALGEBRA.json)。无真实数据、作者代码或优化器调用，不是实验性能证据。

以下任一变化都会破坏上述状态闭合：解冻U-Net/原头、移动中心、重新估计标准化/带宽、随当前R重选历史伪标签或重加历史权重、丢弃矩阵谱、改用不能用A/B表示的CE目标。不能在实现中静默加入，再沿用精确记忆结论。

拟议最低机制矩阵（仅设计，不启动）：

| |当前U一致性关|当前U一致性开|
|---|---|---|
|历史A/B不参与当前求解|同容量当前L读出|同容量当前L+U读出|
|历史A/B参与当前求解|历史能量+当前L|完整统一方案|

每组固定相同p0、ψ、源读出入口、当前L采样、数据曝光与预声明视图；比较U的当前域作用、历史状态的旧域作用及二者交互。再用历史L-only状态与L+U状态作必要状态消融，区分“保存监督统计”与“保存U学到的响应关系”。具体组数/预算未授权，不自动追加。

本方案解决的是“历史状态有明确函数含义、U-Net接入不靠模糊旁路、L/U与保持共用对象”的设计闭合问题。**目前仍不足以直接作为TMI论文的充分方法贡献**。可能的研究空间在医学像素级视图变化的哪些响应值得积累、如何在无旧图像条件下给出可用的语义风险证据；若只剩“ACIL+一致性+医学数据集”，则应作为强基线或放弃主线，而不是包装新缩写。
