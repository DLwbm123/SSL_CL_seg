# CARE-Seg V1：首次有效性筛查（2026-10-18）

用户已授权：实现后在 指定服务器 GPU 3 实验，每小时监测，自行修复工程问题；本轮输出、缓存和临时文件放该服务器 data 盘的新目录。旧实验及其预算不变。本文件是新方案的独立协议，不继承此前 PPI 提案的实验臂或停止点。

## 固定问题与比较

M&Ms canonical320，冻结 split seed0；Siemens → Philips 的两域验证。只使用已有 Siemens V1 seed163、43,600 步封存源，所有臂使用相同 dense 原生 U-Net、3×3 valid 线性分类头与上采样。源初始化不是“无历史记忆”条件。训练整个学生，不使用 key isolation、低秩侧支、RL 或投影更新。

依次运行 supervised、EMA、CARE-no-repair、CARE；每臂 4,000 optimizer 步，seed163，FP32，禁 TF32。L/U batch 各 2；uniform patient → phase → slice；SGD momentum .9；LR .005，poly .9，长度 4,000；多维参数 weight decay 1e-4，其他 0；监督 CE，Dice 权重 0。弱几何使用共享翻转；强视图采用现有亮度、对比度和 .03 高斯噪声，不加 cutout。不同臂固定同一步的采样和增强 RNG；因 L 角色不同，不能称监督样本完全相同。

两个常规对照使用全部 13L；CARE 使用 NumPy default_rng(163) 对排序后的患者置换，前 7 个 A、其余 6 个 B；ED/ES 随患者。A 承担学生监督、原型和修复拟合；B 承担状态标定和候选风险拟合；U 为固定 50 人，禁止任何标签访问。B 间接影响训练，因此不是独立验证集。私有配置记录实际角色清单和体素间距，不进入公开 Git。

## CARE 固定设置

- 树：背景 vs 全部前景；LV+MYO vs RV；LV vs MYO。每节点读取条件分布，没有新增分割头；选定父决策的质量权重递归传播到子节点。父节点拒绝时不补造历史质量。
- P 来自 EMA（.99），每 250 步刷新固定块缓存；两弱视图为原图与可逆水平翻转。语义原型来自 A 的相同 EMA decoder feature，按 slice → case/phase → patient 聚合。
- 条件标签锚定 GMM：一致状态仅 00/11；二分类分歧仅 01/10；合法分量至少两名 B 患者，缺支持则关闭该分支。25 次 EM，B/U 分别归一化，MAD 标准化，协方差收缩 .2，Mahalanobis 距离平方 >25 拒绝。
- 三候选 P/R/H 各自拟合 Brier 风险（.5×概率平方误差）；标签状态后验加各候选置信度、熵和相对 P 距离进入 ridge=1 模型。绝对风险上限 .15，切换 margin .02。H 也须有标签支持，不因是历史模型而默认可信；repair 须同时优于 P 和现有候选。
- 唯一跨块稳定器为候选风险 EMA（.7）；风险恶化立即生效、改善滞后，目标 argmax 身份改变时重置。没有第二套动作投票/迟滞机制。
- 全体积物理几何，读取 frozen HDF5 的 z/y/x 间距；不把 MRI 切片假定为独立 2D 几何。32×32 网格、半径 20mm 的边界 taper × [1,z,y,x]；每节点共享 4 系数修复，log-odds L1 上限 .5，50 次投影梯度、LR .1。无修复臂仅将这 50 次设为 0，其余机制不变。
- GMM/风险拟合每患者最多 2,048 个确定性网格位置，优先等 case 配额；稀少父类可能无法填满某 phase 配额。这个近似与 32×32 缓存均属于固定工程选择，不宣称已得到校准概率。
- 以 partial conditional CE 使用被接受的节点，U 权重 1，全有效像素分母，不随少量接受区域放大。
- 固定 weak 输入、固定 H 支持 K，在完整优化器更新前后计算条件 KL 的绝对值、差值和覆盖率。只做诊断，不加硬投影；当前数据上 H 的正确性不证明旧域功能重要性。

## 额度、恢复和停止

正常训练总计 16,000 步；每臂 GPU 精确续跑资格检查默认 2 步，单列不进入学习轨迹。工程故障最多累计 32 步/臂；故障恢复从 durable checkpoint，最多额外 128 次 optimizer 调用/臂。物理调用账本不清零；已有结果、失败记录、重放次数保留。达到上限、数据角色/源模型身份不符、非有限梯度或不支持的新变换时停止相应依赖操作。负结果不会触发本协议下自动改阈值、换 seed、挑 checkpoint 或扩展数据。

每 100 步原子保存恢复状态，含学生、EMA、H、控制器拟合物、缓存、单一 temporal state、优化器、调度器和 RNG。checkpoint 及私有配置只放 data 盘。主进程和 GPU 进程用中性入口；不得终止其他进程。每小时检查实际日志与账本，正常状态保持安静，异常、完成或必须用户介入时通知。

## 评估和结论

固定 final **学生**，不是 best/EMA；训练结束在 Siemens 23val、Philips 31val 评估一次。按每个完整 ED/ES 体积计算各前景 Dice，先 phase 平均再 patient 平均，再 LV/MYO/RV 宏平均；同时报告源入口基线、旧域有符号变化和两域均值。test 不访问。源入口验证仅用于描述，不用于调整配置。

资格门：完整 CARE 相比其余三个臂，Philips 各至少 +0.5 个百分点，同时 Siemens 各不差于 -1.0 个百分点。所有比较均公开，包括无修复胜出、全拒绝或负迁移。单 seed、短程、两域验证仅提供筛查证据，不证明稳健有效、完整 CL 贡献或医疗安全。没有自动 GE 后缀、第二 seed 或长程扩展。
