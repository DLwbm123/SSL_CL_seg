# 面向 TMI 的方法主线：可靠语义支持上的决策余量保护

2026-10-22。性质：方法设计与执行路线，不是已验证方法或新的运行协议。

用户最新目标：结合五篇论文，允许先复用已有机制，先形成效果好的完整方法，再改进创新性。研究目标从单一正则的验证提升为完整方法构建。正在运行的固定 EMA 确认不变；已冻结的 SOURCE_DECISION_PROTOCOL_V1 保留为第一阶段基础验证，不能把其结果当作本文完整方法的验证。本文第二阶段必须另立运行协议及调用预算后执行，不能借用第一阶段额度。

## 1. 主张与真正要解决的问题

拟研究：在不保留旧域图像的医学分割适配中，依据当前标注图上的可靠语义证据，保护原源仍然正确的类别竞争关系，同时允许纠正源错误和增强正确决策。

工作名为“可靠语义支持上的决策余量保护”。暂不造最终论文缩写，也不把机制组合称为原创或 TMI 级成果。先验证它是否优于普通适配、固定头、完整特征蒸馏和选择性漂移；之后再判断是否需要新的可靠性或优化机制。

当前反复出现的问题是旧域患者尾部退化、新域适配代价，以及训练代理量改善却未转化为患者收益。它们支持把主线转向实际分割决策，尚不证明某一种漂移就是遗忘的原因。

已有 DS 方案仍会惩罚正确方向的 margin 增大。一个更完整的候选应区分：

1. 源知识在该位置是否正确、跨视图是否稳定；
2. 变化是否确实侵蚀正确类别相对竞争类别的余量；
3. 保护是否在少数器官或边界上失效，而全图均值仍良好。

这三件事组成一个问题链，不对应三个必须堆叠的网络。

## 3. 完整候选 V0：先建立可用的组合

### 3.1 原源完整接入与实际决策坐标

原 FixMatch 43600 EMA 直接初始化 student、固定源参考和部署 EMA。只固定最后分类核 W0；其余可训练 encoder、pre-head decoder 继续更新。没有额外专家或推理分支。

沿用第一阶段的真实读出：u=T(unfold_3×3(h))，z=W0u；padding=0，T 使用原生 align_corners=True 插值。令 C=I−11ᵀ/4，B=CW0。保护在最终输出像素坐标定义；任何稀疏索引实现都必须核对完整算子等价。

对 GT 类 c 与每个 j≠c，定义 m_j=z_c−z_j。因为 (e_c−e_j)ᵀC=(e_c−e_j)ᵀ，这正是 centered logit 的决策量。固定 W0 时，margin 差只依赖其类别对比行空间，但无需显式给全部 patch 漂移施加二次惩罚。

### 3.2 可靠支持：让标注证据优先于置信度猜测

仅使用已有当前 train-L 图像及标签。拟在同一空间几何下生成两个保持标签的弱光度视图，源参考各前向一次；student 只用主视图，CE 设置保持不变。第二视图的具体增强算子与强度必须在第二阶段协议中预先锁定并记入调用账；不从验证性能选增强。

在像素 p，源两个视图的预测都等于 y_p 才进入支持。语义证据来自 GT；视图稳定性提供连续权重：

    r_p = 1[argmax q0^(1)=y_p 且 argmax q0^(2)=y_p]
          × (1 − JS(q0^(1), q0^(2))/log 2).

q0 为四类 softmax，JS 使用自然对数。r∈[0,1]，完全 detach；它是支持权重，不是经过校准的正确率。固定源产生全部权重，student 不能通过操纵门控逃避保护。两视图均错但一致也会被 GT 排除。

不在此阶段增加原型库、GMM、U 伪标签或时间后验。跨视图一致可能偏向容易的器官内部，因此必须报告支持在器官/边界/患者上的覆盖；覆盖不足不能用背景像素数掩盖。

### 3.3 从“保持特征不动”改为“保留必要决策余量”

记固定源两视图的对应 margin 为 m0,p,j^(1)、m0,p,j^(2)。在可靠支持上两者为正，取保守参考：

    a_pj = min(m0,p,j^(1), m0,p,j^(2)).

首版候选采用固定保留比例 ρ=1/2。这是待检验的工程选择，不是临床阈值或理论最优值；正式第二阶段协议只能事前确认一次，不做验证集比例扫描。

    v_pj = ReLU(ρ a_pj − mθ,p,j).

正确 margin 增大时不受罚；适度下降但仍高于参考一半时不受罚；侵蚀超过预算才激活。源错误位置不接受源保护，仍由真实 CE 学习。该启停是连续损失的活跃集，不是 TriggerMatch 的监督撤回，也没有额外 EMA 滞回状态。

为控制源 logit 尺度，以固定 train-L 校准批中类 c 的正 a 值中位数 s_c 归一化。若任何前景类没有足够患者支持或 s_c 非有限/过小，工程门禁停止；不以验证数据补估。阈值和样本数在第二阶段协议冻结。

    L_c = sum_{p:y=c,j≠c} r_p · (v_pj/s_c)^2
          / (3 sum_{p:y=c} r_p),
    L_guard = mean_{c:该批支持非空} L_c,
    L = L_CE + λ L_guard.

空支持类不参与该批辅助均值；全空时 L_guard=0，CE 仍运行。类均值仅用于辅助项，不能回改为宏平均 CE；之前宏 CE 的负结果仍保留。均衡辅助是否有益也需消融，不能从“医学器官重要”直接推出有效。

λ 只做事前规定的一次训练梯度尺度校准。hinge 若全为零，不随意延长探针或调 ρ 以制造梯度；按预注册条件判断“当前约束不活跃/不可辨识”，停止该轮。第一阶段的 λ 不可直接挪用。

### 3.4 能证明什么

固定 W0 时，在实际被约束的可靠像素上，若每项 v=0 且 a>0，则所有 mθ≥ρa>0，student 的 argmax 仍为 GT 类。这是局部、条件性的代数结论。

软损失有限、有限像素采样、网络共享参数、训练随机性、EMA 参数平均及未见旧域图像都不满足“所有位置约束精确成立”的前提。因此不能推出旧域无遗忘、EMA 同样保 margin，或临床安全。最终仍看固定部署 EMA 的真实患者结果，student 全部报告。

这个设计的主要潜在优势是允许有益变化，而非严格零损失保证。风险包括：支持集中在容易区域；强源 margin 仍抑制新域；固定头限制可塑性；当前域正确性无法代表旧域输入；辅助类均值可能造成新尺度冲突。

## 4. 与医学分割问题的结合

第一版必须分开报告器官内部和边界上的支持率、余量侵蚀与错误率，关注小器官和少数患者，不只画低维特征图。边界定义与评价指标只能在正式方案中事前确定；本设计稿不授权额外模型前向或读取封存测试标签。

首版不增加 topology loss、解剖模板或结构生成器。如果可靠性支持系统性遗漏边界，才把“区域级可靠支持”作为下一项机制问题；不能结果一差就同时加入边界、拓扑、原型和不确定性模块。

## 5. 两阶段执行，不再做无止境的碎片扫描

### 第一阶段：保留已冻结的原源/DS 四组

当前 EMA 完整退出、一次审计及报告公开交付之后，实现 SOURCE_DECISION_PROTOCOL_V1 原有 A/B/C/D、三流及原门槛，不修改任何系数/种子/预算。它回答原源完整接入、固定读出代价、选择性漂移是否有效三个基础问题，是完整方法的基础对照。

P0 不通过则先按该协议停止并交付，依据具体失败修复独立后继设计；不能把不可辨识的正则强行叠进完整候选。正式科学结果失败也完整保留。第一阶段通过不等于本文候选通过，不等于 TMI 达标。

### 第二阶段：比较完整组合与关键替代

目标为检验“可靠语义支持＋单侧 margin 保护”能否在第一阶段基础上提升旧患者保持并保留新域学习。预定关键比较是：

- 仅固定头 CE：判断保护是否必要；
- DS 二次漂移：判断单侧余量是否优于双侧不动约束；
- 相同可靠支持上的标准 centered-logit 蒸馏：判断是否只是普通蒸馏收益；
- 只用单视图源正确支持的 margin 保护：隔离第二视图可靠性；
- 完整候选：可靠支持＋单侧 margin 保护。

所有组等数据访问、等更新，辅助诊断的额外前向必须显式计数。为公平归因，须统一辅助聚合/系数校准或增加唯一必要对照，不能把可靠性、类别归一化和约束形状同时变化后归因给一个模块。最终组数、精确标准蒸馏形式、预算和门槛在独立协议中冻结；这张列表当前不是可执行 launch 配置。

不凭第一阶段哪个 seed 好就选 seed；不在失败后重扫 ρ、温度、类权重、视图强度。保持当前原源绝对性能、患者尾部、新域非劣的核心要求，不能为组合候选放宽。

## 6. 从好用组合到论文贡献

先复用机制完全合理，但组合数量不是贡献。优先寻求的证据是：

1. 同一完整源函数下，完整候选比标准蒸馏和 DS 有稳定且有实际意义的增益，且不是额外数据/调用预算造成；
2. 源错误被允许修正、正确且脆弱的决策被保留，两者能通过预声明分析区分；
3. 患者尾部、器官边界或小结构改善，而不只均值变好；
4. 单模型部署的实际成本与约束机制一致，无隐藏 teacher 或任务 ID。

若简单组合已经有效，先保留它，不为了“新”增加模块。若要形成更强的方法学贡献，依据失败模式选择一个方向：区域级可靠性估计，或可解释的局部安全预算，或面向边界的约束几何。每次只解决已观测的具体缺口。

更广泛的独立源种子、外部域/多任务序列、标签预算和标准对比，是最终论文证据的一部分；当前反复开发的 23/31 验证患者无法替代它们。本文件只规划证据需求，不授权扩大封存测试、旧图访问或新增数据集。是否达到 TMI 的科学贡献与实验充分性，留给证据判断。
