## 1. 研究问题与唯一候选

候选D：原源模型直接初始化，固定最后分类卷积，以其类别对比行空间约束当前训练图上的pre-head功能漂移；encoder和pre-head多尺度decoder继续学习。

三个可分别证伪的问题：
1. 原源checkpoint能否零更新、原样进入新训练图，不再发生原源→S†约−0.933692pp的接入损失？
2. 决策敏感保护是否比仅固定最后分类头更有效？
3. 在一次匹配初始梯度尺度下，选择性保护是否比完整特征保护保留更多新域学习能力？

这是结合DSDR选择性表示保护、FEAST类别对比等价关系和OP-FRS完整读出原则设计的新适配，不称三篇方法的复现。TriggerMatch/RCF已核读全文，但本轮不引入其监督门控、GMM、LoRA专家或真实U。

## 3. 精确的读出与保护对象

源pre-head特征h∈R^(16×H×W)。真实LinearHead为4×16×3×3的卷积kernel，bias=None，stride=1、padding=0；之后是bilinear interpolate，align_corners=True，回到输入空间。启动时核对真实结构；不匹配即工程停止，不偷偷改成1×1或池化向量。

定义U(h)为3×3无padding patch展开；定义T为**与真实logit完全一致的空间插值算子**，作用在每个patch坐标通道上。令u_p=[T U(h)]_p∈R^144，W0为源kernel展平后的4×144矩阵。因T线性、W0空间共享，真实输出精确满足 z_p=W0 u_p（浮点核实现仅容许下面的明确容差）。

C=I4−11ᵀ/4，B=CW0。对B做一次float64 thin-SVD，按σ>1e−10σ_max识别数值秩，要求rank=3；不改阈值补救。V为三个右奇异向量，P=VVᵀ，N=I−P。于是BN=0；固定W0时，null漂移不改变相对logit，CΔz=BPΔu。包含background及三前景的同一个四类softmax，不能对器官分别softmax。

这里的C沿类别轴，不是以前跨样本中心化谱。P是精确数值行空间投影，区别于DSDR原实现的ridge算子。固定最终整个W0，是固定单块类别对比map的简洁实现；FEAST跨任务块公共分数校准在本四类域增量中不适用。不得宣称141个patch-null坐标均可被共享卷积网络独立实现。

计算允许对所选最终像素直接取得插值相邻patch并加权，避免保存整幅144通道张量；必须与完整U→T算子对照，不得用插值前坐标、平均池化或错误padding近似。

## 4. 支持、损失和梯度路径

固定源在同一L弱视图上预测，支持m_p=1[argmax z0_p=y_p且y_p有效]。只依据原源与当前train-L GT，不随student/EMA改变，不使用置信阈值。每图从有效支持均匀无放回取最多512个最终网格位置，sampler key由目标流/step/slot和固定字符串生成；四组共用，选点不消耗模型全局RNG。空支持图辅助项为0，CE照常；不重抽图寻找有效支持。所有类使用同一像素规则，不改CE类别权重。

对选中行，δu=uθ−stopgrad(u0)。定义

L_DS = mean‖Pδu‖² / (mean‖u0‖² + 1e−12)
L_FULL = mean‖δu‖² / (mean‖u0‖² + 1e−12)

均值对非空支持行，零行时定义为0。源分支、W0、V、m和归一化分母完全detach。student h/patch/interpolate均不detach；损失必须反向穿过pre-head decoder、skip和encoder。不是此前将b/e3/e2/e1全部detach的decoder-only探针，也不是匹配所有历史概率的KL。

只在训练使用源参考/P。部署使用一份student或EMA native网络，不带teacher、P、采样mask或CG。由固定读出得到的代数恒等式，不等于源域所有患者在有限训练后不退化；正则只见当前L的源正确支持。

## 5. 四组与训练

|组|起点|最后分类kernel|训练目标|作用|
|---|---|---|---|---|
|A|原源EMA|可训练|原CE|原源完整接入后的普通适配对照|
|B|原源EMA|固定|原CE|隔离仅固定读出效果|
|C|原源EMA|固定|CE+λ_FULL L_FULL|完整特征保护对照|
|D|原源EMA|固定|CE+λ_DS L_DS|唯一主候选|

A/B/C均为机制对照，不搜索它们的超参。三个新目标流20270601/02/03，共12个正式job；每job2000 optimizer。按seed外层、A/B/C/D内层固定顺序。相同采样、初始化、全局RNG、弱增强、lr=.001、SGD Nesterov=.9、matrix weight_decay=.0005/vector=0、global clip1。B/C/D读出从optimizer排除，其他encoder/decoder参数按原允许范围训练；sigma/grad_update继续固定。固定源不进入checkpoint optimizer状态。

EMA=.999从原源初始化，每次真实optimizer后更新；B/C/D固定读出直接复制源，避免数值累计漂移。EMA是预先指定主部署终点，student2000是配对辅助结果，不择优。A的可训练读出按正常EMA规则处理。无中途验证、best、early stopping、衰减扫描、动态λ、额外训练或追加seed。

各组都计算同样的student和源弱前向、支持与两种辅助标量；A/B仅CE反向。无BN的既有模型，RNG/状态守恒仍需核查。有限差分自检仅用合成张量。

## 6. P0与一次系数校准：先判机制是否可辨识

全部在EMA父轮收尾以后进行。P0先32步工程资格，再从原源全新空optimizer运行64步B探针（seed20270690）；不把工程或探针终点用于正式训练。探针64终点在固定16个两图train-L批（seed20270691）上测量CE、DS、FULL对共同pre-head可训练参数的梯度，模型/buffer/RNG保持不变。

S_j为16批gradient squared norm总和，λ_j=.25 sqrt(S_CE/S_j)，j∈{DS,FULL}。仅计算一次，所有流共享；要求各S≥1e−12，λ有限且在[1e−6,1e4]。这只是固定P0处匹配0.25倍CE梯度RMS，不宣称后续全程梯度或实际位移匹配。

P0必须同时通过：
- 源原样state、原生图与新包装输出逐元素相同；源/EMA/初始student一致，optimizer为空。
- patch读出重建max error≤1e−5×max(1,max|z|)，CΔz=Bδu关系同容差；CPU/CUDA合成P对称/幂等/BN残差相对误差≤1e−6。
- rank=3；源和固定头无梯度；DS对encoder与pre-head decoder分别有有限非零梯度。
- 每前景类在16批的source-correct覆盖≥其GT像素5%，且至少3个不同train患者有支持；不能以patch数代患者数。
- DS/FULL各自选中支持的前景损失贡献≥5%；禁止靠纯背景证明“决策保护”。
- 拼接16批梯度后，DS与FULL归一化梯度距离≥0.05，两者均有限非零；若方向不可辨识则停止，不加probe步数、不扫rank/阈值。
- golden、非空optimizer+EMA+RNG恢复、两例overfit有效下降和冻结状态检查通过；固定两例若没有可解释的学习空间，记录工程阻塞，不改阈值绕过。

P0失败只记录STOP，12个正式job不启动。通过后追加两条32步对齐轨迹（B与λ=0的D，合计64 optimizer），逐步model/optimizer/EMA/RNG exact，终点丢弃；再做12×32资格，全部PASS后开始正式。不能复用当前EMA轨迹充当新结构的资格证据。
