# 去EMA显式入口项与图像-mask对应诊断

本独立零更新诊断在N完成、M/N完整分析及单组审计后启动。冻结最后学生终点不变，不挑选诊断模型替代主部署。完成审计PASS，精确使用3612真实验证切片、128合成native输入、64generator样本，0训练/functional更新，无额外encoder前向。

## 1. 去显式初始化项：轨迹平均仍有收益，显式入口项也有贡献

对实际EMA eligible native浮点state，用(EMA−w*entry)/(1−w)，w=.999^2000≈.1352，其他state沿原copy规则。此代数构造不能逆转float32递推舍入，也仍包含接近入口的早期训练状态，不等于完全去除所有源影响。

|组|去显式入口项：Siemens%|Philips%|相对完整EMA旧pp|相对完整EMA新pp|
|---|---:|---:|---:|---:|
|A|79.547149|83.491593|-1.029685|-0.082338|
|M|78.893059|83.268395|-1.316871|-0.261450|
|N|80.175925|83.548799|-0.895135|-0.081262|

A/M/N去显式入口项后都仍优于各自最后学生，因此平均收益并不完全依赖显式入口项。但三个模型旧域相对完整EMA分别下降约1.030/1.317/0.895pp，说明这项初始化混合对观察到的旧域结果有明显影响；不能把Dice差值解释为线性可加的“源知识贡献百分比”，也不能证明特定末期震荡根因。未来如使用EMA部署，应对所有对照采用一致预设规则；本轮学生主终点不改。

## 2. M图像-mask对应：生成任务拟合充分，真实旧域仍未获益

所有32个固定生成图/mask在entry、M学生和M EMA之间相同。以下以生成hard mask定义前景区域，入口预测不是GT。soft Dice使用全32样本聚合比值，不与旧诊断的批次平均soft Dice直接混用。

|状态|全图softCE|前景条件softCE|LV hardDice|MYO hardDice|RV hardDice|生成hard前景上的预测不一致率|
|---|---:|---:|---:|---:|---:|---:|
|entry|0.130323|3.665784|0.849543|0.460601|0.380815|56.6188%|
|student|0.024572|0.392287|0.978811|0.945763|0.948265|4.5097%|
|EMA|0.027895|0.445342|0.961785|0.888726|0.863356|12.7660%|

入口在M生成hard前景区域的条件CE约3.666，而全图仅0.130，说明背景主导的全图数值会掩盖前景不一致；入口对MYO/RV的hard一致性约0.461/0.381，低于LV的0.850。可能是生成图-mask不对应，也可能是生成分布使入口模型失效；不能把56.6%的“不一致”当作相对真实GT的错误率。

M学生经过目标训练后，生成mask hard Dice达到约0.979/0.946/0.948、条件CE降至0.392，但真实Siemens验证仍低于N。这支持优先研究合成训练任务与真实历史任务的迁移/代表性及与当前目标的优化竞争，而不是继续增加类别数量或几何分散。它不单独证明图像mask错误或某一项损失是唯一根因：N还删除了历史几何行并改变了n归一化/空间采样与计算量。

M学生比M EMA更拟合生成mask，真实旧域却不如EMA，因此合成监督拟合程度不能作为真实旧域保护代理指标。逐器官softDice、soft质量、条件CE及4×4混淆矩阵均在匿名JSON，矩阵行是生成hard类、列是native预测类，不是真实GT混淆矩阵。

## 3. 旧A的入口检查：两者全背景，前景诊断必须NA

旧A32码生成mask全背景，入口native预测也全背景；hard背景Dice1，三器官hardDice/前景条件CE/前景不一致率均为NA（JSON null），没有前景样本可供判断。全图softCE约0.002473，不代表器官记忆有效。

这项检查没有观察到“入口模型在生成图上预测器官，却被旧A生成mask压成背景”的hard冲突。因此不能仅凭背景占优就声称已经证实了该抑制机制。它也不能排除后续训练轨迹或其他损失交互中的负作用。原A、M低于N的结果仍是功能证据，具体原因尚需独立机制实验。

## 4. 统计、成本与保留边界

3个轨迹平均模型只各评价两域一次；已有entry/student/EMA完整模型成绩和患者记录复用，不重复前向。各域患者/EDES集合与各自已有收据精确相同，配对bootstrap seed163/10000次，完整器官/EDES/改善下降/中位与区间见TRAJECTORY_CORRESPONDENCE_RESULTS.json。单seed开发验证限制继续，不解释为训练随机性显著性。

所有forward reserved/executed记录逐调用对应，1956次分批调用，样本数恰好3612/128/64，无在途；EXIT0，worker及timeout退休，一次审计不增加模型前向。运行约37.83秒，新增约0.49MB，另保留100MB退出余量；2h/严格<500MB预算内。CPU空前景/错类聚合自检PASS，0模型前向。
