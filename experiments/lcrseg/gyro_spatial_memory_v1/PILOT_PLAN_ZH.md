# GYRO 空间凝缩闭环：最小实验方案 v0.1

2026-10-20。方法定义见 [完整公式](GYRO_SPATIAL_MEMORY_SPEC_V0_1_ZH.md)。用户最新全局授权允许独立实验自主执行；本文先规定完整最小证据集与准入条件，实际运行状态另记，不能将方案当作已完成实验。

## 1. 科学问题和边界

同样的源数据访问、32个8×8×32码、共同图像/mask生成器、历史合成监督量和完整native训练下，**“可读取空间码的凝缩＋码作为GYRO固定伪视图”**是否比普通合成回放＋GYRO更少遗忘、且不损害Philips适应？

不是与旧16/256原图bank轮次直接归因；本轮有生成mask和历史软CE，所有新对照必须共享这些监督。不声称U语义贡献、独立泛化、全部i-CTRL设定复现或多阶段生成器持续更新已解决。

## 2. 五组最小证据集

|组|源记忆|目标读取|主要回答|
|---|---|---|---|
|A：串联合成回放＋GYRO|C0：训练效用＋共同mask约束|R0：三种图像视图|直接A＋B基线|
|B：只改读取|同一C0|R1：旧码替换弱几何视图|新增的码—再编码读取接口是否有用|
|C：完整候选|C1：C0＋同一个闭环GYRO算子|R1|凝缩与读取共同坐标是否改善结果|
|D：对应打乱|与C逐码相同的C1|R1，但参考码为Z_{π(j)}|是否依赖正确的码—生成图对应，而非多一个固定向量|
|E：集合级谱闭环对照|与C逐码相同的C1|R0＋下述集合级率差|与i-CTRL式统计闭环的机制差别|

π(j)=(j+1) mod 32，固定无不动点；D的生成图、mask、样本顺序和source frame不变，只替换读取用参考码，不打乱监督标签。按每4步覆盖32码的相同随机顺序采样，使长期参考码多重集相同。

没有C1/R0单元，所以**不能计算完整2×2交互或宣称统计意义上的形成×读取协同**。B−A隔离在C0下的读取变化；C−B隔离在R1下的形成变化。增加该缺失单元不是最初资格的一部分，只有结果支持且另立记录时才考虑。

### E组的完整定义与归因边界

令Z和U分别为本批8码×4位置的固定参考和生成弱图的再编码单位行，定义

\[
R_\epsilon(A)=\tfrac12\log\det\left(I+\frac{D}{\epsilon^2}\frac{A^\top A}{n_A}\right),\quad\epsilon=0.5,
\]

\[
d_R(Z,U)=\frac{
\frac12\log\det\left(I+\frac{D}{\epsilon^2}\frac{G_Z+G_U}{2}\right)
-\frac12R_\epsilon(Z)-\frac12R_\epsilon(U)
}{\frac D2\log(1+\epsilon^{-2})},\quad G_A=A^\top A/n_A.
\]

E目标为 L_current＋L_replay＋0.1L_geo^{R0}＋0.1d_R。frame、原生CE、码与生成器均保持共同合同。采用positive-definite Cholesky/logdet，不显式求逆。

这是**i-CTRL式集合级协方差闭环＋共同GYRO的匹配接口对照**，不是原i-CTRL论文完整复现：未重现类别增量、可变生成器或原始完整minimax目标。它只检验集合级闭环与成对视图闭环的区别。比较优于E不能写成“全面超过i-CTRL”；若需要论文级比较，须另行定义可比的dense i-CTRL复现。

该距离不识别集合内的码身份交换；D则直接检验C是否依赖对应。这两个控制比单纯再跑一个beta更有辨别力。

## 5. 顺序与早期科学停止

1. 零更新合同检查：张量/归一化/数据权限/所有SG路径、joint mask空间对应、码不是逐图缓存、字节上限、完整native前向兼容性、谱公式及集合率差数值。
2. 有限source codec工程检查；不通过则不继续正式500。
3. source codec500后一次无模型选择的质量检查，再运行C0、C1有限凝缩工程；都通过才完成各256 outer。
4. target工程资格后先依次运行A、B、C；中途不做患者验证，不改变其配方。
5. C相对A若未达到旧域至少+.5pp且Philips不低超过.5pp，则报告未支持主假设，不自动启动D/E来追逐另一个最好结果。若通过，再运行D、E以分辨对应机制与集合闭环解释。
6. 任一失败／科学负结果后可根据当前全局授权选择有依据的新独立路线，但不得修改本轮终点、预算、入口或门槛。

共同source codec的固定质量准入：在预先固定的源train-L小检查批上，重建MAE相对“源训练像素均值常数图”至少降低20%；生成mask前景mean Dice≥0.60，且每个器官预测前景非空。检查批只取源train-L，不用验证／test；它已属于codec训练数据，不宣称泛化。500步后不达标即停止本轮目标实验，不延长codec或换seed补过关。

凝缩工程必须验证一次真实query超梯度沿图像和mask路径均能到达V，且θ₀/P/G始终无参数更新；固定两例检查中utility有可检测下降。source codec、凝缩、target各自验证非空状态的实际恢复重放；所有成本占工程账本。

## 6. 终点评估与判断

主要终点固定2000步最后学生；不用EMA替代、不选best、不通过验证曲线调参。A、B、C各自完成后先报告两域绝对变化，全部必要对照齐全后再归因。

设S、P为Siemens/Philips患者宏平均Dice百分数，统一用pp差。

|判据|预设解释|
|---|---|
|C−A：S≥+.5，P≥−.5|相对串联合成回放改善保持、适应非劣|
|B−A、C−B分别报告|区分读取与形成的条件性效果；未达到+.3pp旧域改善时，不称该组件有实质保持贡献|
|C−D：S≥+.3，P≥−.3|支持正确码对应的作用；不达则不声称成对回路机制已被验证|
|C−E：S≥+.3，P≥−.3|支持超出所定义集合级闭环对照的作用，不等于超越原i-CTRL全部设定|
|S_C−S_entry≥−.5|只有满足才称旧域绝对保持；否则至多相对少遗忘|
|P_C−P_entry≥+.5|确有新域学习；不以源域收益掩盖目标未学|

原同入口Dense的两域及目标13L训练作为实用外部参照（非本轮同期机制控制），不重复其模型评估。C较其任一验证域低超过.5pp或目标训练低超过1pp，须明确报告仍有实用代价。旧五组U/frame阴性结论保持不变；本轮没有noNewU，不声称U语义贡献。

报告LV/MYO/RV、ED/ES、两域患者改善/下降人数、中位差及患者配对区间；源10L与目标13L训练分开。单seed是机制探索，不能凭阈值宣称统计显著或独立泛化。

生成侧报告codec重建MAE／生成mask和源GT Dice、最终码生成mask与源teacher一致性、固定source train查询上的学习效用、C/D闭环视图项/锚项/谱项、码间多样性及出现背景坍缩情况。统计这些不是新患者评估／选模型依据，不保存原图画廊作记忆。
