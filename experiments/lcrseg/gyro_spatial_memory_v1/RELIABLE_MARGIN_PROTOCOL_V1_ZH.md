## 完整方法与五组

B：固定头 CE；S：按源头中心化矩阵行空间投影的决策子空间保护；K：标准中心化 logit L2 蒸馏；M：单视图正确支持上的单侧边界约束；R：完整双视图可靠单侧边界约束。S/K 是机制对照及方法构建部件，不宣称原论文忠实复现。

源视图 1 为训练输入原图；视图 2 保持几何，逐图固定私有随机流采样 alpha∼U(.9,1.1)、beta∼U(-.05,.05)，clip(alpha*x+beta,-1,1)。教师完全冻结并 detach。S/K/R 使用两视图均预测正确的当前训练 GT 像素，可靠度 r=1−JS(p0,p1)/ln2；GT 不通过的像素仅不参与辅助项，普通像素 CE 始终不变。M 用视图 1 正确支持且 r=1。每图各支持集均匀无放回取至多 512 像素；相同支持用相同随机流。

对每个非 GT 类 j，m_j=z_y−z_j，a_j=min(m0_j,m1_j)。R 的逐像素值为 r/3 × sum_j ReLU(.5*a_j−m_j)^2 / s_y²；M 使用 a=m0。不会惩罚保持或扩大可靠间隔的方向。s_c 是单独训练 L 固定批次双视图正确支持上的正源间隔中位数，四类各一个，所有组共享。

K 的逐像素值是 r × mean(center(z−z0)^2)/s_y²。S 是 r × ||(u−u0)V||² / mean(||u0||²)，u 为原生 3×3 unfold 后按原读出 align_corners=True 双线性插值；V 为源分类头去类均值后的 rank3 行空间。每个辅助项按存在类分别平均、再对存在类平均；不会改 CE 的类聚合。S/K/R 支持、采样、可靠度和类聚合匹配；S 的特征归一化与 logit 尺度不同，不能宣称所有数学属性匹配。

所有五组计算相同四个辅助项和相同三次 batch 前向（学生、源1、源2），只优化被指定辅助项；B 权重为零。私有 generator 不推进训练全局 RNG。原源 teacher 不进入 checkpoint 或 optimizer，固定头 EMA 直接复制，不做衰减漂移。

## 一次性校准与工程门禁

固定顺序：32 次 P0 工程更新；seed20270790 的 B 探针 256 次；seed20270791 的 16 批源前向校准 s；seed20270792 的 16 批在探针末态计算 CE/S/K/M/R 梯度。仅当前训练 L，不读取验证结果。不因 hinge 不活跃延长探针或降低 .5。

每个辅助权重 λ=.25*sqrt(sum||gCE||²/sum||gaux||²)，一次校准共享全部正式种子。要求每项梯度能量≥1e−12、λ∈[1e−6,1e4]且有限，所有 s>1e−6；前景各类支持覆盖≥5%、涉及≥3训练患者，各辅助项前景损失占比≥5%；R encoder/decoder 梯度均非零且有限；R 与 K 归一化梯度距离≥.05；源、探针权重及全局 RNG 在测量前后完全不变。失败即 P0_STOP，无正式运行、不换种子/阈值/探针长度。

P0 通过后做 B 与 R λ=0 的各32步全状态/optimizer/EMA/RNG一致性；每个正式组独立32步工程资格（原源精确初始化、golden、非空优化器恢复、两样本 CE overfit、固定头检查）。复用现有 target 引擎，不另写正式训练循环。新增合成 CPU/CUDA hinge 正确方向和零梯度检查，复用原生读出投影自检。
