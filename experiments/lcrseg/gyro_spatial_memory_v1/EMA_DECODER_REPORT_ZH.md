# EMA与encoder/decoder诊断：固定零更新结果

## 主要发现

本轮证据更支持优先检查encoder轨迹及encoder–decoder兼容性，未支持“EMA decoder单独修复历史读出”的解释。A/C两组：EMA encoder＋学生decoder使旧域提升约2.12/2.47pp、新域提升约1.03/1.04pp；学生encoder＋EMA decoder反而两域下降。交换实验是兼容性诊断，不是可加因果分解，也没有改变本轮最后学生终点。

同时确认一个更直接的记忆问题：最终32码生成的mask严重背景占优。A的32码hard mask全部背景；C前景hard像素仅约0.0528%，每器官仅1/32码非空。源codec训练检查Dice0.8014，不能代表最终优化码覆盖了历史分割任务。低softCE在近乎全背景的软标签上不能当作语义回放有效证据。

## EMA来源与入口混合

EMA每组从共同入口初始化，alpha=.999，2000次后入口直接系数0.1351999254。eligible native浮点state按EMA同规则混合，常量与其他state按copy规则保持；同组初始化EMA=student及不eligible state相等检查通过。没有保存每一步模型，未声称逐步重建全轨迹EMA。student与EMA通过相同eval流程。

entry_mix以固定13.52%入口＋86.48%最后学生构成。它已恢复A/C旧域约1.535/1.934pp，但仍比对应EMA低0.751/0.902pp；新域与EMA接近（分别高0.032/0.037pp）。因此仅入口混合可解释一部分观察到的收益，不能解释全部旧域差异；剩余差异与轨迹平均相容，但不能证明特定噪声/末期震荡根因。不扫描系数、不从这些组合选择新主终点。

## 患者配对与解释边界

所有新增组合两域患者/EDES集合与同组已有记录匹配，报告相对student及EMA的患者改善/下降、中位差与bootstrap95%区间（seed163、10000次），见EMA_DECODER_RESULTS.json。主轮已有记录的ABC比较及EMA−student区间见PAIRWISE_INTERVALS.json。

特别是C的EMA−student：旧域23/23患者改善，均值+2.836pp、区间[2.014,3.764]pp；新域仅15改善/16下降，患者中位−0.007pp，均值+0.480pp、区间[−0.212,1.359]pp。EMA新域均值较高不等于多数患者改善。单seed重复开发验证仍不构成独立泛化或训练随机性显著性证据。
