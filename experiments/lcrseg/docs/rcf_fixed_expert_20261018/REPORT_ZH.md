# RCF 固定专家与路由诊断报告

本次仅使用已有 checkpoint 完成固定专家验证。结果不支持“RCF 本域专家已形成较大优势，只是被路由掩盖”的解释：三个目标域固定本域专家的 RCF 减 confidence 为 −0.0041 个百分点，已有实际路由结果的差值为 +0.0107 个百分点，两者都接近零。与此同时，实际路由相对固定本域专家使两臂平均 Dice 分别低0.5414和0.5266个百分点，说明路由影响绝对性能，但不是两臂表现接近的主要解释。

## 执行范围与预算

诊断于2026年10月18日北京时间21:36:45开始，21:38:48结束，耗时122.62秒，退出码0。使用源阶段 sealed checkpoint 和两个分支最终 Canon deployment 中已冻结的 Philips、GE、Canon 专家。没有训练、反向、参数更新、额外路由前向或第二步实验。

共执行3726次切片模型前向：每个模式在 Philips 660张、GE 288张、Canon 294张上评价，总计1242张验证切片乘三个模式。55名验证患者被三个模式重复评价，不是165名独立患者。原固定数据、验证划分、batch2、FP32和 phase → patient → 三个前景类别 macro Dice 协议保持不变。测试标签与 U 隐藏标签未访问。九个域与模式组合均通过前向计数和参数及 buffer 未修改检查。

实际路由指标和患者级汇总复用原实验最终 Canon 阶段结果，不重做路由推理。固定专家由真实域信息指定，只用于诊断；它不是无任务 ID 部署方案，也不保证是所有专家中最优的选择。三个目标域均值为域等权，与原报告四域均值不同。

## 路由改变了多少方法差异

定义固定专家差值为 `RCF固定 − confidence固定`，路由差值为 `RCF路由 − confidence路由`。最后一列为路由差值减固定专家差值，单位均为百分点；正数表示改用实际路由后比较更偏向RCF。

| 域 | 固定专家差值 | 实际路由差值 | 路由使差值变化 |
|---|---:|---:|---:|
| Philips | +0.0076 | +0.0497 | +0.0421 |
| GE | -0.0301 | -0.0314 | -0.0013 |
| Canon | +0.0102 | +0.0139 | +0.0037 |
| 三域平均 | -0.0041 | +0.0107 | +0.0148 |

Philips 的固定专家差仅+0.0076个百分点，实际路由差为+0.0497；GE 的−0.0301变为−0.0314；Canon 的+0.0102变为+0.0139。没有哪个域呈现“较大的正向固定专家收益，经路由后消失”。三个目标域平均差从微小负值变为微小正值，变化为+0.0148个百分点，因此不报告以接近零且变号的分母计算的“优势衰减率”。

两臂原型路由相同，但路由到各专家后的分割差异分布不同，所以即使路由决策相同，也可以改变两种方法之间的聚合差值。固定本域专家与实际路由的指标差是两种推理策略的观察差异，不能进一步分解为每个错误路由切片的因果损失。

## 路由影响两臂的绝对性能

下表为固定本域专家 Dice 减实际路由 Dice，正数表示固定本域专家在该域聚合结果更高，单位百分点。

| 域 | confidence | RCF |
|---|---:|---:|
| Philips | +0.1539 | +0.1119 |
| GE | +0.8137 | +0.8151 |
| Canon | +0.6566 | +0.6529 |
| 三域平均 | +0.5414 | +0.5266 |

两臂绝对性能受到相近的路由影响，GE和Canon更明显。这说明路由有改进空间，但固定本域专家使用真实域信息，这个差值不能直接宣称为可实现的无任务 ID 路由增益，更不是已知最佳专家上界。

患者级结果也不支持“本域专家对每名患者都更好”：Philips 上，本域固定专家相对路由，两臂均只有13/31名患者提高，18/31名降低，但少数提高较大，最终均值仍更高。GE 上 confidence 为8/12提高、RCF为10/12；Canon 为7/12和6/12。完整匿名配对统计见[PAIRED_SUMMARY.json](PAIRED_SUMMARY.json)。

## 目标域适应是否真正发生

下表为固定本域专家 Dice 减 source 固定专家 Dice，单位百分点。

| 域 | confidence | RCF |
|---|---:|---:|
| Philips | +1.9828 | +1.9905 |
| GE | +2.5413 | +2.5112 |
| Canon | +4.8969 | +4.9071 |
| 三域平均 | +3.1404 | +3.1363 |

两个分支都获得约3.14个百分点的三域平均适应收益，Canon接近4.9个百分点。confidence 相对 source 在 Philips 25/31、GE 11/12、Canon 11/12名患者上提高；RCF分别为24/31、11/12、11/12。该冻结网络加LoRA结构确实能够发生有用的目标域适应，不能再用“固定解码器使专家完全学不动”解释本轮结果。

这个比较测量的是整个目标域训练相对 source 的收益，包括可见 L 监督和 U 学习。没有纯监督目标域对照，不能把约3.14个百分点全部归因于半监督筛选，也不能据此排除固定解码器仍限制进一步收益。

Philips 中类别3的微小提高被类别1、2下降抵消。GE 中类别2下降约0.2015个百分点，超过另外两类的提高，导致域均值略降。Canon 三类差异均很小。固定专家比较中，RCF在Philips 16/31、GE 8/12、Canon 8/12名患者上更高；GE虽然多数患者略升，均值仍下降，说明不能仅按胜出患者数宣布优势。这些是描述性分解，不是显著性检验。

## 对三个候选原因的更新判断

1. **路由：影响绝对 Dice，但没有掩盖一个较大的 RCF 专家优势。** 固定专家下仍几乎相同，因而本轮“RCF没有体现优势”的主要问题已经存在于专家自身的结果里。路由使目标域平均方法差值变化约+0.0148个百分点，没有出现正向优势被压没的证据。

2. **固定解码器：不是完全无法适应，但仍可能限制上限。** 两臂相对 source 的真实目标域收益清楚存在；本次没有可训练解码器对照，不能判断解除冻结会扩大、缩小还是不改变两臂差距。

3. **前景筛选与迁移表征：仍是更直接的后续检查方向，尚未被本次单独验证。** 先前只读缓存显示入选伪标签高度集中于预测背景、共同入选 hard 标签一致，且语义原型分离较弱。在本次验证集和固定终态下，没有看到“存在较大本域专家收益却被路由隐藏”的证据；本次也没有新增筛选干预或真值校准，不能直接证明前景筛选是唯一原因。

本次仅完成第一步，不启动第二步。单种子、已见验证集的事后诊断不能证明统计等效或独立泛化，也没有评价所有跨域专家组合或按真值挑选最佳专家。
