# RCF 固定专家诊断协议

本诊断仅使用已完成 RCF TransUNet 实验的现有 checkpoint，判断实际路由是否掩盖本域专家的差异。用户授权第一步推理诊断，不训练、不启动前景筛选与解码器四格实验。

训练来源提交为 `3adb9f7cbb7d75b75ff0fe1bfcf88f3fe5d9b509`。使用源阶段 sealed 模型和两个分支最终 Canon deployment 中的本域专家；历史专家在后续阶段冻结。权重严格加载，不改动原运行或其回执。

仅访问原 canonical320、split seed0 的 Philips、GE、Canon 验证集，切片数分别为660、288、294；使用原评价函数，batch2、FP32、eval mode、无梯度。每个域执行 source 固定专家、confidence 本域专家、RCF 本域专家。患者与类别聚合沿用 phase → patient → foreground class macro Dice。

预算为3726次切片模型前向，0次反向，0次优化更新，0次新路由前向。程序计数并限制模型调用；实际路由指标复用原最终聚合结果，不新增 Siemens 推理，不访问训练隐藏标签或测试标签，不自动重试。

主比较为每个目标域 `RCF固定专家 Dice − confidence固定专家 Dice` 与已有 `RCF路由 Dice − confidence路由 Dice`。二者之差报告为从固定本域专家改为实际路由后，方法差值的变化，单位百分点；同时报告各分支固定专家到路由的绝对变化。固定专家使用真实域信息，仅为诊断，不能冒充无任务 ID 部署成绩，也不保证是所有专家中最优者。

报告三个目标域等权平均，不与原四域平均混用。若固定专家差值接近零，不以微小分母计算夸大的衰减比例；仅在方向和量级允许时补充比例。对照 source 固定专家判断本域适应的总收益，但没有纯监督目标域分支，不能将收益全部归于无监督筛选。固定专家差值与路由差值比较是部署策略变化的诊断，不分解每个切片或专家的因果贡献，不作统计显著性声明。

模型参数及 buffer 在推理前后检查未被修改；输出包含各域各类别指标与聚合核验回执。患者明细、权重、数据和环境路径仅留在私有运行目录。实际完成后发布源码、协议、匿名结果及中文报告。
