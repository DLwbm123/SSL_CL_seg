# 02｜五框架统一实验与选择计划

## 0. 目的与解释边界

目的：在同一个真实单侧参数隔离父模型上，一次性开发并比较F1–F5，选出最多2个最值得深入的论文候选。不是事先把所有模块拼成主方法，也不是保证排名前二就有创新/正增益。已有AMS/CIST/SVD/DPR等报告保持原判定；这些结果只是动机，不当作新运行的对照数值。

本轮固定为**源模型之后的持续适配模块比较**：所有新增机制从首个增量域开始。不能据此声称从源训练开始全流程都使用新机制。不是独立患者确认，不自动开放test/hidden GT，不自动进入Prostate/M&Ms。

五个框架都实现，每个有8组初始配置，且五个都进入完整预算的新优化种子复核。优先级只控制实现/排队顺序。除工程无效或操作者预算决策外，不因单个初值失败或某类别下降省略一个框架。

## 1. 阶段与停止点

| 阶段 | 内容 | 本次代码交付时可做？ | 何时停止 |
|---|---|---|---|
| A | 绑定入口元数据、五框架实现、CPU合成测试、计划、push | **允许** | push后等待外部代码审阅 |
| B | 审批后CUDA资格、真实current-L工程smoke、数据实际校验 | **当前不允许** | 有效性通过继续，不看性能选臂 |
| C | 父模型配置开发、基线调参、五框架8配置完整训练 | **当前不允许** | 全部有效配置结束后分别选1个/框架与1个/基线 |
| D | 五框架与五基线锁定配置，3新优化种子×2顺序 | **当前不允许** | 完整比较、排名、最多2个shortlist，报告后停 |
| E | shortlist的贡献消融与容量/计算匹配 | 只生成方案 | **D结果外部审阅后另行准入** |
| F | 真正独立确认、外部数据、正式CL方法对比 | 不属本轮 | 另拟方案；不能自动宣称已经投稿验证完成 |

A完成不等于B被批准。B–D可在一次明确外部审批后作为有限DAG顺次执行，无需每个epoch或每个“gate”反复人工确认。D后停止是为了确定主方法与相应证据范围，不是拖延已授权的五框架比较。

## 2. 数据、序列、共同入口

推荐两条完整三域Fundus序列：

- O1：REFUGE → RIM_ONE_r3 → Drishti_GS。
- O2：REFUGE → Drishti_GS → RIM_ONE_r3。

首域D0是REFUGE的计划选择，不冒充已经核验的旧checkpoint。必须在ParentBinding验证合法来源及未来域未暴露。找不到合法旧源学生，B之后按父源配方每个优化种子训练一次；不能复用一个已在RIM或Drishti训练过的权重伪装D0。source optimizer/EMA不继承。

D0模型按seed在所有框架/配置/顺序间共享，目标域1之后各臂必须沿自己的checkpoint继续。source训练的标注比例/预算来自父源配置，单独写明；目标域默认约20% L沿用split0。不能未经检查把整个序列都称为20%标注。

开发优化seed拟161；复核拟162/163/164。用现有日志元数据查编号是否已经参与相关开发，碰撞则按从161开始连续未用编号确定性替换并冻结，不能看结果后挑seed。患者划分仍是既有开发划分，新增seed只检验训练随机性。

选定每阶段成功更新预算S_R/S_D与源预算S0，完整预算训练每组配置。warmup/ramp默认各占阶段预算20%，优先绑定父已定义的日程；按epoch到step换算必须在RESOLVED_PROTOCOL记录，不能声称与旧epoch配方逐位相同。

默认不做低保真截断筛选：较强约束/晚启用U方法可能更慢收敛，若只看早期分数容易偏倚。预算不足时可在审阅前把所有复杂臂统一改为同样的4配置subset；不可跑到一半只砍表现暂差的框架。

## 3. C阶段：先调父方法，再开发全部候选

### C0 父配置（4组）

所有都使用同样LCTX监督、原rank/约束/层集合；只探索：

| ID | 基础lr倍率 | B/A学习率比 |
|---|---:|---:|
| P0 | 1 | 1 |
| P1 | 0.5 | 1 |
| P2 | 2 | 1 |
| P3 | 1 | 4 |

倍率相对真实父lr，并明确分别对应A、B、other参数组。若父已有不同A/B比，以上是探索的**实际比例**，需映射记录。若没有可分离的因子，不能假装执行；交代码审阅决定映射。rank不是当前8配置之外的额外隐藏搜索。

每组1seed×2orders=2条完整后续轨迹，共8条/16个目标训练阶段。C0选一个基础设置供F1–F5使用。最优P结果直接作为B0，不再重训。

### C1 共同基线（四类各8配置）

| 基线 | 配方 | 8配置因子 |
|---|---|---|
| B0 | 父方法+LCTX，无U | 复用选中P |
| B1 | 父方法+LCTX+confidence KL，U普通联合更新 | λU∈{.25,1} × parent lr multiplier∈{.5,2} × B/A lr ratio∈{1,4} |
| B2 | 父方法+LCTX+teacher PAS KL，U普通联合更新 | λU∈{.25,1} × conf∈{.6,.8} × cosine∈{.3,.7} |
| B3 | 父方法+LCTX+dense feature G，无U | parent lr multiplier∈{.5,2} × feature lr multiplier∈{.5,2} × feature wd multiplier∈{0,1} |
| B4 | 父方法+LCTX+PAS KL+dense G，U更新父与G | λU∈{.25,1} × parent lr multiplier∈{.5,2} × feature lr multiplier∈{.5,2} |

dense G=I+R_full，其他feature坐标/合并与Q版本一致。用于避免把多了一个适配器的收益全部归因于子空间。实际trainable容量和受限空间仍不同，不能称完全参数等价。

B1–B4每类8配置，与单个候选框架同样8配置额度；B0因更少自由度单独4配置。所有探索成本公开。基线允许合理调优，不能把λU=.5的单点弱基线当作完整方法的最终对手。

C1新增32配置×2orders=64轨迹。可与F1–F5在C0锁定后交错运行，减少共享服务器负载/日期偏差。基线每类选1配置，D时冻结。

### C2 五个框架（每个8配置）

机器可读配置见 `configs/study_plan.json`；`manifests/SEARCH_CANDIDATES.json` 已展开全部40组。

| 框架 | 因子1 | 因子2 | 因子3 | 固定项 |
|---|---|---|---|---|
| F1 | Q rank ratio {.25,.5} | λU {.25,1} | λJML {.25,1} | PAS .7/.5，U只更新R |
| F2 | λstructure {.1,1} | probes {最后2层,所有父adapter} | λU {.25,1} | rank继承父；U只更新B；CWMI尺度current-L校准 |
| F3 | κ {.5,2} | λU {.25,1} | proto混合β {0,.5} | Q ratio .5；geometry-only覆盖，自定义反向 |
| F4 | Q ratio {.25,.5} | λshape {.1,1} | trust fraction {.05,.2} | λU .5；3步；64²坐标；current-L形状尺度校准 |
| F5 | Q ratio {.25,.5} | λU {.25,1} | λSWD {.05,.2} | 32方向；每类8–64样本；额外clean-U前向 |

实际配置映射后若出现完全相同的有效配置（例如很小通道维导致两个ratio落到同rank），按展开配置hash去重并复用任务，不把重复训练当独立候选；保留原计划槽位的alias/reused标记，预算为上界，不擅自用空余额增加新超参。

这些是**本轮合理的开发起点，不是文献原版最优超参**。采用范围而不是武断单点。所有新增配置在第一次C评价前冻结；代码审阅阶段可以修改明显不合尺度的范围，修改需更新预算/plan hash。C结束后可提后续搜索建议，但不可自动把每类8变成无限搜索。

40配置×2orders=80轨迹。每框架均按开发Final选1配置；哪怕都低于B0，也保留它的best-as-tested进入D，而不是把框架悄悄消失。工程无效的配置不参与均值；报告失败原因和使用额度，不能用不存在的结果填表。若某框架8个配置均因共同实现bug无效，先修bug/计已消耗成本、外部审阅影响范围；不把它当科学无效或冒充完成五框架比较。

## 4. D阶段：五个框架都做多种子复核

5个框架的各1配置，加5类基线的各1配置；3个新优化seed×2顺序。**60条轨迹、120个目标域训练阶段**。各seed一个共同D0，全部从合法source出发，不从C的适配模型继续。

D不再修改超参数。三seed分别报告，不能丢弃较差种子。每条轨迹两个后续域完成并封存后才评价该轨迹；配置选择用完整C数据，最终D排序等全部有效任务结束。中途训练loss只作数值/工程观测，不用于增删方法。

D期间不根据某个分数提前杀掉框架。数据泄漏/错误父模型/非有限参数等必须停相关任务；非关键日志缺字段可报告修复，不因文书小问题否定科学训练。

## 5. 指标（特别避免三域套用两域公式）

记D0,D1,D2；R_t,s为训练到阶段t时在域s的患者均值前景macro Dice。这里前景macro使用**rim/cup**，disc/cup仅另作解剖指标。

- **Final=(R_2,0+R_2,1+R_2,2)/3**。
- **Old=(R_2,0+R_2,1)/2**。
- **Incoming_final=R_2,2**。
- **N_incremental=(R_1,1+R_2,2)/2**，单列，不与Incoming_final混用。
- **Forget_mean=[(R_0,0−R_2,0)+(R_1,1−R_2,1)]/2**，不clip；BWT_mean为其负数。

因此本轮Final=(2*Old+Incoming_final)/3，**不是**旧两域实验的(Old+Incoming)/2。先域内患者平均，再域等权、两顺序等权，最后seed等权。不把2orders×3seeds当6个独立seed。

所有表保留REFUGE/RIM/Drishti与rim/cup；另外报告disc union/cup Dice、边界HD95/ASSD（统一重采样像素单位，缺真实间距不伪造mm）、连通分量与孔洞、面积误差。空预测与空GT的约定在MetricContract固定，给出有限/无限样本分母，不能默默删除困难例。结构指标是次要分析，不临时替代Final主指标。

## 6. 选择最多两个框架

1. C：每family与每baseline独立选开发Final最高配置。均值差≤1e−4的预定义近似tie：优先Old，然后可比较的算子成本，再candidate_id。不能用测试集或隐含类别权重选超参。
2. D：按3seed两order平均Final排序F1–F5。第一候选为最高者；第二为次高者，最多2个。成本/Old并列规则同上。统计显著性不是进入shortlist的必要条件。
3. `PAPER_CANDIDATE_ASSESSMENT.md`额外评估相对C中预选最强L-only参考与最强SSL参考的配对差、方差和成本。D同时报告全部5baseline，不在D看结果后换比较对象藏掉更强基线。
4. 若首二差距小且区间跨零，表述“现有证据无法可靠区分”，保留两者，不伪造唯一胜者。若都没超过强基线，仍给best-as-tested排名，但标 `SHORTLIST_ONLY_NO_CONFIRMED_MAIN`。
5. 只有效应、贡献消融与适用范围有相应证据时，才把一个框架提升为论文主方法；代码/公式更复杂不是晋级理由。

患者区间：2000次按物理域患者cluster配对bootstrap，相同患者重采样权重跨方法/seed/order/stage共享；不以像素为独立样本。区间条件于已训练模型与反复使用的开发患者。训练seed SD单列；n=3不夸大精确显著性。五框架与超参选择带来selection bias，D也是用于选框架的开发复核；不能把所选赢家的D区间称为无偏最终测试区间。

## 7. E阶段：胜出之后才扩展的最小贡献对照（当前仅规划）

每个shortlist最多4个新对照配置，3seeds×2orders。完整候选D结果若身份完全一致可复用，不重复训练冒充新结果。

| 入选框架 | 四个优先对照 |
|---|---|
| F1 | 同Q/R且U=0；同Q/R无JML；同损失U解锁父参数；同rank随机Q |
| F2 | 同总损失但普通父初始化；CE+Dice梯度方向初始化但仍使用完整结构损失；同结构方向U也更新A；U=0 |
| F3 | 同geometry覆盖普通KL；同覆盖每位置scalar D；同最终R梯度范数对照；U=0 |
| F4 | 不修正q；不受Q限制的feature修正（完整dim、成本另计）；只在学生loss加形状不修teacher；U=0 |
| F5 | 无SWD；全维空间类别条件SWD；同Q的非类别条件SWD；U=0 |

“全维Q”很可能包含冗余/等价方向，应记录而不是包装成新方法。F3范数匹配若原梯度因抵消接近0则精确匹配不可能，使用明确fallback并报告比例，不声称处处匹配。

若一个框架的收益完全由loss-only解释，论文应降低子空间贡献主张。对五个框架强行做全量消融效率低，本轮把资源放在都给足开发机会及统一比较上。

## 8. 预算（全部是计划，不是已执行计数）

令S=S_R+S_D，n_dev=1,n_rep=3，O=2：

- C0：4×1×2=8轨迹。
- C1：4类×8配置×1×2=64轨迹。
- C2：5框架×8配置×1×2=80轨迹。
- C总152；D=(5+5)×3×2=60。
- **C+D=(152+60)S=212S**，424个后续域训练阶段。
- source：至多(1+3)S0=4S0；合法复用的source新增0，原成本仍记录。
- B资格：最多256次合成optimizer更新；真实current-L smoke合计最多24步，全部丢弃。
- E上界（尚未授权）：2×4×3×2=48轨迹，即48S。

S_R=3200,S_D=2100的**条件例子**：C805600步，D318000步，合计 **1123600**。E上界254400。source尚未绑定所以不写假总步数。每次physical失败/恢复重复更新与科学预算分开。

F2额外预算按每个目标阶段：8calibration batch×2项VJP +8direction batch×1VJP=24次额外VJP，16次额外完整前向；实际每次请求多层gradient不应重复计作多次backward，但记录返回张量数/字节。

F4额外预算按阶段：8calibration batch×2项VJP=16次，8次完整前向；每个active-U步3次d-VJP，最多5次readout-only前向（共享已完成teacher输出时可更少，记录实际）。inner loop没有optimizer.step，但不是零计算。

C+D中每family有(8×2+1×3×2)=22条轨迹=44个目标阶段。按上面的5300步例子及20%warmup：
- F2额外探针VJP上界1056，额外完整前向704。
- F4校准VJP704；内层VJP 22×4240×3=279840；readout-only上界466400；校准完整前向352。
- 这些额外VJP合计示例281600，不含普通L/U反传、资格和错误重试。
- F5额外clean-U学生前向至多22×4240=93280。

审批前由planner按实际S与warmup生成精确操作上界、显存探测后内存预算和并发数。只核对optimizer次数不能叫等算力。原型teacher-L前向、stage eval、source训练等也计数。

若预算需缩减，应在代码审阅前统一采用预列的4点子集，例如8点网格的C01/C04/C06/C07，保持每framework同配置数并保留D五框架比较；同时重算所有基线搜索额度、计划hash与审批cap。**本包默认仍为完整8点，不由Codex自行缩减。**

## 9. 输出与完成标准

必须输出：
`RUN_LEDGER.csv`、`SEARCH_RESULTS.csv`、`SELECTED_CONFIGS.json`、`PHASE_D_RESULTS.csv`、`FULL_STAGE_DOMAIN_CLASS_MATRIX.csv`、`PAIRED_EFFECTS.csv`、`PATIENT_INTERVALS.csv`、`RESOURCE_ACCOUNTING.json`、`DATA_ACCESS_AUDIT.json`、`FRAMEWORK_RANKING.md`、`SHORTLIST.json`、`PAPER_CANDIDATE_ASSESSMENT.md`、`FAILURES_AND_REPAIRS.md`、`PHASE_E_DRAFT.json`。

公开只含聚合与源码身份；patient-level数据/模型/具体路径保留授权存储。不得把“已启动/日志增长”写成“已完成”。完成需每个计划任务的success/failed/skipped-with-reason状态、退出码、有效checkpoint和评价receipt相符。没有关键输出不补造。

结果写出不受正负方向控制。不可把框架选择改成只挑最高单seed、最佳中间epoch或最佳类。报告写出后controller结束，不追加seed/超参/数据集或创建持续监控。
