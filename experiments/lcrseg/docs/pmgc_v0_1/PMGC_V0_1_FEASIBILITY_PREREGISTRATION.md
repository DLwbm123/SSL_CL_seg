## Frozen evaluator and thresholds

Each unit selects 16 distinct previous-domain and 16 current-domain validation cases by fixed hash rank, eight batches of two per side. Previous means the immediately preceding domain. Selection uses no pixel labels or results. Every P0-P4 candidate of every integration/formal pair evaluates the whole fixed validation panel plus the whole current labeled panel. Before panels are immutable and shared.

Virtual displacement is exactly `-0.001 * direction / norm(direction)` in a stateless FP64 functional call. Validation is posterior-mean; training-mode diagnostics replay the frozen stochastic Gaussian. Validation GT enters only the separate evaluator. CE is a pooled valid-pixel mean; Dice is exact pooled confusion-matrix Dice, macro over classes 1/2. No prediction/threshold selection occurs. Unsupported evaluator modes are explicit, with candidate-independent support; no pair is removed.

G1 requires all 24 foreground training mode units with >=32 pixels, >=2 cases, >=0.05 occupancy, >=75% active KD, finite/null/convergence rules. G2 requires all 48 P4 active raw guard dots >=-1e-10 with zero undefined required comparisons. G3 applies exactly the user's P0/P1 previous-utility thresholds. G4 applies the user's current safety thresholds; the any-class 0.003 Dice bound is pointwise across pair/class. G5 compares each candidate's maximum supported foreground-mode previous CE delta, uses the user's 0.60/5e-5/4-of-6 thresholds, and checks the 1e-4 no-new-mode-worsening bound pointwise. G6 uses median/p10/stage-transition retention thresholds 0.50/0.20/0.40, no zero direction and all finite. G7 requires all model/bank/checkpoint/gradient/GT isolation guards. All thresholds and exact formulas are itemized in JSON.
