# CARE-Seg V1 四臂筛查结果

**结论：本次固定方案未通过有效性门槛。** 四个分支均完整执行 4,000 步并完成预定验证；完整 CARE 在新域学习和旧域保持两项上均落后于普通 EMA 对照。没有工程失败、故障重放、事后调参或选择最佳 checkpoint。

## 固定评估

M&Ms canonical320，split seed0，优化 seed163。所有分支从同一已封存 Siemens 源模型出发，评估固定 final 学生。Siemens 23 名、Philips 31 名 validation 患者；完整 ED/ES 体积计算前景类别 Dice，先 phase、再 patient、再类别宏平均。没有读取 test 或 U 隐藏标签。

## 执行与成本证据

- 每臂 final checkpoint 与 latest checkpoint 的 step 均为 4,000，物理更新账本均为 4,000；总计 **16,000 正式 optimizer 调用**。
- 每臂 GPU 精确恢复资格检查 2 步，独立计数，总计 **8 工程调用**；恢复/重放记录为零。
- 两个 CARE 分支的 final state 均为 block 15、EMA updates 4,000，表明到达预定第 16 个缓存块。
- 原生接口在真实输入上与封存部署输出逐元素相同，最大误差 0。进程退出与 GPU 释放只作为辅助证据；完成判断来自账本、checkpoint 和评估结果。
- 公开机器可读结果在 `aggregate_results.json` 与 `results.csv`，包含每类 Dice、最终控制器统计及完成核验。患者级数据、模型及恢复状态保留在获授权的数据盘，不公开。

## 控制器实际做了什么

完整 CARE 最后一个块有 3,274,752 个节点位置，其中 1,151,493 个被选择：P 52,571，R 6,673，H 1,092,249。H 占被选位置约 94.9%，修复约 0.58%。这些是**最终缓存块的位置计数**，不是全程累计训练曝光，也不等于有效梯度质量。

检查递归父质量后的有效权重：

| 节点 | 权重大于零的位置比例 | 全网格平均权重 |
|---|---:|---:|
| 背景/前景 | 98.71% | 0.9871 |
| LV+MYO/RV | 3.60% | 0.02218 |
| LV/MYO | 1.46% | 0.01013 |

细层条件项覆盖及权重远小于根项。该现象与“路由大量选择 H，但细粒度旧域功能仍严重遗忘”同时出现；不能据此宣称当前输入上的 H 正确性或小 KL 漂移就是旧域保护。面积比例也受器官实际占比影响，未计算前景条件覆盖率，不能仅凭全图占比断言细层覆盖异常。这里提供的是诊断线索，不是已验证的失败因果机制。

## 解释边界

1. 两个常规对照直接监督使用全部 13L；CARE 直接监督使用 A 的 7L，B 的 6L 用于控制器拟合。总可见标签人数相同，但标签利用方式不同。缺少相同 7L 的普通对照，不能将全部差距单独归因于控制器。
2. B 重复参与状态与风险拟合；没有独立证明后验/风险校准。32×32 缓存、固定抽样、有界线性修复限制了表示能力。
3. 单 seed、4,000 步、两域 validation 筛查，不能得出跨 seed、长程、后续域或独立 test 的结论；也不能解释为医疗安全证据。
4. 没有工程异常需要恢复。科学门槛失败不会在此协议下自动触发调参、扩大预算或换终点；任何后续设计应单独立项并保留本次负结果。
