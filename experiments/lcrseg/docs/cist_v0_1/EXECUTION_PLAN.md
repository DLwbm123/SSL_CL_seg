# CIST V0.1：语境条件化的读出子空间等距输运

## 0. 定位与本次决策

本文件提出新的研究假设与首轮固定实验，不宣称方法已实现、已有效或具有经完整文献检索确认的首创性。

不再把此前的源权重插值/回拉作为主要方法贡献；它们最多保留为将来的低成本基线。本轮不新增密集参数锚定任务，不搜索旧 KI 身份，不重跑或改写既有负结果。已完成的 `RETENTION_VALUE_NOT_ESTABLISHED` 保持不变。

新主线：保留源模型中的已训练参数，冻结其特征提取和读出，以单个固定大小的共享模块，依据每张图像的当前语境改变分类敏感坐标系。未标注数据用于对齐同一图像的受控外观视图，不提供伪类别标签。

工作名称：Context-conditioned Isometric Semantic Transport（CIST）。这里的“semantic”指分类读出敏感坐标，并不意味着已证明语义/风格的因果解耦。

### GOLD 的借鉴与不照搬部分

用户提供的 Lai 等 2026 论文第3页及附录B讨论固定线性分类器下可实现的 logit 修正的最小范数特征变化；第4—6页给出低秩特征缩放、AGOP、教师一致性与源原型。原型在源训练阶段提取并保留，不能当作本项目“仅参数承载历史信息”的既有许可。

最小范数结论不是旧域预测不变的定理。本文不复制源原型，不保存历史AGOP，不复制论文的 r=64，也不把新实验称为完整 GOLD 复现。

对于固定线性头，按原文 top-logit 梯度定义，g=w_c，AGOP 为 W^T diag(pi) W；这说明它在该特例中重加权既有方向，并不自动产生 row(W) 外的新方向。此推导只针对该简化情况，不覆盖非线性中间层、可更新归一化和卷积全空间雅可比。

OFT、低秩正交微调、SOBA 和 ViDA 已包含相关的正交/旋转/轻量条件适配思想。CIST 的候选贡献不是“第一次使用旋转”，而是当前图像条件化的、读出约束的图内等距映射，与无伪类别的成对外观对齐的结合。需要用直接消融验证贡献归属。

## 2. 模型与读出坐标构造

复用现有源学生、原分辨率、原线性3x3头及其输出插值。新模块插入 `decoder.dec1` 输出特征与 `decoder.conv_logit` 之间。

设单图特征 H 属于 R^(C_f x P)，当前 C_f=16。原三类卷积核 K 属于 R^(3 x 16 x 3 x 3)。冻结原编码器、解码器、归一化、读出及其所有原有有效参数。

令 Pi=I_3-11^T/3，K_delta 为一个空间偏移上的3x16核。构造：

    G_R = sum_delta K_delta^T Pi K_delta    # 16x16

v^T G_R v 衡量一个通道方向对各偏移处类别对比 logit 的平方敏感度之和。这是卷积读出导出的通道几何，不是把3x144展平头的秩2/3行空间错误当成16维通道空间。

使用 FP64 对称特征分解，固定 r=8，取最大的8个特征向量 V；余下8个为 N，组成完整正交基 [V,N]。同一源模型的所有源读出臂共享完全相同的缓存基底、符号规范和hash。若切分处特征值近简并，记录间隙，不凭验证分数换基底或换r。源头退化属于输入异常，不按性能更改模型。

定义 S=V^T H，Z=N^T H。N是读出较低敏感的补空间，不是经证明的纯风格空间或精确输出零空间。

## 3. 条件等距模块

对每张图像分别计算语境描述：

    c = concat(mean_spatial(Z), sqrt(var_spatial(Z)+1e-6))

使用本图统计，不累计历史均值/方差，不跨患者做batch语境归一化。c只由当前输入决定，不需要域ID、GT或测试时数据集身份。

核心网络：MLP(16 -> 32 -> 72)，中间GELU；输出reshape为 M(c) 属于R^(8x8)与 b(c)属于R^8。最后线性层权重和偏置全零，第一层使用固定seed初始化，因此入口严格为恒等映射。主模块共有2920个可训练标量；实际总成本还包括基底与运行状态，单独核算。

令 A=(M-M^T)/2，使用小矩阵Cayley变换：

    Q = solve(I-A, I+A)
    S' = Q S + b 1^T
    H' = H + V[(Q-I)S + b 1^T]

Q的求解采用FP64小矩阵并保持autograd；作用到特征时按明确的FP32路径执行。使用原分类头与插值对H'预测，不改变原padding语义。不要创建每患者独立模型或保存每患者Q、b作为推理记忆。

同一图像内的所有像素共享Q、b；不能擅自改为逐像素Q，因为那会破坏下述命题。全局图像级变换不能表示任意局部变形，这是首版的表达能力限制。

### 图内几何命题

在实数算术下，对于同一图像任意位置p,q：

    ||H'_p-H'_q||^2
    = ||Q(S_p-S_q)||^2 + ||Z_p-Z_q||^2
    = ||H_p-H_q||^2.

这是图内特征距离不变，不是像素空间几何、分割边界、跨图像距离、旧域Dice、分类margin或概率校准不变。Q、b依赖输入；即使源特征保持，控制器也可能遗忘旧输入的适配关系。

不可通过把新旧checkpoint线性插值实现本模块。由于Q(c(x))和b(c(x))依赖当前图像，通常也不能精确合并为一个固定卷积核。部署是一个带小模块的学生，不是零额外参数的原网络。

## 4. 无伪标签的未标注目标

标注分支保留现有LCTX来源计分：前20 epoch只用干净当前L的CE+前景Dice；21—100 epoch使用原互补L/L上下文，每个锚定L像素只计分一次。只训练新模块，不更新冻结主干。不得给donor标签增加损失。

未标注分支只读当前域train_unlabeled图像。epoch21后为同一图像构造两种空间对齐的视图：

    u_a = u
    u_b[c] = clip(gain_c * u[c]^gamma + eps_c, 0, 1)
    gamma ~ Uniform(0.8,1.2)
    gain_c ~ Uniform(0.9,1.1), 独立RGB增益
    eps_c ~ Normal(0,0.02^2)

不裁剪、不翻转、不改变坐标、不做器官形状变换、不读任何U标签，不把U当标注训练的donor。几何有效mask沿用图像数据接口。

上述视图假定保留分割标签，是受控外观不变性假设，不是已识别的真实医院/设备因果模型。

冻结特征提取器给出H_a,H_b；经同一共享模块得到S'_a,S'_b。定义每图：

    E_i = stopgrad(0.5*mean_valid(S_a^2 + S_b^2)) + 1e-4
    L_view = mean_i [ mean_valid((S'_a-S'_b)^2) / E_i ]

分母使用模块之前的源坐标，不随Q,b改变，不允许通过增大输出范数作弊；先患者内均值、再batch均值。此目标属于特征一致性，不将其公式本身宣传为新损失。

总损失：

    L = CE_LCTX + Dice_LCTX + lambda_view(e)*L_view
    lambda_view(e) = min(1,max(0,(e-20)/20))

这里L提供语义坐标对分类读出的锚，U提供同一对象不同外观间的不变关系。不使用argmax伪类别、不采用高置信筛选、不需要源原型、历史教师或EMA目标。第一版lambda最大值固定为1，不按旧类别坏病例调权。

仿射对照可能通过缩小语义坐标减轻一致性损失；等距主候选不能以统一收缩改变单图内部的特征距离。但是分类输出坍缩仍不是理论上不可能，标注目标与实际结果必须共同检查。

## 5. 模型状态与history-free边界

跨阶段保留：冻结核心网络参数、一个共享控制器参数、由冻结读出确定的V/N基底。后续阶段继续更新同一控制器；不新增任务专用模块，不重置已训练控制器。原头冻结，所以V/N不随阶段重新估计。

不保留：源图像、历史目标图像、原型、AGOP、特征缓存、历史Q/b库、患者条件缓存、任务router、历史教师。

当前图像统计只在当前forward临时存在。optimizer/RNG是训练恢复状态，不作为部署记忆；阶段边界按既有协议重置Adam/LR。无需维护无训练用途的EMA，不可因少了第二模型遗漏实际forward/I/O成本。

冻结第一源核心能减少核心表征漂移，但后续域知识存于共享控制器，它仍可能遗忘。两域实验不能证明任意长序列的保持能力。

## 6. 首轮固定矩阵

命名空间建议：`experiments/lcrseg/cist_v0_1/`，测试与文档建立对应新目录。旧源码/报告不覆盖。

基线：复用源身份一致的F_FULL、F_CONV、STATIC_SOURCE；F_CONV为主性能参照，F_FULL为第二参照。不再重训旧36任务。

六个新臂：

1. SCALE_LU：固定源读出V/N，学习全局s和b，S'=(1+s)odotS+b。相同L和U目标。只称GOLD-inspired固定基底缩放对照；没有AGOP/原型/原论文归一化适配，不称完整GOLD复现。
2. AFFINE_LU：与主候选相同MLP、原始输出维度、图像条件与目标；Q=I+M，不施加等距约束。原始参数数量相同，有效自由度更大，必须说明。
3. ISO_GLOBAL_LU：同MLP但输入c固定为全零，输出对所有图像相同的Q,b；是条件化消融。原始参数量相同不等于有效自由度完全匹配，输入层部分梯度退化须披露。
4. ISO_COND_L：主结构，只用标注LCTX，无U图像读取、无L_view。
5. ISO_COND_LU：完整CIST，唯一预指定主候选。
6. ISO_RANDOM_LU：同主候选，用同源/seed下事先固定的随机16x16正交矩阵的前后8列替代V,N；不用验证结果挑随机基底。V/N影响语境和一致性坐标，因此是整体读出几何对照，不是某个单因素因果证明。

source：复用ams_seq_transfer_v0_1六份SRC_CE及已核实的source/student hash。
seeds：61,62,63。
orders：RIM_ONE_r3 -> Drishti_GS；Drishti_GS -> RIM_ONE_r3。
split：0。
epochs：100，RIM目标3200步，Drishti目标2100步。
optimizer：Adam lr0=0.001，betas=(0.9,0.999)，eps=1e-8，weight_decay=4e-5，沿父poly schedule。作用对象仅新臂的可训练模块；不能声称不同参数化下weight decay是相同函数正则。

36个新目标任务，新增正式更新：

    6 arms * 3 seeds * (3200+2100) = 95400

不需要新源训练、旧KI来源搜索、源原型预计算或旧患者特征。

资格/smoke另计。全部任务都执行，不以第一个seed或某类别下降删队列。若源文件确有错误，按已知合法源配方另列重建成本；不伪造来源、不无限溯源。

## 7. 更符合本研究目的的评价决策

从本新实验起，撤销“所有方向都改善才采纳”的合取式研究门槛；这不追溯更改旧实验结论。旧源SVD方案的平均负效应不因本修订变为正面。

唯一预指定主要效能比较：ISO_COND_LU - F_CONV 的Final，患者rim/cup宏平均，旧/新域等权，先两顺序平均，再三seed平均。

Incoming、Old、绝对Forget、每域类别、最差seed、患者分布、参数量/真实计算成本均为必须披露的次要结果，不要求它们全部胜出。

- 平均Final增益是主研究方向信号。约+0.005或以上视为值得优先复核的实用幅度，不是TMI接收标准。
- 小于0.005但为正，报告小效应及成本；不是通过反复加seed把门槛刷过去。
- 不要求每seed、每顺序、每类别为正；不再使用任一个单元-0.050就自动否定整套方法的规则。
- 不要求三个消融都显著、两个总体参照同时显著，才承认整体价值。
- CI跨零表明证据不确定，不当作无效证明；均值为负也不靠效率话术重新解释成精度获益。
- Old/Incoming之间允许真实权衡。报告Pareto位置，但不要假定所有可接受权衡都可部署；本轮没有临床安全许可。

工程硬停止保留：数据泄漏、GT越界、NaN/Inf、错误初始化、source身份错配、无法解释的状态损坏。理论图内等距的单元测试与浮点误差测试是工程检查，不是再次创造类别性能硬门槛。

### 消融只限定对应主张

完整-L：决定能否声称本版U目标有增量。
完整-GLOBAL：决定是否支持图像条件化。
完整-AFFINE：决定等距结构是否有实际价值。
完整-RANDOM：决定读出坐标是否比随机坐标更有用。
完整-SCALE：区别于借鉴GOLD的简单缩放。

某个组件无增量，只撤销该组件的强解释；不必因此否定一个主指标确有改进的整体配方，也不允许把无U收益的方法包装为SSL机制成功。

### 统计

固定阶段末学生，所有权重封存后再进行整矩阵分析。2000次患者配对bootstrap，同一物理域的患者权重在所有配方、种子、顺序间共享；两个顺序不是两个额外独立种子。三seed的差值完整列出，患者区间条件于已训练模型。仍是重复开发队列，不是独立患者验证。

## 8. 必要机制测试，不以机制图替代性能

1. source初始化与控制器零输出恒等性；主干所有原参数不更新；正常推理不读域ID。
2. FP64随机小矩阵Cayley正交性、可导性；FP32落地的图内距离相对误差采用正常范数尺度，不除以接近零的参数变化范数。
3. 同图两视图几何对应；LCTX来源监督一次；ISO_COND_L的U访问为0；其余臂U loader无GT字段。
4. 报告不同图像Q,b的变化与view对齐误差，以判断条件化是否实际被使用；不据此挑checkpoint。
5. AFFINE与等距臂的图内距离畸变、预测类别分布和置信变化；理论只保证特征距离，不保证预测永不坍缩。
6. 正常推理只需一张原图、一次冻结核心和一次控制器，不做测试时多视图集成。

小矩阵solve前后保存可恢复状态，继承V0.1.1的pending-diagnostics存档顺序。新的模块不涉及旧D+W0小分母投影检查，不复用不相关的残差门槛。

## 9. 执行后如何推进

首轮完成一次固定矩阵后停止。主指标有前景则在新优化种子重训源模型复核完整方法及主要解释对照，随后才做第三域/更长序列与独立患者验证。若初轮主要失败来自表达能力，不自动恢复14层全量更新、叠加新损失或扫rank。本轮的目标是检验一个有明确几何性质的候选，不是保证它必胜。

方法的创新性需要同GOLD、OFT/MOFT、SOBA、ViDA以及条件适配/几何保持相关工作进一步对照。当前仅提出可证性质与可证伪假设；不宣称首次、SOTA或TMI达到接收标准。
