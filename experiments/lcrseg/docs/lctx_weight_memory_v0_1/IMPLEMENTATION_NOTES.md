# Implementation and admission contract

The six existing SRC_CE receipts/student hashes are fixed in PROTOCOL.json. No source recovery is needed. Preflight opens only metadata and source weights, verifies identity, and computes CPU FP64 thin SVD/QR bases using isolated generators; per-layer bases, initialization hashes, dimensions, selected energy and visible SVD tensor bytes are recorded. Backend SVD workspace is not directly observable. Zero/rank-deficient source layers stop admission. No spectrum/score-based tuning is allowed.

The unchanged parent T_LCTX objective serves all six arms. F_FULL must match each corresponding parent target's final student/EMA/optimizer/label-order hashes. All arms share inherited data, mask and noise keys. The new trainer creates only a current-L accessor and uses frozen per-epoch step counts; U counts are metadata only. Fourteen convolutions and r=8 / scaling=1 / k=min(m//2,d-8) are fixed. Dense effective weights are formed in every LR forward. Both A/B train, while base weights and all other parameters remain frozen. A-only names a right constraint, never a frozen B.

Current EMA remains the second full model, updated from effective dense student weights. Effective tensor temporaries are layer-local, not another complete network. At source loading/checkpoint serialization transient state tensors are unavoidable and included in measured CUDA peaks. No persistent CPU shadow or source teacher is retained. For dense-arm diagnostics, individual source-layer tensors are loaded from the bound NAS cache rather than keeping a full source copy. At epoch0/20/100 diagnostics record update norm, both source/input and output leakage; both parameterized and FP32-added effective deltas are checked at 1e-5. Thin-basis hash checks enforce the frozen input identity.

A single student is merged in place after training and verified against its pre-merge output on a keyed synthetic probe (max_abs <=1e-5). These two extra forwards per task are counted separately from training/evaluation. Final evaluation uses one ordinary student, after the training process exits. The six zero-update STATIC_SOURCE target evaluations are admitted only after all36 target hashes are sealed; source-stage scores are reused and counted as historical evaluation evidence, not new GT reads.

Atomic epoch checkpoints include student A/B/base/bases, dense EMA, Adam, RNG, task/source, step and accumulated counts. Resume requires matching identity, frozen source/bases and exactly the committed log position. Uncommitted tails stop as engineering anomalies; no automatic rollback/replay. An engineering exception prevents new tasks from dispatching; other already-running tasks finish without being killed. No score-based task selection occurs.

Qualification plan: 38 optimizer updates in development CPU, 38 on exact local source, 38 on exact server CUDA (114 synthetic total); 24 discarded full-resolution real-L smoke updates (two per arm/domain). The existing math and geometry primitives are reused. The suite tests nonzero Adam constraints, trainable A/B, frozen-head feature gradients, bytewise frozen state, initial/output/merge equivalence, exact parent loss/grad/update/RNG, resume, two-case overfit, access guards and decision arithmetic. Any failed attempt remains separately recorded and counted.

Run with the NAS wrapper; each GPU4/5/6/7 has at most one task. Memory admission is max(2048MiB, ceil(1.25 * measured smoke peak + 512MiB)); sharing does not require an idle GPU. Long execution is detached; no recurring monitoring is created. The frozen matrix terminates after evaluation and aggregate output. Public closeout includes source/configuration, aggregate evidence and delivery verification only.
