# Diagnostic semantics and limitations

All active-U steps reuse the same already computed teacher U probabilities, current committed (lagged) risk, geometry and fine PAS mask. Main-only means geometry & not-fine & main-disc>=.9. Equal/risk add the existing fused-disc>=.9 and variance<=.01. Counters expose valid geometry, PAS-rejected pixels, main-disc eligible candidates, each selection, pairwise XOR/intersection/union and sequential mean/variance rejection reasons. Mean rejection is counted first, then variance among the remaining candidates, so each partition is exact. Cumulative ratios use sums of pixel counts; selected/XOR/rejection denominators include both valid geometry and candidate support. Jaccard is intersection/union, with empty union NA. No U label or correctness claim is available.

Counters are accumulated only after successful update commit and included in support_summary for exact continuation. Fixed-point records also retain the same-step counts. No per-U tensor, pixel bank, identity or label is exported. Current implementation aggregates all-step U counts over the stage; it does not publish a time series per minibatch.

At the same8 fixed points, teacher L main+two aux probabilities provide separate parent disc/background Brier and rim/cup-conditional Brier/error. Parent Brier retains the original equal-present-class, equal-image reduction; conditional diagnostics expose class counts and sums plus an equal-present-rim/cup summary. These diagnostics do not update risk: the training risk remains the original current-L parent Brier.

Boundary strata use a fixed one-pixel (3x3 neighborhood) GT band: inner means neighboring rim and cup within disc, outer means neighboring disc and background, interior means neither. Unknown-label neighborhoods are excluded. Inner takes precedence on overlaps. For each stratum AND GT class, conditional cup-probability variance across scales and main3-class entropy rank the same eligible pixels; each selects ceil(.25*n) pixels with stable flattened-index tie breaking. Both selected counts and main conditional-error counts are exported. This is a descriptive one-quartile comparison, not a tuned threshold, ROC estimate, patient-level independence, independent calibration, or pixel-level significance. No GT boundary enters U selection, risk or loss.

The numerical KL shadow uses exact parent/conditional decomposition with unit conditional weight, original accepted-pixel denominator and logsumexp for extreme logits. The production loss still calls the original masked_kl once. Pure numeric tests verify equality, ignore/masked support and empty support. No conditional gate or weight is implemented.

Every fixed point requests exactly4 VJPs (L, KL, DS, H); DS upstream None is represented as zero and cosine with zero vectors is NA. L/KL/H path tests use a generated route fixture where appropriate; an empty observed coarse mask can legitimately yield H gradient0. Diagnostic functions are no-grad/detached where applicable and do not modify RNG, parameter gradients or risk. No extra full backbone forwards are needed in production.
