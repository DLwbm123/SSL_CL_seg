## 2. 证据、推测、尚未解决的问题

原 AGMS 的 M-only 已经产生主要负向变化，H-only 接近 B2。这是当前实现及 seed163 两顺序上的消融证据，不是所有深监督都无效的定理。
HALF 改善不单调；不能证明只要再缩小系数就会恢复。Adam 依赖梯度一二阶矩，缩放某个损失不等于将最终参数更新等比例缩放。对只受 DS 监督的头，忽略 epsilon/weight decay 且整个梯度历史统一缩放的理想化情况下，矩的比例会抵消；实际混合梯度、不同轨迹和正则化不满足精确不变。

最值得干预的是“新辅助头通过 DS 直接改写主网络特征”这条路径，而不是继续改变标量。
另一个独立问题是监督目标错位：当前 H 只推高 disc 成员概率，当前 risk 只测 disc/bg，不能判断 rim/cup 条件分类是否可靠。多个头一致也可能共同预测错误。

## 3. 新设计的两部分

### 3.1 先剥离负干预：观测型辅助头（OBS0）

主模型 theta 保持 B2；现有两个 1x1 三类辅助头 phi 接收 detached 特征：

    z_s = head_s(stop_gradient(h_s(theta, x_L)))

头仍按原 A5 的 0.25 * CE+Dice 训练，lr=.001、weight_decay=4e-5、EMA=.99 均不变。
主网络继续接受原 B2 的 L/KL 及原 H，不全局 detach、不冻结 B、不将 U 更新限制到辅助头。
数学上 DS 对 theta 的直接梯度为零，phi 的梯度仍存在。H 的 mask 由 teacher 和 lagged risk 决定且停止梯度。

正式 OBS0 与原 A5=.25 相比，只改变辅助头输入 detach。恢复 .25 不是重新加大主网络压力，因为 DS 不再回传主网络。
H=0 的 shadow-only 模式仅用于生成资格：主模型/EMA/optimizer/RNG 应与 B2 等价。真实 OBS0 保留 H，因此不能预先宣称整条真实轨迹与 B2 完全相同。
阶段内恢复头、EMA、R、optimizer；阶段间只携带合并主网络，丢弃辅助头和 R。

### 3.2 再争取增益：解剖条件监督降级（后续 PLAN_ONLY）

设 q=(q_bg,q_rim,q_cup)，p 为学生；d_q=q_rim+q_cup，c_q=q_cup/d_q，学生同理。

    KL(q||p) = KL(Bern(d_q)||Bern(d_p))
               + d_q KL(Bern(c_q)||Bern(c_p))

分别称为 parent 与 conditional 项。候选机制保留 parent 项，依据当前图像的内部边界风险降低不可靠 conditional 项：

    L_U = mean_original_mask[parent + w_i*d_q*conditional], 0 <= w_i <= 1.

这是替换原 fine KL 的一部分，不是再加一份 KL；w=1 必须返回原实现，原 mask、分母、LCTX 几何不变。
不可靠细类应退回 disc/bg 软监督，而不是无条件硬推 disc=1。背景和低父类可信区域默认不降级。
该等式不是新的理论贡献；原创性只能来自医学风险判定与持续学习的独立实证作用。

当前轮只实现这部分的无反馈数值核/日志，不实现用于真实更新的 w，不产生新执行节点。
后续风险至少要区分：disc/bg、disc 内 rim/cup、外边界、内边界；不得直接复用父类 Brier 当条件风险。
可借助同一图像不同尺度 conditional 预测分歧，但是否有用先在当前 L 做描述性错误排序评估；不能用 U 真值、旧域 val 或测试集学习权重。

当前 L 是训练样本，指标不能当作独立校准或泛化证明；像素不是独立患者重复。

## 6. 新研究决策（不改旧门槛）

恢复性检查：每个顺序 OBS0-B2 Final >= -.001；每个旧域单独 macro Dice >= -.002；每个顺序 Incoming >= -.005。
这是开发投入阈值，不是统计非劣检验。First-target 必须独立列出，不允许 source 提高掩盖它。

- 恢复到 B2、但无独立信息收益：只支持去掉负向 DS；不宣称医学联合机制成功。
- 主性能恢复，观测器 conditional 分歧提供稳定、有覆盖的错误排序信号：允许提出新的条件监督研究，另审。
- 性能恢复但观测器不优于主头置信度：删除多尺度观测器，不能为了复杂保留；不自动增加结构项。
- OBS0 仍明显低于 B2：原 AGMS 多尺度/父类接入关闭；已知 H/门控的负作用再做只读归因，不继续标量搜索。
- OBS0 本身有实际收益：先补简单观测头/等权等必要控制与新 seed，不直接主张 TMI/SOTA。
