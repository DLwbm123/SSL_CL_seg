# Implementation and frozen execution contract

Independent full-parameter sequential control, no KI dependency. All36 tasks and95400 updates are bound in PROTOCOL.json before new source training. All six SRC_CE sources must complete before targets; no source-score gate. Old namespaces remain immutable. One shared new loop serves all six recipe identities, directly invoking the unmodified frozen AMS mathematical kernel; no qualification flag bypasses an old formal engine.

Target input is only its matched new source deploy_student.pt, containing student tensors plus identity, not EMA/Adam/RNG. State hash must match both content and complete source receipt. Current EMA copies the target student; fresh Adam has empty state and local LR resets. Target training access capability guards inherited CurrentData construction against old/evaluation domains. T_LCTX reverses two verified different current L patients' image/geometry only; source accounting renames donor fields and reports actual U reads0.

The source and target optimizers maintain the inherited Adam and precision semantics. Exact model hashes use existing source primitives, not rounded parameter comparison. Every epoch saves an atomic recovery checkpoint; qualification verifies exact resume at an within-epoch saved boundary and an epoch boundary. A formal crash with optimizer/log updates beyond the latest checkpoint is preserved as an uncommitted-tail engineering stop; it is never silently replayed or omitted from cost. Operation attempt counters are retained across explicit resumes. No automatic fresh retraining of failed task IDs occurs.

No intermediate GT evaluation. Training process exits before fresh one-student deployment/evaluation. Source sees only its own val; target sees source and target val. Patient rows remain private; aggregation uses the same physical-domain patient weights across all recipes/seeds/orders/stages. Three order-averaged seeds, not six independent samples. All five required source comparisons plus LCTX/UCTX versus each supervision baseline are frozen; supplemental comparisons do not replace T_AMS as the main candidate.

CPU and CUDA synthetic qualification include direct loss/update equivalence, inherited independent Dice/source/odd-U gradient checks, LCTX accounting, two-case overfit, source/EMA/Adam boundaries, warmup equivalence, exact resume and deployment, access/identity failures and paired arithmetic. Real-resolution labeled-only smoke:8 updates across two domains, labels stripped from pseudo-U; discarded states, zero actual U-image opens. Admission memory is max(2048MiB,1.25*max(smoke peak allocated,reserved)+512MiB), rounded up. GPUs4/5/6/7 are shared with at most one task per GPU; no exclusivity required.

Official source counters/GT operations are zero until this source is frozen and qualified; developmental synthetic attempts are separate, preserved and counted. Long matrix runs detached on NAS using the existing storage wrapper and child exit receipts. No default ongoing chat polling or monitor. Run/result completion triggers public aggregate delivery; private data, weights, raw paths remain NAS.
