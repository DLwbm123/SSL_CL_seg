# Frozen implementation boundaries

User authorization covers the attached complete matrix; the prior head/PAS study remains closed. One shared five-arm engine reuses the qualified head-control loop and its checkpoint/EMA/RNG/data primitives in a new namespace. All PAS/prototype branches are removed, and every new model uses the existing raw linear head. Old code is never patched.

Only target eligibility (joint vs teacher-only) and loss (MSE vs SCE) change. J_MSE is checked against the original LIN_MT_CONF for exact loss/acceptance and student/EMA/Adam state after a fixed-input update. Soft targets and masks detach; SCE uses log_softmax, and safe xlogy computes teacher entropy. The same nominal lambda retains both loss geometry and scale differences; no post-hoc rescaling is allowed.

Snapshot inference is batch1: clean plus four paired old-style perturbation draws. Each patient's complete prediction/mask payload is hashed before the val loader reads that patient's label. The hash covers student logits, teacher probability, geometry and both masks. All three masks and four analytic gradient alternatives share these same outputs. Ground truth enters only post-seal statistics. No new network backward, learned diagnostic head, prototype or model copy is created.

Correction support is grouped separately by teacher-predicted and true class, crossed with the five fixed correctness strata. Each row gives raw support, T and J accepted support and the two separate rejection fractions. Empty denominators are null with n_patients_defined counters. Gradient rows report unweighted per-pixel norm and GT dot/cosine, and real-mask/denominator/lambda-weighted local norm and GT dot/cosine. Weighted cosine is undefined at lambda0. Evaluation scalar accumulation uses FP64 on already-fixed FP32 outputs. L1<=1e-6 is a preregistered distribution-nearness description, never a training gate.

Four prediction draws average within patient before equal patient means. Pooled legacy probability counts remain draw-pixels, never new patients. The two kinds of grouping overlap and must not be summed together. Actual training class losses/entropy/KL and local gradients are tagged separately from evaluator counterfactual-loss rows. The student primary output stays epoch100; every other arm remains a mechanism comparison.

Synthetic qualification uses a reduced literal canonical HDF5 fixture with2 rows per allowed role, plus deliberately invalid path/role cases. Five independently executed20-epoch warm-ups and a26-epoch full/interrupted pair require154 optimizer steps per full qualification attempt, including the golden pair. Each attempt has a200-update hard limit; the combined ledger must remain<=1000. Checkpoints are loaded one at a time for comparison, avoiding four-model CPU shadows. Exact-source CPU and CUDA qualifications follow development. The real smoke is10 updates total on only the first two sorted labeled cases in each domain, with labels removed for pseudo-U; real train-U/val are not read for smoke.

Thirty independent100-epoch tasks are prelisted before training. Three lanes use authorized GPUs4/5/6; GPU7 had less than4GiB free at admission planning. Every task checks at least4GiB free and uses the existing NAS wrapper. No result-based admission or automatic retries exist. A failed trajectory stays incomplete while unrelated prelisted tasks continue. Diagnostics compare optimizer hash, student/EMA hashes, head mode and RNG before/after. No precomputed warm-up is shared.

The optional patient bootstrap is not used; fixed seed/domain/class deltas, sample SD and range are reported. This exposed fixed split is development evidence, not independent patient confirmation. The final compiler cannot swap the preregistered candidate when a simpler control wins.

Pre-real-data engineering revision: gradient vectors, norms and GT-dot maps are computed once per candidate and reused across descriptive class/stratum subsets. It changes no definition or tensor arithmetic order for an individual statistic. Superseded f573a4a CPU qualification and metadata-only preflight are retained, with no real-data forward/GT read.
