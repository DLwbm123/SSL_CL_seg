# Engineering qualification and execution

Exact-source local CPU and server CUDA regression plus the prescribed real-data gradient smoke gate formal execution. The new protocol supersedes old method-specific milestone/overfit requirements: real qualification is capped at 8 updates per domain and is not required to improve Dice. Smoke runs every registered arm once on the first two labeled/U rows of each domain (6 updates/domain); only SSL arms receive U. No smoke state initializes formal training. NaN/illegal data/incorrect gradients block; legal empty masks are recorded and do not change thresholds.

Synthetic integration independently generates canonical h5/v1 assets, attractive wrong-root decoys and separate roles. It uses the real model/loader/loss for warm-up through epoch26, prototype refresh, read-only diagnostics, uninterrupted-vs-resumed equality and single-student deployment. A 26-epoch synthetic trajectory is not a formal experiment. Source-qualified tests additionally cover paired initialization and streams, loss/PAS numeric witnesses, GAS gradient source and EMA timing, per-class quality denominators and fixed selection rules. No old solver test is run or claimed.

Each formal task has one student and one EMA. Checkpoints serialize references to existing tensors, not full shadow models. Qualification resume assigns loaded states to meta modules. Fresh-process deployment only loads the final student and checks deterministic predictions against evaluator-only private cache; it does not reread GT. Formal resume/retry is not automatic. Failures preserve their attempt and update ledger. A failure does not substitute a seed, recipe or input.

Durable scheduler uses only GPU4/5, one study child per GPU; existing unrelated processes are never terminated. Each child has its own create-only log and exit receipt. All 12 P1 tasks and deployments must complete before selection; admitted P2 always includes both new seeds and all four prescribed arms. Successive small checkpoint replacements are confined to the newly created run. NAS wrapper enforces NFS and an actual write/read probe; 10GiB free reserve is required.

Long runs do not depend on this Codex turn or SSH session. No recurring monitor is created. On the user's next progress query, inspect live receipts; if terminal, complete interpretation and public delivery. The generated NAS result tables are scientific evidence; final public narrative and publication receipt are completed at closeout.
