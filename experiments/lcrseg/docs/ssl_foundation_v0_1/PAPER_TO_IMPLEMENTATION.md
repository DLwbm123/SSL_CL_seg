# Paper and implementation boundary

The v1 PDF downloaded from https://arxiv.org/pdf/2605.20538v1 is 63 pages and has SHA256 `dc5cdfc70cdda70e6175ce055632a0cf00431bcdbf88fd2801f6f5cf37742b93`, matching the supplied plan. Page 5 equations (3)–(5) support per-image normalized prototypes, cosine validation and probability consistency over the two valid sets' intersection. This is a single-domain adaptation experiment, not complete JASCL reproduction or a test of all theoretical claims.

Pinned official classifier: `prinshul/JASCL@3c93ca70784fc3a1d2a887f8d7dce5af6bc75f53`. G0 retains normalization, temperature 10 and no-padding functional convolution; the existing wrapper interpolates logits with align_corners=True. G0 only disables sampling. The unused sigma parameter is retained and its absent gradient and bytes are reported. grad_update is excluded from Adam.

Explicit plan choices: random initialization, two independent domains, all effective weights trainable, fixed Adam/LR schedule, 20-epoch warm-up, input Gaussian noise 0.02, 0.99 EMA, shared student prototype coordinates, refresh times, fixed development split and prospective gates. No prototype replay, predecessor weights or hidden-U labels. Mean Teacher is an EMA reference, not an expected Fundus effect: https://proceedings.neurips.cc/paper/2017/hash/68053af2923e00204c3ca7c6a3150cf7-Abstract.html

Unlike the old RepairedMeanTeacher helper, this implementation copies GAS sensitivity after the successful supervised-gradient update instead of averaging it. Other floating network weights use EMA; discrete buffers copy. The frozen old engines and locks remain unchanged. One new loop serves all six new recipes because the old lifecycle has incompatible warm-up, EMA and read-only diagnostic timing. Existing model, canonical HDF5 loader, geometry, sampling primitive, CE, scorer, Adam and durable child launcher are reused.

The official module import resets Python/NumPy/Torch RNG and backend flags; its classifier constructor sets Torch seed 1024. Both are scoped and external state restored. Backbone initialization uses the registered seed/domain stream, while official classifier initialization remains identical across seeds. Per-image geometry/input noise use sample_position; the official sampled weight tensor is shared by a mini-batch, so head streams use position 0. No arm ID appears in matched component keys. The official constructor is not rewritten.

Diagnostics use deterministic clean inputs plus four independent noise/head draws. GT is evaluator-only. Fresh diagnostic prototypes are distinct tensors; actual-training PAS prototypes are additionally measured without modification. Ground-truth validity affects counts/scoring only. Patient IDs and per-case draws are private NAS artifacts. Public tables disclose equal-patient means, pooled draw-pixel counts and all valid-denominator counts; four draws never become four patients.
