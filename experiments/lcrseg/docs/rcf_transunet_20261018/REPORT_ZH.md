# RCF TransUNet M&Ms 持续分割结果报告

本轮固定预算迁移实验于 2026 年 10 月 18 日北京时间 17:43:38 正常结束。RCF 最终四域平均 Dice 为 80.3182%，匹配置信度对照为 80.3095%，差值仅 +0.0087 个百分点。三个域略升、GE 略降；单种子验证结果不足以支持 RCF 有明确优势，也不能将两者接近解释为统计等效。

## 实验范围

本轮将分类类增量 RCF 迁移到同类别域增量医学分割，域序 Siemens → Philips → GE → Canon，canonical320、split seed0、训练 seed163。源阶段只用已有可见 L，不使用 U 隐藏标签或测试标签。评价为固定终态模型的验证集结果；先汇总每个病例各前景类别的像素 Dice，再平均 ED 和 ES、患者、三个前景类别，最终四域等权平均。

采用 R50-ViT-B/16 TransUNet，源阶段训练完整网络，后续冻结源网络、解码器和统计量，只训练当前域最后六层 Q/V 的 rank8 LoRA。历史模型参数及摘要原型保留，不回放历史图像。推理用冻结源特征与原型选择专家，不使用真实厂商任务 ID。

两臂共享源模型、初始化、采样、增强、1500 步目标域预算和路由协议。confidence 使用固定 0.95 置信度筛选；rcf 使用预测一致性和语义证据的 MAD、二维 GMM 与后验阈值。两者均为两弱视图、温度2、完整分辨率缓存，前300步仅监督。详见 [冻结协议](../../rcf_seg_study_v1/PREREG.md)。

## 结论和局限

本轮说明该实现可以在固定预算下完成源训练、两个匹配持续学习分支及无任务 ID 评估，且历史参数隔离检查通过。科学结果是：RCF 与固定置信度对照在本次单种子验证迁移中表现接近，最终均值差仅+0.0087个百分点，没有形成有说服力的增益证据。

本轮不提供独立测试、多种子置信区间或原论文分类结果复现。原 RCF 的冻结 ImageNet 特征被替换为源域训练后冻结的编码器；分类样本 GMM 改为确定性抽取像素拟合并对全部像素应用；医学分割增强、batch和固定解码器也与原分类设置不同。这些均为预先固定的迁移边界。不能将旧 U-Net 或 CARE 结果作为本轮骨干匹配对照，也不能据当前结果拆解可靠性筛选、固定解码器与路由各自的因果贡献。
