# Implementation of the already registered test readout

This is an implementation record, not a change to the registration, training, evaluation roles or scientific gates. No new pilot, hyperparameter or training run is added. The exact training source remains `4d4c2e4333fd0c75733b58d0c44227b15beedc6b`; readout source is published separately and deployed to a separate NAS checkout.

`scripts/evaluate_fundus_lwf_v1.py` first checks all six actual training exits, all three queue exits, complete training receipts, frozen planned/resolved configs, all 80,400 contiguous steps, finite losses, zero skipped updates, all 18 final-stage checkpoints, unchanged old-model tensors, manifests/splits and all previously verified training/validation bytes. This admission uses zero model forwards and does not request a test-role view. An incomplete admission may be inspected again after training completes; it does not consume a test attempt.

Only after admission passes does create-only `test_evaluation/` claim the single attempt. The script verifies test-role assets, loads the unchanged shared `UNet2D`, and calls the existing `evaluate_site` with no gradients, no optimizer, no augmentation and batch size 4. All six lower-triangular cells per run are evaluated. The fixed case counts imply **612 forward calls and 2,430 case predictions** across the six runs: per run, 25 + (25+10) + (25+10+7) forwards. A pre-forward guard prevents exceeding this bound. Missing, duplicate, unexpected, nonfinite or inconsistent required Dice cells fail engineering acceptance.

Forward hooks save predictions and case mappings on NAS without any extra model call. This enables a separate artifact-only arithmetic and label-coverage audit. Raw predictions, case IDs and per-case metrics remain private. Aggregate hard Dice is computed by the existing case/patient-mean evaluator, with both-empty class Dice=1; this is not pooled B0 Dice. Ancillary ASD/HD95 may be undefined for empty surfaces, as in the unchanged evaluator, and do not enter any registered Dice gate.

The fixed F/I/BWT formulas and all five bounds are read from the existing registration. A hand-calculated synthetic oracle checks direction, pairing and negative decisions; malformed evidence is tested separately. These synthetic readout tests use no real data. Real-batch and overfit engineering attempts have already passed and must not be repeated for this read-only milestone. Training code, loss and checkpoint lifecycle are unchanged.

After the sole readout, protected input/checkpoint byte hashes are checked again, a complete or failed result is saved, and the parent must record the actual child exit. Scientific failure is retained as a completed negative study, not converted to an execution error or followed by a retry. Archive verification and publication follow separately.
