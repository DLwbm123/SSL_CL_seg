# Canon 前景筛选与解码器四格验证协议

2026年10月18日，用户明确授权本轮单域验证。共享300步监督 warm-up，四格各1200步，正式物理更新总计5100，工程更新最多12。单种子、无调参、无自动重跑，失败保留现场与已消耗预算。不重训源模型，不修改旧实验，不运行第二个种子、其他域或路由消融。

## 四格与共同设置

| 分支 | 预测前景筛选 | 解码器 |
|---|---|---|
| A | 原 RCF | 冻结 |
| B | 各预测前景类按 RCF 后验保留前50% | 冻结 |
| C | 原 RCF | 卷积与分割头可训练 |
| D | 各预测前景类按 RCF 后验保留前50% | 卷积与分割头可训练 |

前景干预在每次当前U全集缓存刷新后执行，背景沿用本分支原 RCF 选择规则；对预测类1、2、3，各自以EMA后的RCF后验降序精确保留 ceil(n/2) 个像素，分数并列按固定数据绑定与像素顺序决定。没有最低置信度、真值锚定、前景损失加权或额外损失；前景掩码替换原前景选择，伪标签不改变。空预测类不补样本，GMM从未有效时仍仅监督。这是数量和组成同时改变的诊断，不声称筛选精度改善。

仅放开 decoder 的 Conv2d 参数和 segmentation head 的 Conv2d 参数；所有BN affine与运行统计保持冻结和eval状态。ResNet、原Transformer参数、归一化参数仍冻结；当前Canon LoRA正常训练。解码器新参数与LoRA同用 AdamW lr5e-4、wd1e-4、恒定LR，不另调学习率。

沿用原训练 source sealed checkpoint，骨干与数据划分不变。仅创建Canon LoRA，不携带无关历史专家；原各域独立从同一冻结源模型初始化，历史专家不参与当前域训练或本轮固定专家评价。使用原Canon初始化seed166（163+域索引3），原batcher seed163，canonical320 seed0，Canon可见L为5患者116切片、U为20患者530切片。全部隐藏U标签及测试标签禁用。原类别原型映射、GMM、缓存、增强、温度2和150步刷新保持原样，不顺带修正其他实现问题。

## 共同入口与物理预算

从源模型创建当前LoRA，先执行4次工程更新检查：2次full-state exact-resume/golden更新，恢复后对同两病例执行2次更新并检查确定性eval监督损失下降，再恢复到工程前状态。随后实际执行300次监督warm-up，保存模型、method、优化器、调度器和RNG完整状态。

四格各自从该300步checkpoint独立加载，先核对完整状态相等。C/D此后放开卷积，将新参数加入相同LR的第二优化器组，原LoRA Adam状态与调度器时钟继承，新参数Adam状态为空。各格在site_step300准备自己的首个缓存，再执行2次完整状态exact-resume资格更新并恢复，随后执行site_step300至1499共1200次正式更新。工程合计4+4×2=12；所有物理资格与正式调用使用optimizer hooks记账与限额，失败不清零、不重试。共享warm-up仅物理执行一次，不能按四份计成1200步。

所有状态恢复深拷贝优化器张量，防止load_state_dict别名污染共同入口或资格快照。未来工程恢复未授权，入口create-only，任何失败保留partial、checkpoint、退出与失败回执。

## 诊断与评价

每格记录监督和U损失、每预测类总体与入选像素数、GMM状态、LR及更新数。在每格正式site_step300和900，复用同一次训练前向，额外计算监督与U四个预测类别损失对本格可训练参数的梯度范数。每点5次autograd.grad，合计40次额外导数调用，0次额外优化更新、0次额外模型前向；它们保留训练图，正常总损失仍由共享Trainer反向一次。不同解码器设置的参数空间不同，梯度范数主要用于格内类别贡献描述，不直接作跨参数空间效应比较。

统计所有分割图像前向和编码器图像前向（后者包含冻结语义特征提取）；资格、缓存、诊断和失败成本不隐藏。正式训练反向5100次，工程反向最多12次，另有上述40次诊断导数调用。缓存和checkpoint工作量按实际记录，不把5100次优化更新冒称总算力。

仅四格最终终态后各评价Canon固定专家一次，每格294切片，合计1176次验证切片前向。沿用phase→patient→三个前景类别macro Dice，报告全部四格和逐类结果，不中途验证、不选最佳checkpoint。真实Canon域信息仅用于固定专家，不能宣称无任务ID部署结果或CL遗忘改善。源模型与先前诊断仅作背景，不新增source或warm-up验证。

## 固定比较与结论边界

报告百分点：B−A和D−C为前景干预的条件效应，C−A和D−B为解码器干预的条件效应，交互为(D−C)−(B−A)。另报前景与解码器两个平均主效应，不只挑最优格。没有预设显著性检验或任意成功门槛，不因结果追加训练。

这是已见验证集上单种子、单Canon域、两个共同因素的开发诊断，不是独立测试或原RCF复现。它可以分辨该固定干预下的结果变化与交互，但不能将前景数量、伪标签质量和类别分布的变化完全拆开，也不能概括其他种子或域。
