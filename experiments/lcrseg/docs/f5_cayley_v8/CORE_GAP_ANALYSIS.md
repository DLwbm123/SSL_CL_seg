# F5 与 B2 的核心差距：结构诊断与下一模块

本次核对实现、已公开成对结果，并只读检查8个归档 F5 封存变换；不读患者图像或逐患者指标，不重训或改变正在运行的 V7。V7 核对快照为321正式步、0封存，资格PASS、STATUS=train，无完成读出。本报告不使用 V7 部分效果。

## 直接事实

| 比较项 | 原 F5_C02 | 历史 B2_C06 |
|---|---|---|
| 主干/输入约束 | NativeLRParent，W0+B@(A−A@V@V.T) | 同一个 NativeLRParent 与硬投影 |
| U 的作用位置 | 仅末端R；父A/B仅监督L | 所有可训练父A/B；无R |
| 额外特征记忆 | k=8、D=16；G=I+Q R Q.T，跨阶段F_next=F_prev G | 不维护这一累乘特征变换 |
| U 目标 | KL+0.2类条件SWD | PAS筛选KL |
| 原选中系数/筛选 | lambda_U0.25，PAS置信0.7/余弦0.5 | lambda_U1.0，PAS置信0.6/余弦0.7 |
| Final/Old/Incoming % |65.4109/63.1689/69.8950|67.9011/66.2410/71.2212|

因此“F5有输入硬投影而B2没有”是不正确的解释。核对依据是实际NativeLRParent、Model.u_parameters/detach_u_parent、StageTrainer.losses和冻结B2 C06候选配置。B2的U能共同改变各层低秩因子A/B；F5的U只能在最终固定Q子空间调整R，不能直接修正整个编码/解码特征。这是明确的容量和梯度耦合差异，但尚未被隔离实验证实为性能差距的原因。

均值Final差距2.4902pp=(2/3)*Old差3.0722pp+(1/3)*Incoming差1.3262pp，其中82.25%来自Old。不能只看Incoming或一个有利seed。F5−历史B2成对Final：163/O1 +3.7174pp，163/O2−2.3688pp，164/O1−5.1701pp，164/O2−6.1392pp；对应Old+5.2221/−1.8478/−7.2132/−8.4497pp。seed与顺序差异显著，不能把均值差解释成统一欠拟合。

## 为什么此前改动没有解决它

V1边界与线性损失适配器降低Old且总体为负；OT仅+0.0987pp对F5，32点中仅1点hinge正，不能当充分激活的强方法。V2冲突投影实际8183/16960活跃调用，却仅+0.1017pp Final对F5，说明处理当前L/U冲突的收益不足，不能断言冲突就是B2差距的主要来源。当前L只来自新域，梯度与其对齐本身不约束旧域性能。

V3/V4/V5仅向父B开放U，父A仍L-only；这没有重现B2联合A/B的反馈。V3总U到B、V4仅KL到B、V5限制B-U范数都延续严重163/O1旧域退化；V5cap仅100/16960次生效。这些结果反对把“只补B或压B幅度”当可靠修复，而不能排除联合A/B结构的潜力。

V6在原F5上仅将U系数0.25→1，Final64.2484%，vsF5−1.1625pp、vsB2−3.6527pp；两seed对F5平均均负。14/32固定R梯度点方向相反，9/32 U范数>L，仅是稀疏诊断。加大同一R目标没有改变反馈容量、目标质量或累乘几何，反而加重Old。过去几轮过度集中在局部损失/梯度/幅度干预，尚未直接检验跨阶段R结构。

## 下一轮首选：OFT/Cayley 子空间旋转

借鉴[OFT的正交参数化](https://arxiv.org/abs/2306.07280) §3.3；这是把其Cayley思想移到现有F5末端特征子空间，不是宣称原文研究了我们的医学CL任务，也不标为未经核实的NeurIPS2026论文。设 S=(R−R.T)/2，O=solve(I−S,I+S)，G=I+Q(O−I)Q.T，F_next=F_prev G。保留原Q、R存储、主干硬投影、原lambda_U/SWD/PAS/损失、两阶段常量D×D封存方式和R-only U权限。只替换R的几何参数化；不叠加V7拒绝或V2投影，不调系数。

当Q正交且初始F_prev=I，每阶段G和累积F都正交，消除模块本身的通道缩放。教师EMA必须平均原始R生成元后再Cayley映射，不能平均旋转矩阵或把O−I当原始R。须从本轮自己的正交前缀继续，不接归档线性F5的非正交前缀。

目前模块和零优化器CPU数学检查已准备：恒等初始化、正交/保范数、两阶段折叠、原始R的EMA、state restoration、关闭模块与线性F5一致、数值梯度和冻结Q/F_prev/teacher通过。尚未进行native/GPU资格、真正checkpoint续训或任何性能训练，不能称为实验启动或方法成功。

风险：正交不保持固定分类头logits，父主干仍由L更新；它只控制该模块造成的几何失真。有效自由度由64降为28，可能损失必要缩放/适应能力。B2的联合U容量与PAS差异仍未解决。若变换几何改善却Old未改善，就应否定其性能主因假设，转向有依据的层级反馈/教师可靠性模块，而不事后调旋转幅度。
