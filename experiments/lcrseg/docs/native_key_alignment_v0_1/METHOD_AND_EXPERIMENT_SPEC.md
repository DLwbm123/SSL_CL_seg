## 1. 目标和固定底座

在 NATIVE_LR_SRC_A_3DOMAIN_V1 + B2_PARENT_PAS_KL_C06 上检验：保持原生 A/B 更新权限时，利用已训练权重导出的输入键子空间做当前域类别条件特征对齐，是否改善最终性能和旧目标域保持。

不更换父方法、不增加 B 侧正交、不改变 LoRA rank、优化器、学习率、监督配方、EMA、PAS 或标签划分。无新增 R、F、投影 MLP、旧教师、历史样本、历史原型库或域路由。

## 2. 可检验假设，而非既成结论

H1：把分布对齐作为原生 A/B 路径的辅助项，比仅通过新增低维模块学习更有希望；本研究不声称单独解释旧 F5 的失败。
H2：用父方法已保护的权重键 V 作为对齐坐标，相比同维随机坐标有额外收益。
H3：收益应出现在完整两次目标更新的轨迹中，而不仅在统一 B2 前缀的第二次域切换中。

局部推导：W = W0 + DeltaW，DeltaW V = 0。若输入 patch 从 p0 变为 p0+delta_p，则输出差为 DeltaW p0 + W0 delta_p + DeltaW delta_p。输入侧投影不能独自消除特征漂移项。||DeltaW V||^2 已被原参数化压到零，不应被包装成新增有效损失。

新的对齐只使用当前域 L/U 和当前 EMA，不对历史特征做蒸馏。因此它不能保证过去输入的特征不漂移；该机制必须通过性能与对照验证。

## 3. 唯一新增模块：原生键空间类别条件对齐

### 3.1 层和坐标

第一版仅选 decoder.dec1.merge.block.3 的实际输入，即最终 decoder block 第二个 3x3 卷积之前的张量。
该层在已核对结构中为 16 输入通道、16 输出通道；3x3 patch 展平维度 d=144。父方法保护维度 k=8。
从当前阶段入口 student 的真实父方法获取既有 V in R^(144x8)，不额外估计历史激活协方差，不改原保护矩阵，不再额外做 SVD。
teacher 使用同一个固定入口 V 对其当前特征做只读投影，不从 EMA 另求一套基。

取该层输入的真实 3x3 patch p(x,v)。z = V^T p，随后按向量做 L2 normalize，eps=1e-6。
不得把 V 当成16维通道基直接乘最终特征；V 的坐标是144维卷积输入 patch。
建议先选中心位置，再 gather 所需 patch，避免对整幅特征图保留巨大 unfold 张量。
卷积 stride/padding/dilation 与实际层一致，feature/output 标签映射必须有坐标测试；第一版忽略边界和 invalid 区域。

### 3.2 两端样本

参考端：现有当前 EMA 在当前 L clean 前向中的该层输入，按当前 L 真值类别分类，全程 stop-gradient。
学习端：同一当前 U batch 的额外 clean student 前向，不做 UL 拼接，不新增空间增强，保留对上游 A/B 的梯度。
U 分类与有效集合完全来自原 B2 teacher 预测和 PAS；不读取 U 真值，不增加学生高置信门槛。
只处理 rim/cup；每类 n=min(64,n_L,n_U)，n<8 则该类不参与平均。无有效类别时返回 graph-connected 零并计数。

沿用现有经验 SWD 的单位随机方向、排序和平方差归约，32方向；不换成均值MSE、Gaussian近似或uniformity。
两个类别等权，参考特征不跨 batch 存储，更不跨域保留。
像素选择与随机投影方向必须使用不同的独立 namespace，不能因维度变化扰动相同位置抽样或共同训练随机流。

### 3.3 对照的尺度

令辅助空间维度为 D，统一定义 L_align=(D/8)*SWD_squared，向量先L2归一化。
原生键与随机键 D=8，普通全patch特征 D=144。
该比例仅消除单位随机投影最直接的1/D尺度差异，不声称精确匹配梯度范数；另行记录实际梯度范数。

### 3.4 总损失和权限

L = L_supervised_original + ramp * (KL_B2 + 0.05 * L_align)。
固定 lambda_KL=1.0、lambda_align=0.05、PAS confidence=.6 / cosine=.7。
warmup和ramp沿用B2，均为阶段总步数的.2；warmup不计算辅助项。
A/B初始lr均.0005；Adam、weight decay和原调度保持不变。
这是一个新的辅助损失定义；不声称数值系数与旧F5等价。

所有原允许 A/B 都保持对监督和KL的更新权限。辅助项作用于所选层输入，因而直接梯度主要进入上游参数；所选层自身A/B不一定收到此项梯度。
特别是新B=0初始化时部分A梯度可为零，不能要求每个A/B在每一步的辅助梯度都非零。
只做一次总optimizer更新；不新增梯度投影/裁剪/自适应门控，不增加B侧约束。

阶段间仅保留父方法合并后的权重。V按父规则从自己的新阶段入口权重重建；当前EMA、原型、优化器重置。部署与B2同结构，不增加测试时分支。

### D1分析与推进门槛（建议，需在看结果前冻结）

先按seed/order与C0配对，再在seed内平均两顺序。
C3相对C0：两个开发seed均值均>0、总体Final至少+0.005；O2平均Old不下降；每个顺序平均Incoming下降不超过0.005。
机制证据：C3与C2的逐seed及总体差必须报告；若没有方向一致的优势，不支持真实权重键优于随机低维正则的叙事。
C1同样必报，避免复杂模块只优于弱对照。门槛不是显著性检验。
共同前缀下早期分数固定，因此 DeltaForget=-DeltaOld；不能把二者当成两份独立证据。
所有16阶段跑完统一判断，不按途中旧域val剪枝；工程故障单独处理。

若C3不优于C0且其他辅助臂也无收益，关闭本轮alignment假设，不接着扫更多系数/层数。
若C1/C2更好，按实际结果收窄机制主张，不把控制臂的成功包装成权重记忆贡献。
若C3表现良好但不优于最强普通控制，不自动进入论文主实验。

## 7. 论文主张边界

SWD本身不是新方法。候选贡献是让同一组权重导出键承担互补角色：参数更新的输入侧隔离 + 当前有标注/无标注分布对齐的坐标；无附加部署模块、无历史样本或特征统计记忆。
已有文献包括O-LoRA（EMNLP 2023）、GPM（ICLR 2021）、SWSEG（CVPR 2025）以及LoRA Subtraction for Drift-Resistant Space（CVPR 2025）。本方案仅为当前项目的新待测组合，不声明首次提出或保证优于B2。
