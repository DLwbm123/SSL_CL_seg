# Implementation and evidence boundaries

The user authorizes the complete fixed P0/P1 and mutually exclusive conditional P2 process in PREREGISTRATION.md. This new namespace starts at the requested 405337e commit. Historical source and outcomes remain immutable.

The implementation reuses the qualified Foundation loader, original constructor, cyclic order, geometry, noise, prototype, PAS, MSE, EMA, metrics and process-launch primitives. Its four-arm loop makes head_mode explicit in every save/load and adds read-only statistics. The normalized original classifier remains untouched. An independent golden step compares new SUP_G1 against the original engine, including student, EMA and Adam state. Linear warm-up states match across all three arms.

The single-method change replaces only the classifier forward with raw F.conv2d using the same mu, kernel and interpolation. Inactive sigma is retained and frozen; linear EMA copies this inert field exactly to avoid meaningless rounding drift. Effective parameters retain the original0.99 EMA. Numerical synthetic witnesses cover the explicit head math, strict PAS mask with disagreeing predicted labels, zero/nonzero consistency gradients, unchanged RNG, inert fields, canonical HDF5 layout and protected roles. A real 26-epoch synthetic lifecycle checks checkpoint/Adam/EMA/head/RNG/data-order recovery and deployment with the combined teacher/prototype checkpoint removed. Formal execution uses no extra network backward for diagnostics.

Checkpoint recovery is epoch-boundary only. Every completed checkpoint stores RNG, optimizer, EMA, prototype, epoch and cumulative loader counters. The stateless epoch/step streams reconstruct the complete labeled-order digest. A checkpoint/log divergence stops instead of silently discarding partial updates. No automatic retries are enabled; numerical/data failures preserve the attempt and terminal status.

P0 loads exactly one original pair in each isolated worker. The original actual epoch96 prototype is verified against the old final diagnostic receipt; no labeled accessor or prototype refresh is used. Prediction-only APIs construct all six masks and their geometric K before that patient's evaluator reads GT. Equal geometric mass is asserted per teacher class. Post-ignore effective-support equality is recorded separately. Neither GT nor P0 summary enters training or gates.

Random controls average four null permutations, then four training-like prediction draws, then patients. Clean predictions stay separate. Public aggregates retain support counts and number of patients with defined rates; missing denominators stay null. Infinite and undefined conditional likelihood ratios remain explicit. Pooled counts describe replicated draw-pixels, not independent patients. Reliability tables include pooled bin confidence/accuracy and patient means. Local derivative norms use the actual mask, denominator and lambda; they are not full-network gradients. Actual per-step training class losses are aggregated separately from evaluator candidate-filter diagnostics.
